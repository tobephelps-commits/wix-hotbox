# Milestone v2.0: Pi Appliance

**Status:** SHIPPED 2026-03-10
**Phases:** 43-59 (18 phases)
**Total Plans:** 60

## Overview

Full ground-up rewrite of HotBox as a self-contained Raspberry Pi 5 production appliance with touch-first UI, LAN access, and network printing. Replaced the v1.x Node.js CLI/desktop application with a Fastify + SQLite backend, Vite/React frontend, and Pi OS infrastructure — all deployable to a single Raspberry Pi 5 with 15.6" touchscreen for kiosk-style operation. Every feature from v1.x was ported and modernized with touch-optimized UI, plus new capabilities like network printing, mDNS discovery, and systemd appliance hardening.

## Milestone Summary

**Key Decisions:**

- Pi OS Lite 64-bit Bookworm without desktop environment -- lighter, faster boot, fewer attack surfaces
- Fastify over Express for backend -- better TypeScript support, plugin architecture, schema validation
- SQLite with WAL mode over PostgreSQL -- single-file database, zero setup, optimal for single-user appliance
- Vite + React for frontend -- fast HMR, modern build tooling, component-based UI
- setDataDir/setConfig init patterns -- decouple modules from config imports, pure functions
- JSON blobs for order addresses -- always loaded with order, rarely queried independently
- Unified vendor consolidator -- single vendor-agnostic module replaces separate SanMar/S&S cart modules
- CSS custom properties for design tokens -- single source of truth for touch-optimized theme
- mDNS for LAN discovery -- hotbox.local accessible without IP address lookup

**Issues Resolved:**

- Fixed static file serving in dev mode (47)
- Fixed sizeOrder sort crash (47)
- Replaced hardcoded CSS values with design tokens (58-06)
- Replaced undefined --spacing-* and --shadow-depth-* tokens (59-05)
- Production build validated clean with zero TypeScript errors (59-05)

**Technical Debt Incurred:**

- None significant -- clean architecture from ground-up rewrite
