# Milestone v0.1: MVP

**Status:** SHIPPED 2026-01-31
**Phases:** 1-10
**Total Plans:** 34

## Overview

Transform HotBox Clothing from a manually-managed WIX store into a streamlined operation with optimized storefront UX and automated SanMar product pipeline. The first half focuses on conversion -- fixing navigation, mobile experience, and checkout on the live store. The second half builds the SanMar integration that eliminates manual product creation, adds inventory monitoring, and automates stock-level responses.

## Phases

**Goal**: Complete picture of current store state -- site structure, navigation hierarchy, product catalog, page layouts, and specific UX issues to fix
**Depends on**: Nothing (first phase)
**Plans**: 3 plans

## Milestone Summary

**Key Decisions:**

- UX improvements first, SanMar integration second (store is live, losing conversions)
- Draft-first product publishing (owner reviews before going live)
- Variable pricing by product type with 7 category presets
- Mockup images, not SanMar photos (products are custom decorated)
- SanMar stock monitoring only (decorated inventory tracked externally)
- ESM module system with TypeScript and NodeNext resolution
- Pure-function pricing engine with no API dependencies
- Nodemailer for SMTP email delivery (zero external service dependencies)
- Visibility-only variant updates (price/SKU preserved, only visible field changes)

**Issues Resolved:**

- SanMar API credentials provisioned and all endpoints verified
- 3 critical WSDL bugs fixed (pricing arg structure, media namespace collision, inventory endpoint selection)
- Chat widget removed (was blocking product purchases)
- Broken LMNT products hidden from storefront
- 5 checkout policies configured via API
- 15 brand-specific size guides added to all clothing products

**Issues Deferred:**

- 32 WIX Editor manual fixes pending for store owner
- Mobile responsive design requires WIX Editor (zero REST API endpoints)
- Abandoned cart recovery emails require WIX Dashboard setup
- CK-3 variant image switching requires WIX Editor gallery-variant linking
- Multi-supplier support deferred to future version
- Print-on-demand integration out of scope

**Technical Debt Incurred:**

- Client-side pricing presets duplicated in preview.html (self-contained HTML, no build tools)
- WIX site ID hardcoded as constant (single-site deployment)
- Console output suppression pattern for clean validation formatting
