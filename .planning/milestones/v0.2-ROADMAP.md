# Milestone v0.2: Multi-Brand Operations

**Status:** ✅ SHIPPED 2026-02-01
**Phases:** 11-20
**Total Plans:** 38

## Overview

Transform from single-pipeline MVP into a multi-brand, multi-vendor operation with order fulfillment automation and advanced pricing/inventory capabilities. Extended the SanMar-only pipeline into a vendor-agnostic architecture supporting S&S Activewear as secondary supplier, added full order management with invoice/label PDF generation and SanMar cart automation, built profitability tooling with cost tracking and sale/promo pricing, and upgraded inventory monitoring to real-time multi-warehouse with priority-based polling.

## Milestone Summary

**Key Decisions:**
- Vendor abstraction with VendorAdapter interface preserving SanMar direct path for zero regression risk
- S&S Activewear REST API using zero new dependencies (Node.js built-in fetch)
- Order management with local-first store and WIX sync that preserves local status advancement
- Playwright browser automation with headless-to-headed handoff for SanMar cart filling
- Preview-before-execute pattern for destructive/expensive operations (cart fill)
- Priority-based polling daemon with single tick-based loop for inventory monitoring
- Cross-platform print service with platform detection (PowerShell/lp) and zero dependencies

**Issues Resolved:**
- 0 of 3 WIX API automation candidates were actually automatable (all require Editor)
- Left-sleeve logo position corrected from (0.25, 0.25) to (0.80, 0.32)
- WIX customer name resolved from billingInfo.contactDetails (not buyerInfo)
- WIX addressLine mapped correctly to addressLine1

**Issues Deferred:**
- 30 WIX Editor/Dashboard manual fixes remain for store owner
- Abandoned cart recovery email setup (requires WIX Dashboard)
- Variant image switching (requires mockup upload + WIX Editor gallery linking)

**Technical Debt Incurred:**
- Auth helpers duplicated in orders and coupon modules (avoiding wix-api.ts internal modifications)
- SanMar direct path preserved alongside vendor adapter (transitional bridge mapping)
- All preview UI in single preview.html file (growing large but consistent pattern)
