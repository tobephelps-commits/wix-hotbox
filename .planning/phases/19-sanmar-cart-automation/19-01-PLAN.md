<task type="auto">
  <name>Task 1: Define cart types for SanMar batch fulfillment</name>
  <files>scripts/orders/cart-types.ts</files>
  <action>
Create cart-types.ts with these type definitions:

1. `CartItem` interface:
   - `vendorStyle: string` — SanMar style number (e.g., "PC61")
   - `color: string` — Color name as it appears on line items
   - `size: string` — Size label
   - `quantity: number` — Consolidated quantity across all orders
   - `sourceOrders: number[]` — Array of orderNumbers that contributed to this cart item (for audit trail)
   - `productName: string` — Display name (from first matching line item)

2. `CartFillRequest` interface:
   - `items: CartItem[]` — Consolidated items to add to cart
   - `orderNumbers: number[]` — All order numbers included in this batch
   - `createdAt: string` — ISO-8601 timestamp when consolidation was created

3. `CartFillResult` interface:
   - `request: CartFillRequest` — The original request
   - `status: 'success' | 'partial' | 'failed'` — Overall result
   - `itemResults: CartItemResult[]` — Per-item result
   - `checkoutUrl?: string` — URL where the browser was left for manual checkout
   - `completedAt: string` — ISO-8601 timestamp

4. `CartItemResult` interface:
   - `item: CartItem` — The cart item that was attempted
   - `success: boolean` — Whether it was added to cart
   - `error?: string` — Error message if failed

Export all types. Follow existing project patterns (JSDoc comments on interfaces, named exports).

<task type="auto">
  <name>Task 2: Build order consolidation engine</name>
  <files>scripts/orders/cart-consolidator.ts</files>
  <action>
Create cart-consolidator.ts with a `consolidateOrders` function:

```
consolidateOrders(orders: Order[]): CartFillRequest
```

Logic:
1. Filter line items to SanMar-vendor only (`vendor === 'sanmar'` or `vendor === undefined` since existing orders default to SanMar). Skip items where `vendor === 'ss'`.
2. Filter line items that have `vendorStyle` defined — items without a vendor style number cannot be added to SanMar cart. Log a warning for skipped items.
3. Group by composite key: `${vendorStyle}:${color}:${size}` (all lowercased for comparison, but preserve original casing in the CartItem).
4. Sum quantities across matching items.
5. Track which orderNumbers contributed to each CartItem in `sourceOrders`.
6. Return a `CartFillRequest` with the consolidated items sorted by vendorStyle then color then size, the full list of orderNumbers, and current timestamp.

Also create a helper function:
```
getOrdersForCartFill(filter?: { statuses?: OrderStatus[] }): Promise<Order[]>
```
This loads orders from the store and filters to orders in eligible statuses (default: `['new']`). Returns orders sorted by orderNumber ascending.

Import Order types from ./types.ts and CartItem/CartFillRequest from ./cart-types.ts. Import listOrders from ./order-store.ts.

Include clear console warnings when:
- A line item has no vendorStyle (cannot be added to SanMar cart)
- An order has zero SanMar line items after filtering
- The final consolidated cart is empty (no items to order)
  </action>
