  <action>
  Add new CLI subcommands to the monitor CLI:

  1. `warehouse <style>` — Show per-warehouse inventory for a tracked style.
     - Load the latest snapshot for the style from store
     - If snapshot has `warehouses` array, display a formatted table:
       ```
       Warehouse Inventory: PC61 (Port & Company Essential Tee)
       Last polled: 2026-01-31 14:30:00

       Warehouse          | Total Qty | Status
       ───────────────────┼───────────┼────────

       Cincinnati, OH     |       450 | Normal
       Phoenix, AZ        |         0 | Out of stock
       ...
       ───────────────────┼───────────┼────────
       Total across all   |    34,500 |
       ```
     - Sort warehouses by qty descending
     - Use WAREHOUSES constant for names when available
     - If snapshot lacks warehouse data, print "No warehouse data. Run 'poll' to refresh."

  2. `priority <style> <hot|normal|slow>` — Set poll priority for a tracked product.
     - Load tracked products, find by style, update priority field, save
     - Print confirmation: "Set PC61 priority to hot (polls every 15 minutes)"
     - Use interval from config to show actual poll frequency

  3. `priority <style>` (no priority arg) — Show current priority for a product.
     - Default to 'normal' if priority not set

  Update the help text in the CLI to document new commands.
  </action>
