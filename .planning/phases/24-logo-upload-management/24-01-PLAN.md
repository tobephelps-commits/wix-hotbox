Add registry write-back and logo management functions to overlay.ts:

1. **saveLogoRegistry(registry: LogoRegistry)** — Write updated registry to data/logos.json. Use JSON.stringify with 2-space indent. Ensure data/ directory exists (same pattern as loadLogoRegistry).

2. **addLogo(key: string, entry: LogoRegistryEntry)** — Load registry, validate key doesn't already exist (throw if duplicate), validate entry.filePath exists on disk (throw if missing), add to registry.logos, save registry. Return the updated registry.

3. **updateLogo(key: string, updates: Partial<LogoRegistryEntry>)** — Load registry, validate key exists, merge updates (Object.assign), save. Return updated entry.

4. **removeLogo(key: string, deleteFile?: boolean)** — Load registry, validate key exists, remove from registry.logos, save registry. If deleteFile is true AND the file exists, delete the PNG from disk. Return void.

5. **processLogoUpload(fileBuffer: Buffer, originalName: string, key: string, displayName: string)** — The core upload processor:
   - Validate the buffer is a valid image using `sharp(buffer).metadata()`. Accept PNG, JPEG, WebP, GIF. Reject if format is undefined or unsupported.
   - Get dimensions. If either dimension exceeds 2000px, resize to fit within 2000x2000 (using `sharp.resize({ width: 2000, height: 2000, fit: 'inside', withoutEnlargement: true })`).
   - Convert to PNG with `sharp.png({ compressionLevel: 9 })` — PNG is required for alpha channel support in the overlay engine's multiply blend mode.
   - Ensure `media/logos/` directory exists.
   - Write to `media/logos/{key}.png`. Use the key as filename (sanitized: only alphanumeric, dash, underscore allowed — reject keys with other characters).
   - Call addLogo() to register. Set filePath to `media/logos/{key}.png`, defaultScale to 0.25, defaultBlendMode to 'multiply', defaultOpacity to 0.88.
   - Return the LogoRegistryEntry.

Export all 5 new functions. Keep all existing functions unchanged.

**Key constraints:**
- Key validation: `/^[a-zA-Z0-9_-]+$/` — reject anything else with clear error message.
- File size: Sharp will handle any size, but the API layer (Plan task 2) should reject files over 10MB before passing to this function.
- The processLogoUpload function should NOT catch errors — let them bubble up to the API handler for consistent error responses.

Add three new API endpoints to the preview server for logo management:

**1. POST /api/logos/upload — Multipart file upload**

Since the server uses raw `http.createServer` (no Express/multer), implement a minimal multipart parser:

- Read the raw request body as a Buffer (NOT string). Add a new `readRawBody(req)` function that collects chunks into a Buffer, with a 10MB size limit (reject with 413 if exceeded).
- Parse the `Content-Type` header to extract the multipart boundary string.
- Parse the multipart body manually: split on boundary, extract each part's Content-Disposition headers (name, filename) and content. Need to handle binary data correctly — split on boundary bytes, not string.
- Alternative simpler approach: Since this is a single-file upload with metadata, accept a simpler protocol — the file as the raw request body with metadata in query parameters or custom headers. Use:
  - `X-Logo-Key` header: the registry key name
  - `X-Logo-Display-Name` header: display name
  - `Content-Type`: the file's MIME type
  - Request body: raw binary file data
  This avoids multipart complexity entirely while the UI can use `fetch()` with the raw file body.
- Call `processLogoUpload(buffer, originalFilename, key, displayName)` from overlay.ts.
- Return `sendJson(res, 200, { ok: true, logo: { key, entry } })`.
- Error handling: catch errors from processLogoUpload and return `sendJson(res, 200, { ok: false, error: message })` (consistent with existing API error pattern using 200 status).

**2. PUT /api/logos/:name — Update logo metadata**

- Parse JSON body with `readBody()`.
- Accept: `{ displayName?, defaultScale?, defaultOpacity?, defaultBlendMode? }`.
- Call `updateLogo(name, updates)`.
- Return updated entry.

**3. DELETE /api/logos/:name — Remove a logo**

- Call `removeLogo(name, true)` (delete file too).
- Return `sendJson(res, 200, { ok: true })`.

**Route registration in parseRoute():**

Add route matching for:
- `/api/logos/upload` → `{ route: 'logos-upload' }`
- `/api/logos/:name` → `{ route: 'logos-manage', param: name }` (for PUT and DELETE)

Place these BEFORE the existing `/api/logos` match to avoid the more general route catching them. The existing GET /api/logos route continues to work unchanged.

**Import the new functions** from overlay.ts: `addLogo`, `updateLogo`, `removeLogo`, `processLogoUpload`, `saveLogoRegistry`.

**readRawBody implementation:**
```
function readRawBody(req, maxBytes = 10 * 1024 * 1024): Promise<Buffer> {
  return new Promise((resolve, reject) => {
    const chunks: Buffer[] = [];
    let size = 0;
    req.on('data', (chunk) => {
      size += chunk.length;
      if (size > maxBytes) {
        req.destroy();
        reject(new Error('File too large (max 10MB)'));
        return;
      }
      chunks.push(chunk);
    });
    req.on('end', () => resolve(Buffer.concat(chunks)));
    req.on('error', reject);
  });
}
```
