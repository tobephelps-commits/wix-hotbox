<task type="auto">
  <name>Task 1: Build logo upload and library management UI</name>
  <files>scripts/pipeline/preview.html</files>
  <action>
Add a "Logo Library" section to preview.html, positioned logically near the existing logo overlay controls (before or as a collapsible section above the angle cards area). The section has two parts: upload area and logo grid.

**Upload Area:**
- A drop zone area (~200px tall) with dashed border, centered icon and "Drop logo here or click to browse" text. Style with the existing dashboard color scheme (use existing CSS variables/colors from the file).
- Hidden `<input type="file" accept="image/png,image/jpeg,image/webp,image/gif">` triggered by clicking the drop zone.
- Drag-and-drop support: dragenter/dragover/dragleave/drop events on the zone. Highlight border color on dragover.
- On file selection (drop or browse): show a brief inline form for metadata:
  - **Key** (auto-generated from filename by lowercasing, replacing spaces/dots with dashes, stripping non-alphanumeric-dash-underscore chars) — editable text input
  - **Display Name** (auto-generated from filename without extension, title-cased) — editable text input
  - **Preview thumbnail** of the selected file using FileReader + createObjectURL
  - **Upload button** — sends to POST /api/logos/upload with raw body and headers
- Show upload progress state: "Uploading..." spinner during fetch, success message with thumbnail on completion, error message on failure.
- After successful upload, refresh the logo grid AND the logo selector dropdown(s) in the angle cards.

**Logo Library Grid:**
- Fetch logos from GET /api/logos on page load and whenever a logo is uploaded/deleted.
- Display as a responsive grid (3-4 columns on desktop, 2 on mobile) of logo cards.
- Each card shows:
  - Thumbnail image loaded via `/api/logo-file/{key}` (existing endpoint from Phase 23)
  - Display name (bold)
  - Key in monospace small text
  - Default scale/opacity as subtle metadata
  - **Edit button** (pencil icon) — inline editing of displayName, defaultScale, defaultOpacity. Save via PUT /api/logos/:name.
  - **Delete button** (trash icon) — confirmation dialog ("Delete {displayName}? This cannot be undone."), then DELETE /api/logos/:name. On success, remove card from grid and refresh logo selectors.
- Empty state: when no logos exist, show a message "No logos uploaded yet. Drop a logo above to get started."

**Logo selector refresh:**
- After any CRUD operation, re-populate the logo selector `<select>` elements in the angle overlay cards. The existing code populates these on product fetch — extract that logic into a reusable `refreshLogoSelectors()` function that can be called after upload/delete too.
- Preserve current selection when refreshing if the selected logo still exists.

**Styling:**
- Match existing preview.html styling patterns — same font, colors, card styling, button styling.
- Upload zone: dashed border, subtle background, hover/active states.
- Logo cards: similar to existing product color cards or order cards in the dashboard — consistent visual language.
- Use CSS grid for the logo library layout.
- Mobile responsive: stack to 2 columns below 700px.

**Error handling:**
- File type validation in browser before upload (check file.type starts with 'image/')
- File size validation in browser (reject > 10MB with user-friendly message)
- API error responses displayed inline (not alert())
