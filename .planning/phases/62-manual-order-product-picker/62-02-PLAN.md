   ```typescript

     color: string;
     size: string;
     quantity: number;
     unitPrice: number;

   }
   ```

   ```typescript

   ```

3. **Add "Browse Catalog" button** next to the existing "+ Add Item" button in the Line Items section. Style it as a primary-ish button (distinct from "Add Item" which is for manual entry).

4. **Handle picker result:** When `onPick` fires from ProductPicker:
   - Create a new FormLineItem from the PickedProduct fields
   - Append to items array
   - Close the picker modal
   - The new item should be fully populated (productName, vendorStyle, color, size, unitPrice, vendor, imageUrl)

5. **Enhanced line item display:** For each line item card in the items list:
   - If `imageUrl` is present, show a 48x48 thumbnail on the left side of the item card
   - If `vendor` is present, show a small vendor badge (e.g., "SanMar" or "S&S") next to the vendor style field
   - Picker-sourced items still have all fields editable (user can adjust qty, price, etc.)
   - Manual items (no imageUrl) display exactly as before (no visual regression)

6. **Include vendor and imageUrl in submission body:** Update the submit handler to include vendor and imageUrl in the items array sent to POST /api/orders. These fields are already supported by the CreateOrderInput type (OrderLineItem has vendor and imageUrl optional fields).
