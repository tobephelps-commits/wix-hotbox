  <files>scripts/orders/production-sheet.ts</files>
  <action>
Create a PDFKit-based production sheet generator following invoice-generator.ts patterns.

The production sheet PDF should contain:

1. **Header section** (similar to invoice header):
   - HotBox Clothing logo top-left
   - "PRODUCTION SHEET" title top-right in brand color
   - Order # and date below title

2. **Order summary** (below header):
   - Customer name (order.customer.firstName + lastName)
   - Collection/brand if present (order.collection)
   - Total item count (sum of all line item quantities)

3. **For each unique product in order.lineItems** (grouped by vendorStyle):
   - Product name and style number (e.g., "Port & Company PC61 Essential Tee")
   - Product image (from lineItem.imageUrl if available)
   - Logo placement visual if logo data exists (see below)
   - Quantities table: Color | Size | Qty columns

4. **Logo placement visual** (key differentiator from invoice):
   - If the order has a collection field that matches a customer in customers.json,
     AND that customer has logoKeys, show a small logo placement diagram
   - Use position presets from data/logos.json to indicate placement area
   - Simple visual: product silhouette outline with logo position marker
   - If no logo data available, skip this section

**Implementation details:**
- Export generateProductionSheet(order: Order): Promise<Buffer>
- Export saveProductionSheet(order: Order, outputPath?: string): Promise<string>
- Use PDFDocument from pdfkit with letter size
- Follow brand constants from invoice-template.ts (BRAND_COLOR, BRAND_NAME, etc.)
- Group line items by vendorStyle for consolidated product sections
- Fetch logo registry with loadLogoRegistry() from overlay.ts if needed

**Quantities table format:**
```
| Color           | Size | Qty |
|-----------------|------|-----|
| Jet Black       | L    | 12  |

| White           | M    | 6   |
```

  <action>
Add GET /api/orders/:id/production-sheet endpoint to preview-server.ts.

1. Import generateProductionSheet from orders index (near existing invoice/label imports)

2. Add route handler in the HTTP request handler, near the existing print-invoice/print-label endpoints:

```typescript
// GET /api/orders/:id/production-sheet - generate production sheet PDF
if (req.method === 'GET' && urlPath.match(/^\/api\/orders\/[^/]+\/production-sheet$/)) {
  const orderId = urlPath.split('/')[3];
  try {
    const order = await getOrderById(orderId);
    if (!order) {
      res.writeHead(404, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify({ error: 'Order not found' }));
      return;
    }

    const pdfBuffer = await generateProductionSheet(order);

    res.writeHead(200, {
      'Content-Type': 'application/pdf',
      'Content-Disposition': `inline; filename="PS-${order.orderNumber}.pdf"`,
      'Content-Length': pdfBuffer.length,
    });
    res.end(pdfBuffer);
  } catch (err) {
    const message = err instanceof Error ? err.message : String(err);
    res.writeHead(500, { 'Content-Type': 'application/json' });
    res.end(JSON.stringify({ error: message }));
  }
  return;
}
```

3. The endpoint returns the PDF inline for browser viewing/printing, similar to how invoice generation works.
