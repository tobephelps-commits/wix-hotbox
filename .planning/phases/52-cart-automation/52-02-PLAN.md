<task type="auto">
  <name>Task 1: Port SanMar cart filler</name>
  <files>src/orders/sanmar-cart-filler.ts</files>
  <action>
  Port `src/orders/sanmar-cart-filler.ts` from `scripts/orders/sanmar-cart-filler.ts`:

  Core function: `fillSanMarCart(db, request, credentials, options?)`:
  - Parameters: Database (for status updates), CartFillRequest, { username, password } web credentials, CartFillOptions
  - Returns: CartFillResult

  Browser automation flow:
  1. Launch chromium via playwright (headless from options, default true)
  2. `loginToSanMar(page, username, password)`:
     - Navigate to SanMar login page (https://www.sanmar.com/signin)
     - Fill email + password fields
     - Click submit button
     - Wait for redirect away from /signin (networkidle or URL change)
     - Throw on login failure (detect error messages)
  3. For each CartItem in request.items:
     - Navigate to product page: `https://www.sanmar.com/p/{vendorStyle}`
     - `selectColor(page, color)`: Multi-strategy selector:
       a. Color swatch: `[title*="${color}" i]`, `[aria-label*="${color}" i]`, `[data-color*="${color}" i]`
       b. Dropdown: `select` with option text matching color
       c. Button/link: `button:has-text("${color}")`, `a:has-text("${color}")`
     - `selectSize(page, size)`: Multi-strategy selector:
       a. Button/chip: `[data-size="${size}"]`, `button:has-text("${size}")`
       b. Dropdown: `select` with option matching size
       c. Label/radio: `label:has-text("${size}")`
     - `setQuantity(page, qty)`: Clear and type into quantity input
     - Click "Add to Cart" button, wait for cart confirmation or error
     - Wrap each item in try/catch for per-item error isolation
     - 500ms delay between operations (ACTION_DELAY constant)
     - 60s timeout per item (from options.timeout)
  4. Save browser storageState to temp file
  5. Close headless browser
  6. Return CartFillResult with itemResults and status determination:
     - All success → 'success'
     - Mix → 'partial'
     - All failed → 'failed'

  Helper: `markOrdersAsOrdered(db, result)`:
  - For successful/partial results, update source orders from 'new' → 'ordered'
  - Use updateOrderStatus from order-service.ts
  - Add note: "SanMar cart filled" with item count
  - Guard: only transition orders currently in 'new' status

  Key v2.0 adaptations:
  - Database parameter instead of file-based order store
  - Use order-service.ts updateOrderStatus for status transitions
  - Credentials from Config (not env vars directly)
  - No storageState handoff to headed browser in API mode (that's a CLI-only pattern) -- just return the result with checkoutUrl
  </action>
  <verify>npx tsc --noEmit --pretty 2>&1 | head -20</verify>
  <done>SanMar cart filler compiles, uses Playwright with multi-strategy selectors, per-item error isolation, Database parameter</done>
</task>
