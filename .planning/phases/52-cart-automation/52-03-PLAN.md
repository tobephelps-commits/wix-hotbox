<task type="auto">
  <name>Task 1: Add cart preview and fill endpoints</name>
  <files>src/routes/orders.ts</files>
  <action>
  Add cart automation endpoints to the existing orders route plugin in `src/routes/orders.ts`:

  **Cart Preview (read-only, safe to call anytime):**
  - GET /api/orders/cart/preview?vendor=sanmar|ss
    - Call buildCartFillRequest(db, vendor) from cart-consolidator
    - Return { items: CartItem[], orderCount: number, itemCount: number }
    - If no eligible orders, return { items: [], orderCount: 0, itemCount: 0 }
    - This lets the UI show what would be ordered before triggering automation

  **Cart Fill (triggers browser automation):**
  - POST /api/orders/cart/fill
    - Body: { vendor: 'sanmar' | 'ss', headless?: boolean }
    - Build CartFillRequest from eligible orders
    - If no items, return 400 { error: 'No eligible orders for cart fill' }
    - Extract web credentials from fastify.config (sanmarWebUsername/Password or ssWebUsername/Password based on vendor)
    - If credentials missing (empty string), return 400 { error: 'Web credentials not configured for {vendor}' }
    - Call fillSanMarCart or fillSSCart based on vendor
    - On success/partial: call markOrdersAsOrdered/markSSOrdersAsOrdered to transition orders
    - Return CartFillResult (status, itemResults, checkoutUrl)
    - Log errors to order_errors table with operation='cart-fill' for any failed items

  **Important:** Route cart/* endpoints BEFORE parameterized :id routes (same pattern as bulk/* in orders.ts) to prevent "cart" matching as an order ID.

  **Error handling:**
  - Playwright launch failures: return 500 with descriptive error
  - Login failures: return 401 { error: 'Vendor login failed', details: message }
  - Individual item failures captured in CartFillResult.itemResults (not thrown)
  </action>
  <verify>npx tsc --noEmit --pretty 2>&1 | head -20</verify>
  <done>Cart preview and fill endpoints added, routed before :id params, credentials validated, errors logged to order_errors</done>
</task>
