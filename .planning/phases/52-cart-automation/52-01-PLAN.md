<task type="auto">
  <name>Task 1: Port cart types and consolidation logic</name>
  <files>src/orders/cart-types.ts, src/orders/cart-consolidator.ts</files>
  <action>
  Port `src/orders/cart-types.ts` from `scripts/orders/cart-types.ts`:
  - `CartItem`: vendorStyle, color, size, quantity, sourceOrders (number[]), productName
  - `CartFillRequest`: items (CartItem[]), orderNumbers (number[]), createdAt (ISO string)
  - `CartItemResult`: item (CartItem), success (boolean), error? (string)
  - `CartFillResult`: request (CartFillRequest), status ('success'|'partial'|'failed'), itemResults (CartItemResult[]), checkoutUrl? (string), completedAt (ISO string)
  - `CartFillOptions`: headless? (boolean, default true), slowMo? (number), timeout? (number, default 60000)
  - Import VendorId from `../vendors/types.js` -- add vendor field to CartItem

  Port `src/orders/cart-consolidator.ts` from both `scripts/orders/cart-consolidator.ts` and `scripts/orders/ss-cart-consolidator.ts`:
  - Combine both vendor consolidators into a single vendor-agnostic module
  - `getOrdersForCartFill(db, vendor?, filter?)`: Query orders from SQLite using listOrders(db, { status: 'new' }) from order-service, then filter by vendor. Return Order[] with line items.
  - `consolidateOrders(orders, vendor?)`: Group line items by vendorStyle:color:size key, sum quantities, track sourceOrders array. If vendor specified, only include items matching that vendor. Sort by vendorStyle, then color, then size.
  - `buildCartFillRequest(db, vendor?)`: Convenience that calls getOrdersForCartFill + consolidateOrders, returns CartFillRequest.
  - Key adaptation: v1.x loaded orders from JSON files; v2.0 reads from SQLite via order-service.ts functions. Use Database parameter.
  </action>
  <verify>npx tsc --noEmit --pretty 2>&1 | head -20</verify>
  <done>Cart types defined, consolidation works with SQLite orders, vendor-agnostic with optional vendor filter</done>
</task>
