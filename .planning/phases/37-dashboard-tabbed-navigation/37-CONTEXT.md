# Phase 37: Dashboard Redesign - Tabbed Navigation - Context

**Gathered:** 2026-02-04
**Status:** Ready for planning

<vision>
## How This Should Work

The current dashboard transforms into a sidebar-navigated application. A compact vertical nav on the left side with icons and labels provides access to the main sections: Products, Orders, Inventory, Customers. Clicking a nav item instantly switches the content area without page reloads.

The sidebar stays slim to maximize the content area while remaining clearly readable. This gives the dashboard a proper app-like feel rather than a single scrolling page.

</vision>

<essential>
## What Must Be Nailed

- **Clear organization** — Each section (Products, Orders, Inventory, Customers) has its own dedicated space. No more scrolling past unrelated content to find what you need.
- **Quick switching** — Navigate between sections instantly. No page reloads, no waiting.
- **Visual clarity** — Modern, professional look that's easy to scan and understand at a glance.

</essential>

<specifics>
## Specific Ideas

- Continue the existing dark theme aesthetic from the current dashboard
- Badge counts on navigation items showing what needs attention (e.g., orders waiting, low stock alerts)
- Compact sidebar with icons + short labels to maximize content area

</specifics>

<notes>
## Additional Context

This is foundational UX work that sets up the structure for subsequent phases. The Orders tab will be enhanced further in Phase 40 (Order Status Dashboard). The tabbed structure provides homes for existing features while making room for new capabilities.

</notes>
