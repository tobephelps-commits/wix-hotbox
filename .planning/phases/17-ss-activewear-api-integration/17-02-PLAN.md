**scripts/ss-activewear/client.ts** — REST client:
- `ssGet<T>(path: string, params?: Record<string, string>): Promise<T>` — core GET function:
  1. Calls `ssRateLimiter.acquire()` before each request
  2. Builds URL from SS_API_BASE_URL + path
  3. Appends query params
  4. Sets headers: Authorization (from buildAuthHeader()), Accept: application/json
  5. Uses native `fetch()`
  6. Logs `X-Rate-Limit-Remaining` header when < 10
  7. On !response.ok: classifies error with classifySSError, wraps in SSError
  8. On 404: returns empty array (not found is not exceptional for queries)
  9. Returns response.json() as T
- Export retry wrapper: `ssGetWithRetry<T>(path, params, maxRetries = 3)` — retries on retryable errors with exponential backoff (1s, 2s, 4s). Adapt pattern from scripts/sanmar/utils/retry.ts.

**scripts/ss-activewear/services/product.ts** — Product queries:
- `getSSProductsByStyle(style: string): Promise<SSProduct[]>` — GET /v2/products/?style={style}
- `getSSProductBySku(sku: string): Promise<SSProduct[]>` — GET /v2/products/{sku}
- `getSSProductsByBrand(brand: string): Promise<SSProduct[]>` — GET /v2/products/?style={brand}
- `extractSSUniqueColors(products: SSProduct[]): { colorName: string; colorCode: string }[]` — unique colors from flat product array
- `extractSSAvailableSizes(products: SSProduct[]): string[]` — unique sizes sorted by sizeOrder
- `resolveSSImageUrl(relativePath: string | null, size?: 'fl' | 'fm' | 'fs'): string | null` — prepends SS_IMAGE_BASE_URL, replaces _fm suffix with requested size (default: 'fl' for large)

**scripts/ss-activewear/services/inventory.ts** — Inventory queries:
- `getSSStyleInventory(style: string): Promise<SSInventoryItem[]>` — GET /v2/inventory/?style={style} (lighter than full products, for monitoring)
- `getSSInventoryBatch(skus: string[]): Promise<SSInventoryItem[]>` — GET /v2/inventory/{sku1,sku2,...} (comma-separated, for batch polling)
- `getSSTotalQuantity(item: SSInventoryItem): number` — sum warehouse qty
- `isSSInStock(item: SSInventoryItem, minQty?: number): boolean`

**scripts/ss-activewear/services/styles.ts** — Style metadata:
- `getSSStyleInfo(style: string): Promise<SSStyle[]>` — GET /v2/styles/?style={style} (gets title, description, categories)
- `searchSSStyles(query: string): Promise<SSStyle[]>` — GET /v2/styles?search={query}

Follow existing SanMar pattern: services are exported via index.ts barrel, client internals hidden.
