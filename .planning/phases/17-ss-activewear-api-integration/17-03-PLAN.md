  <files>scripts/sanmar/adapter.ts</files>
  <action>
Create `scripts/sanmar/adapter.ts` that implements VendorAdapter by wrapping existing SanMar functions.

The adapter does NOT modify any existing SanMar code. It imports from `../sanmar/index.js` and maps results to unified types from `../vendor/types.js`.

**Mapping functions (private, not exported):**

1. `mapSanMarProduct(product: ProductInfo): UnifiedProduct` — maps:
   - vendor: 'sanmar'
   - brandName: product.productBasicInfo.brandName
   - style: product.productBasicInfo.style
   - productTitle: product.productBasicInfo.productTitle
   - description: product.productBasicInfo.productDescription
   - color: product.productBasicInfo.color
   - colorCode: product.productBasicInfo.catalogColor
   - size: product.productBasicInfo.size
   - sizeOrder: product.productBasicInfo.sizeIndex
   - category: product.productBasicInfo.category
   - pieceWeight: product.productBasicInfo.pieceWeight
   - status: product.productBasicInfo.productStatus
   - caseQty: parseInt(product.productBasicInfo.caseSize) || undefined

2. `mapSanMarPricing(pricing: PricingInfo): UnifiedPricing` — maps:
   - vendor: 'sanmar'
   - piecePrice: pricing.piecePrice
   - casePrice: pricing.casePrice
   - salePrice: pricing.pieceSalePrice > 0 ? pricing.pieceSalePrice : null
   - saleExpiration: pricing.saleEndDate (already ISO or null)
   - priceCode: pricing.priceCode

3. `mapSanMarInventory(sku: SkuInventory, style: string): UnifiedInventory` — maps:
   - vendor: 'sanmar'
   - style
   - color: sku.color
   - size: sku.size
   - totalQty: sum of sku.whse[].qty
   - warehouses: sku.whse.map(w => ({ id: String(w.whseID), name: w.whseName, qty: w.qty }))

4. `mapSanMarMedia(media: MediaContent): UnifiedMedia` — maps:
   - vendor: 'sanmar'
   - color: media.color
   - Map classType IDs to fields: 1007→frontImage, 1008→backImage, etc.
   - Note: SanMar MediaContent is one item per image, not one per color. Group by color first, then map. Use helper to aggregate multiple MediaContent items for the same color into one UnifiedMedia.

**SanMarAdapter class implementing VendorAdapter:**

- `vendorId: 'sanmar'`
- `vendorName: 'SanMar'`
- `getProductsByStyle(style)` — calls getProductByStyle(style), maps each result
- `getStylePricing(style)` — calls getStylePricing(style), wraps single PricingInfo into array (SanMar returns style-level pricing, not per-SKU)
- `getStyleInventory(style)` — calls getStyleInventory(style), maps each SkuInventory
- `getProductImages(style)` — calls getProductImages(style), groups by color, maps to UnifiedMedia[] (one entry per color)
- `fetchAllProductData(style)` — runs all 4 in parallel with Promise.allSettled (same graceful degradation as existing fetchProductData). Returns UnifiedProductData.
- `validateCredentials()` — calls existing validateCredentials()

Export the adapter instance and register it:
```typescript
export const sanmarAdapter = new SanMarAdapter();
```

Do NOT modify scripts/sanmar/index.ts — add adapter.ts as a new file only. The adapter imports from the existing public API.
