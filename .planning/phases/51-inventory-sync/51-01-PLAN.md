<task type="auto">
  <name>Task 1: Create monitoring migration and port types</name>
  <files>src/db/migrations/003-inventory-monitoring.sql, src/monitor/types.ts</files>
  <action>
  Create SQLite migration `003-inventory-monitoring.sql` with tables:

  1. `tracked_products` table:
     - id INTEGER PRIMARY KEY AUTOINCREMENT
     - style TEXT NOT NULL
     - name TEXT NOT NULL
     - vendor TEXT NOT NULL DEFAULT 'sanmar' (VendorId)
     - colors TEXT (JSON array, nullable)
     - sizes TEXT (JSON array, nullable)
     - priority TEXT NOT NULL DEFAULT 'normal' (hot/normal/slow)
     - low_stock_threshold INTEGER (nullable, per-product override)
     - critical_stock_threshold INTEGER (nullable, per-product override)
     - out_of_stock_threshold INTEGER (nullable, per-product override)
     - last_polled_at TEXT (nullable ISO timestamp)
     - added_at TEXT NOT NULL DEFAULT (datetime('now'))
     - UNIQUE(style, vendor)

  2. `inventory_snapshots` table:
     - id INTEGER PRIMARY KEY AUTOINCREMENT
     - style TEXT NOT NULL
     - vendor TEXT NOT NULL DEFAULT 'sanmar'
     - timestamp TEXT NOT NULL DEFAULT (datetime('now'))
     - data TEXT NOT NULL (JSON blob of SkuSnapshot[])
     - UNIQUE(style, vendor) -- only latest snapshot kept per style+vendor

  3. `alerts` table:
     - id INTEGER PRIMARY KEY AUTOINCREMENT
     - type TEXT NOT NULL (out-of-stock/critical/low-stock/back-in-stock)
     - style TEXT NOT NULL
     - product_name TEXT NOT NULL
     - vendor TEXT NOT NULL DEFAULT 'sanmar'
     - color TEXT NOT NULL
     - size TEXT NOT NULL
     - previous_qty INTEGER NOT NULL
     - current_qty INTEGER NOT NULL
     - warehouse_detail TEXT (nullable JSON blob)
     - acknowledged INTEGER NOT NULL DEFAULT 0
     - created_at TEXT NOT NULL DEFAULT (datetime('now'))

  Add indexes: alerts(style, vendor), alerts(created_at), tracked_products(priority).

  Port `src/monitor/types.ts` from `scripts/monitor/types.ts`:
  - Import VendorId from `../vendors/types.js`
  - Keep all interfaces: PollPriority, MonitorConfig, TrackedProduct, InventorySnapshot, SkuSnapshot, WarehouseQuantity, StockAlert, AlertWarehouseDetail
  - MonitorConfig: remove `dataDir` field (v2.0 uses SQLite, not file paths)
  - Add `MonitorThresholds` type extracted from the threshold fields for reuse
  </action>
  <verify>npx tsc --noEmit --pretty 2>&1 | head -20 (types compile)</verify>
  <done>Migration file exists, types compile with no errors, MonitorConfig adapted for SQLite</done>
</task>
