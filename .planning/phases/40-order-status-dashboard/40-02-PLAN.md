<task type="auto">
  <name>Task 3: Add pipeline visualization JavaScript</name>
  <files>scripts/pipeline/preview.html</files>
  <action>
Add JavaScript functions in the script block for pipeline visualization:

1. **`loadOrderPipelineData()`**:
   - Fetch `/api/orders/summary/extended`
   - Store result in `_pipelineData` variable
   - Call `renderPipeline()` and `renderAttentionBar()`

2. **`renderPipeline(data)`**:
   - Get container `#pipelineStages`
   - For each active status [new, ordered, received, in-production, packed, shipped]:
     - Create stage card with:
       - Status name header
       - Order count badge
       - Metrics (items, value, oldest age)
       - Aging indicator bar
       - Attention badge if applicable (from data.attention)
     - Click handler filters order list to that status

3. **`renderAttentionBar(data)`**:
   - Get container `#attentionBar`
   - Build chips for each attention type with non-zero count:
     - `cartFillPending`: "X ready to order" (blue)
     - `stuckInProduction`: "X stuck in production" (orange)
     - `awaitingShipment`: "X awaiting shipment" (yellow)
     - `unresolvedErrors`: "X with errors" (red)
   - Each chip clickable to set appropriate filter
   - Hide bar if no attention items

4. **`formatHoursAgo(hours)`**:
   - Format hours as human-readable: "2h", "1d 4h", "3d"

5. **`formatCurrency(amount)`**:
   - Format as "$1,234.56"

6. **Update `loadOrders()`**:
   - After loading orders, also call `loadOrderPipelineData()`

7. **Aging thresholds** (constants):
   ```javascript
   var AGING_THRESHOLDS = {
     'new': 48,           // 2 days
     'ordered': 72,       // 3 days
     'received': 48,      // 2 days
     'in-production': 72, // 3 days
     'packed': 24,        // 1 day
     'shipped': 120       // 5 days
   };
   ```

8. **Stage click handler**:
   - Set `_orderStatusFilter` to clicked status
   - Update filter pills UI (deactivate all, don't activate any since single-status)
   - Call `renderOrderList(_ordersCache)`
  </action>
