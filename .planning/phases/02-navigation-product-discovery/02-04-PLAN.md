<objective>
Add search functionality and product filtering/sorting to the store so customers can find specific products without scrolling through every page.

Purpose: The store has 105 products across 10 collections with zero search, zero filtering, and zero sorting. A customer looking for "hoodie" or wanting to filter by price has no path forward. This plan adds the discovery tools that turn a static catalog into a searchable, filterable store.
Output: Working search on all pages, product filtering and sorting on category/collection pages.
</objective>

<task type="auto">
  <name>Task 1: Add site search functionality</name>
  <files>WIX site management via MCP</files>
  <action>
Add search capability to the store (NV-2). WIX has a built-in Site Search app.

1. **Enable WIX Site Search:** Use WIX MCP to:
   - Check if the WIX Site Search app is already installed (it may be among the 68+ installed apps)
   - If not installed, install the Wix Site Search app via MCP
   - If search cannot be installed via MCP, document the manual installation steps

2. **Add search to header:** Use WIX MCP to add a search bar or search icon to the site header/navigation area so it appears on every page. Options:
   - Search icon in the header bar (next to cart/login) — preferred, clean look
   - Search bar below navigation — more prominent but takes space
   - If header editing is not available via MCP, document the exact placement instructions

3. **Configure search:** Ensure search indexes:
   - Product names
   - Product descriptions
   - Collection names
   - Page titles/content

4. **Test search:** Use Playwright to:
   - Verify search icon/bar is visible on homepage
   - Search for "hoodie" — should return hoodie products
   - Search for "Big Barn" — should return Big Barn products or page
   - Search for a nonexistent term — should show "no results" gracefully

If WIX MCP cannot install or configure the search app, provide detailed manual instructions and verify the steps are accurate.
  </action>
  <verify>
- Navigate to homepage — search icon or search bar is visible
- Type "hoodie" into search — relevant products appear in results
- Type "tank" into search — relevant products appear
- Type "xyznotfound" — graceful "no results" message
- Search is visible on at least homepage and Shop All page
  </verify>
  <done>
- Search functionality is available on the site
- Search returns relevant products when queried
- Search is accessible from the header on all pages
  </done>
</task>

<task type="auto">
  <name>Task 2: Add product filtering and sorting to collection pages</name>
  <files>WIX site management via MCP</files>
  <action>
Add filtering and sorting controls to product listing pages (NV-3).

1. **Enable WIX product filters:** WIX Stores has built-in product filter and sort functionality that can be enabled on gallery pages. Use WIX MCP to:
   - Enable product filtering on the "Shop All" page (created in Plan 02-03)
   - Enable product filtering on each client collection page (Big Barn, Board 30, AIM, UNMH, Fun Shirts)
   - If filtering requires specific gallery widget settings, configure them via MCP

2. **Filter categories to enable:**
   - Price range filter (slider or min/max)
   - Collection/category filter (on Shop All page)
   - If WIX supports it: size filter, color filter
   - Sort options: Price (low to high), Price (high to low), Newest, Name (A-Z)

3. **Implementation approach:**
   - WIX product gallery widgets have built-in filter/sort options that need to be enabled in the widget settings
   - Use WIX MCP to access gallery widget settings and toggle filter/sort controls ON
   - If MCP cannot modify widget settings, document the exact steps in WIX Editor (click gallery → Settings → Filters → enable)

4. **Special case — Fun Shirts:** This page has 14 products, most with 32 color options. Filtering by color at the gallery level could help reduce the overwhelming option display.

If filtering/sorting configuration is not available via MCP, provide detailed WIX Editor instructions with exact settings paths for each page.
  </action>
  <verify>
- Navigate to Shop All page — filter controls visible (price, collection, etc.)
- Apply price filter — products filter correctly
- Apply sort (price low to high) — products reorder correctly
- Navigate to Big Barn page — filter/sort controls visible
- Navigate to Fun Shirts page — filter controls visible
  </verify>
  <done>
- Product filtering enabled on Shop All page and all collection pages
- At minimum: price filter and sort options functional
- Products correctly filter and sort when controls are used
  </done>
</task>
