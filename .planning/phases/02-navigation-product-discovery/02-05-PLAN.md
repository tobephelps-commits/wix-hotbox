<task type="auto">
  <name>Task 1: Add related products to product detail pages</name>
  <files>WIX site management via MCP</files>
  <action>
Add cross-selling sections to product detail pages (NV-6).

1. **WIX Related Products:** WIX Stores has a built-in "Related Products" widget that can be added to the product page template. Use WIX MCP to:
   - Add the WIX Related Products widget to the product page layout
   - Configure it to show 4-6 related products below the main product info
   - Related products should be from the same collection as the current product (e.g., a Big Barn product shows other Big Barn items)

2. **If WIX MCP can modify product page template:**
   - Add a "You Might Also Like" section below the product description / social sharing icons
   - Use the Wix Stores "Related Products" or "Product Slider" widget
   - Position it above the footer

3. **If WIX MCP cannot modify product page templates:**
   - Document the exact steps to add Related Products in WIX Editor:
     - Open WIX Editor → Product Page → Add Section → Wix Stores → Related Products
     - Configure: Show 4-6 products, from same collection, grid or slider layout
   - This is a common WIX feature that should be straightforward to enable

4. **Also consider:** WIX may have an "Also Bought" or algorithmic recommendation widget. If available, enable it. Otherwise, same-collection related products is a solid default.
  </action>

- Click a related product — should navigate to that product's detail page
  </verify>

  <name>Task 2: Standardize product gallery layout across collection pages</name>

  <action>
Normalize gallery layouts across all collection pages (CL-3, CK-4).

**Current state:**
- Board 30: Has "Add to Cart" buttons visible in gallery (best UX)
- Big Barn: Two sections — product grid + graphics slider carousel
- Artistry in Motion, UNMH, Fun Shirts, Fall PreOrder: Simple grid, no Add to Cart, requires clicking into product page

**Target state:**
All collection pages should have a consistent gallery experience:
1. Product grid with consistent layout (image, name, price)
2. "Add to Cart" or "Quick View" button visible on hover (not just Board 30)
3. If WIX supports it, enable "Quick Add" across all gallery pages so customers can add to cart without leaving the listing page

**Implementation:**
1. Use WIX MCP to check the gallery widget settings on Board 30 page (the one with Add to Cart buttons)
2. Replicate those settings to other collection pages (Big Barn, AIM, UNMH, Fun Shirts, Shop All)
3. If gallery settings are per-widget and cannot be copied via MCP, document the settings for manual replication

**Special case — Big Barn Graphics section:**
- The 22 "graphics" items ($1-$10 each) are add-on decoration services, not standalone products
- Consider: Should these remain in the Big Barn gallery? Or be separated into a distinct section?
- Recommendation: Keep them as a separate section below clothing but label them clearly as "Add-On Graphics" or "Customize Your Order"
- If this requires page layout changes beyond MCP capability, document the recommendation

If gallery widget configuration is not available via MCP, document the exact WIX Editor steps for each page.
