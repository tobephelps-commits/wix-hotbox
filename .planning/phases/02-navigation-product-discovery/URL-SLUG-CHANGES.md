## Why This Matters

All non-product pages use WIX default slugs (`/shop-1`, `/blank-2`, etc.) which:
- Hurt SEO -- search engines prefer descriptive URLs
- Look unprofessional in the browser address bar
- Make navigation impossible by URL alone
- Give no context about page content

- `/gift-card` -- already descriptive
- `/product-page/{slug}` -- product pages use auto-generated slugs from product names; changing risks breaking external links

## Manual Instructions (WIX Editor)

### For Each Page:

1. Go to https://manage.wix.com/dashboard/c744cbdb-46f8-4c66-ac76-eb31bd0d52c1/website/site-pages
2. Click on the page name in the left panel
3. Click the three-dot menu (...) next to the page name
4. Select **SEO Basics** (or **Page Settings** > **SEO**)
5. In the **URL slug** field, change from the old slug to the new slug
6. Click **Done** or **Save**
7. Repeat for all 9 pages

### Alternative Path (WIX Editor):
1. Open the WIX Editor for the site
2. Click **Pages & Menu** in the left panel
3. Click on each page
4. Click the three-dot menu > **SEO Basics**
5. Change the URL slug
6. Save and publish

### After All Changes:
1. **Publish the site** to make slug changes live
2. **Verify redirects:** WIX automatically creates 301 redirects from old slugs to new slugs
3. **Test each URL:** Visit both old and new URLs to confirm redirects work
4. **Check navigation:** Navigation links reference pages by ID (not slug), so they should auto-update

## MCP Limitation Details

**Investigated:** 2026-01-30
**APIs searched:**
- WIX REST API documentation -- no endpoint for page slug management
- Site Properties API -- covers business info, not page properties
- Site URLs API -- only for editor/preview/published URLs, not page slug editing
- SEO API -- only robots.txt and SEO tags, not page slugs
- Headless Redirects API -- only for headless site redirects, not page URL management

**Conclusion:** WIX does not expose site page slug editing through any REST API endpoint. This is a WIX Editor-only operation. The WIX MCP tools (which use REST APIs) cannot perform this change.
