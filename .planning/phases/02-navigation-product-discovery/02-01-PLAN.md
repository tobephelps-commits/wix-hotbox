<task type="auto">
  <name>Task 1: Disable or reposition chat widget and fix broken LMNT products</name>
  <files>WIX site management via MCP</files>
  <action>
1. **Chat widget (CR-2, QW-1):** Use WIX MCP to disable or reposition the "Let's Chat!" Wix Chat widget. The chat widget's popover-element div intercepts pointer events on product option selectors (color swatches, size dropdowns), physically preventing customers from configuring and purchasing products. Options in order of preference:
   - Disable the Wix Chat app entirely via MCP site management (preferred — the store has email + support form already)
   - If disabling is not possible via MCP, reposition the widget to a non-blocking location or minimize its z-index behavior
   - Document what was done and any limitations of the MCP approach

2. **Broken LMNT products (CR-4, QW-5):** Both LMNT product pages return 404:
   - `/product-page/element-electrolyte-drink-mix-sample-pack`
   - `/product-page/lmnt-zero-sugar-electrolytes-30-count-citrus-salt`
   Products exist in API but storefront pages are broken. These are pickup-only drink products, not clothing.
   - Use WIX MCP to either: (a) hide/archive both LMNT products so they don't appear in navigation or search, or (b) delete them if the owner wants a clothing-only store.
   - If hiding: also remove the "Shop" nav link (currently in "More" dropdown) that points to `/shop-5` which only showed these 2 products.
   - Prefer hiding over deleting (reversible).

Do NOT use the Wix Chat widget's browser-based editor. Use only WIX MCP API calls for all changes.
  </action>

  </verify>
