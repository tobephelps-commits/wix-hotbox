<task type="auto">
  <name>Task 2: Fix breadcrumbs, image alt text, homepage H1, and footer</name>
  <files>WIX site management via MCP</files>
  <action>
Fix 4 categories of issues:

1. **Breadcrumb collection assignments (QW-6):** Products show incorrect collection names in breadcrumbs (e.g., Big Barn product shows "Fall PreOrder" breadcrumb). This is caused by WIX using the first collection a product belongs to for breadcrumbs.
   - Use WIX MCP to reorder collection assignments on affected products so the correct/primary collection appears first
   - Focus on products that are in multiple collections (Big Barn + PreOrder, etc.)
   - If collection order cannot be changed via API, document the limitation

2. **Homepage image alt text (AC-1):** 25/28 homepage images have empty alt text. Fails WCAG 2.1 Level A.
   - Use WIX MCP to add descriptive alt text to homepage images where possible
   - Product images: Use product name as alt text (e.g., "BELLA+CANVAS Triblend Tee - Big Barn Crossfit")
   - Logo: "Hot Box Clothing Logo"
   - Decorative images: mark as decorative (alt="") if truly decorative, or add description
   - If homepage content editing is not available via MCP, document which images need alt text updates

3. **Homepage H1 (AC-2):** No H1 on homepage. Heading hierarchy starts at H2.
   - Use WIX MCP to change the "Hot Box Clothing" H2 heading to H1
   - Or add a proper H1 element if the current H2 serves a different purpose
   - If heading level changes require WIX Editor, document the fix needed

4. **Footer navigation (AC-3):** Footer has only an email link and outdated copyright. No secondary navigation.
   - Use WIX MCP to add footer links: Home, Shop All (after Plan 02-03 creates it), Contact, Support, Store Policies
   - Add social media links if the business has social accounts (check homepage for any social references)
   - If footer editing is not available via MCP, document the ideal footer structure for manual implementation

For each fix, attempt via WIX MCP first. Document any limitations and provide manual fix instructions where MCP cannot reach.
  </action>
  <verify>
- Navigate to a product that was in multiple collections — breadcrumb should show correct primary collection
- Navigate to homepage — check image alt attributes via Playwright accessibility snapshot
- Navigate to homepage — check heading hierarchy (should have H1)
- Check footer on any page — should have navigation links
  </verify>
  <done>
- Breadcrumb collection assignments corrected for multi-collection products
- Homepage images have descriptive alt text (or documented for manual fix)
- Homepage has proper H1 heading (or documented for manual fix)
- Footer has navigation links (or documented for manual fix)
  </done>
</task>
