<task type="auto">
  <name>Task 2: Restructure navigation hierarchy for customer-centric browsing</name>
  <files>WIX site management via MCP</files>
  <action>
Reorganize the main navigation to prioritize product discovery over client business names (NV-1, NV-4).

**Target navigation structure:**

```
Home | Shop All | Fun Shirts | [Client Pages ▼] | Gift Card | Contact | Support
                                |-- Big Barn Crossfit
                                |-- Artistry in Motion
                                |-- Board 30
                                |-- UNMH
                                |-- Pre-Order
```

**Key changes:**
1. **Promote "Shop All"** to main nav bar (position 2, right after Home) — this becomes the primary browsing entry point
2. **Keep "Fun Shirts"** in main nav — it's already category-based and useful
3. **Group client pages** under a dropdown labeled "Client Pages", "Custom Teams", or "Our Teams" — keeps them accessible but removes 5 individual business names from the main nav bar
4. **Move "Gift Card"** to main nav (was hidden in "More" dropdown)
5. **Move "Contact" and "Support"** to end of main nav or footer only (they occupy prime nav real estate)
6. **Remove "Store Policies"** from main nav — move to footer only (it's a utility page, not a shopping destination)
7. **Remove "Shop" link** from More dropdown (it pointed to LMNT page, now handled or removed)
8. **Remove or repurpose "Fall PreOrder"** — if the pre-order is still active, keep under client dropdown; if expired, hide it

**Implementation via WIX MCP:**
- Use WIX MCP site management to modify the navigation menu structure
- If WIX MCP supports menu editing: reorder, rename, and nest menu items as specified
- If WIX MCP does NOT support menu editing: document the exact changes needed and provide step-by-step WIX Editor instructions (Site Menu → drag/drop → rename)

**Constraints:**
- Do NOT delete any pages — only change their position in navigation
- Do NOT rename page titles — only change nav labels and menu structure
- Preserve all existing client pages at their (now renamed) URLs from Plan 02-02
