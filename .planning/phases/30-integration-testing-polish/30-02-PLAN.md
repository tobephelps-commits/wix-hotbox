**New workflow sections to add:**

### Multi-Angle Product Images
Explain the 3-angle image pipeline:
1. Front, back, and left-side images fetched automatically from vendor APIs
2. Preview server shows all 3 angles in product preview
3. Angles available for logo overlay placement
4. WIX product draft includes all available angles

### Logo Overlay Placement
Step-by-step for visual logo placement:
1. Open preview server at localhost:3456
2. Fetch a product — angle cards appear showing front/back/left images
3. Select a logo from the logo picker dropdown for each angle
4. Drag and drop logo to position it on the product image
5. Use alignment guides for centering (crosshairs snap to center)
6. Use keyboard arrow keys for fine-tuning (1px nudge)
7. Click "Apply Overlays" to composite logos onto product images
8. Logo placement coordinates saved with the product creation

### Logo Upload & Management
Step-by-step for managing logo library:
1. Open preview server Logos section
2. Drag and drop a PNG file onto the upload zone (or click to browse)
3. Image is validated and processed (Sharp: resize, format check)
4. Logo appears in the library grid with thumbnail preview
5. Click to edit metadata (name, default position)
6. CLI alternative: Add logo file to `media/logos/` and register in `data/logos.json`

### Customer Accounts & Royalties
Step-by-step for customer management:
1. Open preview server Customers section
2. Click "Add Customer" to create a new account
3. Set customer name, markup percentage, and royalty rate
4. Assign logo(s) from the logo library using chip picker
5. Customer pricing auto-calculates: wholesale + markup% = retail, retail × royalty% = royalty per unit
6. View royalty reports: select customer, date range
7. Download royalty statement PDF (branded, per-customer)
8. CLI: Customer data stored in `data/customers/customers.json`

### Batch Product Creation
Step-by-step for creating multiple products at once:
1. Open preview server Batch Create section
2. Enter multiple style numbers (comma or newline separated, up to 50)
3. Select vendor, pricing preset, and other settings (pre-filled from saved preferences)
4. Click "Start Batch" to begin creation
5. Live progress queue shows each product's status: queued → fetching → creating → done/error
6. Products are processed sequentially (respects vendor API rate limits)
7. Summary bar shows success/fail counts when complete
8. Note: Logo overlays are skipped in batch mode (require per-product visual positioning)

### Order Error Handling
Explain order management improvements:
1. Orders dashboard shows status summary cards (count per status, click to filter)
2. Sync health indicator shows last sync time with color-coded freshness
3. Error alert banner appears when orders have unresolved errors
4. Click "View errors" to see affected orders with operation type, message, retry count
5. Click "Mark Resolved" to clear resolved errors
6. WIX sync uses automatic retry with exponential backoff (2s, 4s, 8s) for transient failures
7. Orders support "on-hold" status for pausing/resuming fulfillment

### Inventory Reliability Tools
Explain inventory monitoring improvements:
1. Dashboard health cards show sync timing (Avg Tick, Max Tick), notification delivery, uptime
2. Alert feed supports filtering by type (out-of-stock, critical, low-stock, back-in-stock) and by product
3. Products can have per-product threshold overrides (shown as "Custom" badge with hover tooltip)
4. Stale inventory snapshots trigger amber warning with age display
5. "Run Audit" button validates all product mappings against WIX API
6. Audit results show orphaned mappings with one-click removal
7. CLI: `npm run monitor -- threshold STYLE low 15 critical 5` to set per-product thresholds

**Troubleshooting table — add v1.0 errors:**

| Error | Cause | Fix |
|-------|-------|-----|
| `No back/left images available` | Vendor doesn't provide all angles for this style | Normal — only front image is guaranteed; overlay those angles manually |
| `Logo file too large` | Upload exceeds size limit | Resize image before upload; Sharp handles most formats |
| `Customer not found` | Customer ID doesn't match any account | Check customer list in dashboard or data/customers/customers.json |
| `Batch limit exceeded (max 50)` | Too many style numbers entered | Split into batches of 50 or fewer |
| `Stale inventory snapshot` | Snapshot older than snapshotMaxAgeMinutes | Sync daemon may be stopped; run `npm run sync:start` |
| `Orphaned product mapping` | WIX product was deleted but mapping still exists | Run "Audit" in dashboard and click "Remove Orphans" |

**Key Behaviors — add:**

- **Multi-angle images.** Products automatically fetch front, back, and left-side images from vendors when available.
- **Visual logo placement.** Drag-and-drop interface with alignment guides. Coordinates are per-angle, per-product.
- **Customer markup.** Each customer has a single markup %. Royalty calculated on retail price, not wholesale.
- **Batch creation is sequential.** Respects vendor API rate limits. Up to 50 items per batch.
- **Preferences persist.** Form settings (vendor, preset, markup) save to localStorage and server backup.
- **Order errors are tracked.** Unresolved errors show in dashboard. Mark resolved when fixed.
- **Per-product thresholds.** Override global stock thresholds for specific products via CLI or API.
