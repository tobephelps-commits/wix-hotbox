Create `pi/systemd/hotbox-server.service` — the Node.js application server:
```ini
[Unit]
Description=HotBox Application Server
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=hotbox
Group=hotbox
WorkingDirectory=/home/hotbox/app
ExecStart=/usr/bin/node dist/server.js
Restart=always
RestartSec=5
StartLimitIntervalSec=60
StartLimitBurst=5
Environment=NODE_ENV=production
Environment=PORT=3456
EnvironmentFile=-/home/hotbox/app/.env
StandardOutput=journal
StandardError=journal
SyslogIdentifier=hotbox-server

# Security hardening
NoNewPrivileges=true
ProtectSystem=strict
ProtectHome=read-only
ReadWritePaths=/home/hotbox/app/data /home/hotbox/app/logs /tmp
PrivateTmp=true

[Install]
WantedBy=multi-user.target
```

Create `pi/systemd/hotbox-kiosk.service` — the Chromium kiosk display:
```ini
[Unit]
Description=HotBox Kiosk Display
After=hotbox-server.service
Wants=hotbox-server.service
ConditionPathExists=/dev/fb0

[Service]
Type=simple
User=hotbox
Group=hotbox
Environment=DISPLAY=:0
ExecStartPre=/bin/sleep 3
ExecStart=/usr/bin/startx /home/hotbox/.xinitrc -- -nocursor
Restart=always
RestartSec=10
StartLimitIntervalSec=120
StartLimitBurst=3
StandardOutput=journal
StandardError=journal
SyslogIdentifier=hotbox-kiosk

# TTY allocation for X11
TTYPath=/dev/tty1
PAMName=login

[Install]
WantedBy=graphical.target
```

Key design decisions:
- Server starts first, kiosk waits 3s then starts (ExecStartPre sleep ensures server is listening)
- Kiosk only starts if framebuffer exists (ConditionPathExists=/dev/fb0) — headless-safe
- Both restart on failure with rate limiting (5 restarts in 60s for server, 3 in 120s for kiosk)
- Server has security hardening (read-only filesystem except data/logs)
- Logs go to journald (accessible via `journalctl -u hotbox-server`)

Create `pi/systemd/install-services.sh`:
1. Source hotbox.conf
2. Copy service files to `/etc/systemd/system/`
3. Create symlink `/home/hotbox/.xinitrc` → `/home/hotbox/app/pi/kiosk/xinitrc`
4. `systemctl daemon-reload`
5. `systemctl enable hotbox-server.service`
6. `systemctl enable hotbox-kiosk.service`
7. Create data and logs directories with correct ownership
8. Print status of both services
9. Inform user to reboot to test auto-start

Script must run as root, be idempotent, use `set -euo pipefail`.

<task type="auto">
  <name>Task 2: Create boot resilience and power cycle protection</name>
  <files>pi/resilience/setup-readonly.sh, pi/resilience/setup-watchdog.sh</files>
  <action>
Create `pi/resilience/setup-readonly.sh` — protect against SD card corruption from power loss:

1. **tmpfs overlays for volatile paths:**
   - Mount `/tmp`, `/var/tmp` as tmpfs (already default, ensure it)
   - Mount `/var/log` as tmpfs with 50M limit (logs don't survive reboot — use journald persistent if needed)
   - Add to `/etc/fstab`:
     ```
     tmpfs /tmp tmpfs defaults,noatime,nosuid,size=100m 0 0
     tmpfs /var/tmp tmpfs defaults,noatime,nosuid,size=50m 0 0
     tmpfs /var/log tmpfs defaults,noatime,nosuid,mode=0755,size=50m 0 0
     ```

2. **Filesystem mount options for SD card protection:**
   - Modify `/etc/fstab` root partition: add `noatime,commit=120` (reduce write frequency)
   - `noatime` — don't update access times on every read
   - `commit=120` — flush filesystem journal every 120s instead of 5s (reduces SD wear)

3. **Disable swap:**
   - `dphys-swapfile swapoff && dphys-swapfile uninstall`
   - `systemctl disable dphys-swapfile.service`
   - Swap on SD card is a reliability and performance killer

4. **Writable data directory:**
   - `/home/hotbox/app/data/` remains writable (app data, orders, config)
   - `/home/hotbox/app/logs/` remains writable (app logs)
   - These are the ONLY paths the app writes to (enforced by systemd ReadWritePaths)

5. **Graceful shutdown hook:**
   - Create `/etc/systemd/system/hotbox-shutdown.service` — runs on shutdown
   - ExecStop: sync filesystems, stop app cleanly
   - Ensures data is flushed before power off

Script must be idempotent, run as root, backs up `/etc/fstab` before modifying.

Create `pi/resilience/setup-watchdog.sh` — hardware watchdog for auto-recovery:

1. **Enable Pi 5 hardware watchdog:**
   - Add `dtparam=watchdog=on` to `/boot/firmware/config.txt` (if not present)
   - Install `watchdog` package

2. **Configure watchdog daemon:**
   - Create `/etc/watchdog.conf`:
     ```
     watchdog-device = /dev/watchdog
     watchdog-timeout = 15
     max-load-1 = 24
     interface = wlan0
     ping = 127.0.0.1
     interval = 10
     ```
   - If system hangs (no watchdog pet for 15s), hardware resets the Pi
   - Monitor system load and network connectivity

3. **Enable watchdog service:**
   - `systemctl enable watchdog.service`

4. **Log rotation for journald:**
   - Configure `/etc/systemd/journald.conf`:
     ```
     SystemMaxUse=50M
     SystemMaxFileSize=10M
     MaxRetentionSec=7day
     ```
   - Prevents journal from filling SD card

Script sources hotbox.conf, runs as root, idempotent.

Create `pi/setup.sh` — master orchestrator that runs all setup scripts in order:

```bash
#!/bin/bash
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
source "$SCRIPT_DIR/config/hotbox.conf"

echo "=========================================="
echo "  HotBox Pi Appliance Setup"
echo "=========================================="
echo ""

# Check root
if [ "$EUID" -ne 0 ]; then
  echo "ERROR: Must run as root (sudo ./setup.sh)"
  exit 1
fi

# Phase 1: Base bootstrap
echo "[1/5] Running base bootstrap..."
bash "$SCRIPT_DIR/bootstrap.sh"

# Phase 2: Kiosk installation
echo "[2/5] Installing kiosk display..."
bash "$SCRIPT_DIR/kiosk/install-kiosk.sh"

# Phase 3: Touch calibration
echo "[3/5] Configuring touchscreen..."
bash "$SCRIPT_DIR/kiosk/touch-calibrate.sh"

# Phase 4: systemd services
echo "[4/5] Installing services..."
bash "$SCRIPT_DIR/systemd/install-services.sh"

# Phase 5: Boot resilience
echo "[5/5] Configuring boot resilience..."
bash "$SCRIPT_DIR/resilience/setup-readonly.sh"
bash "$SCRIPT_DIR/resilience/setup-watchdog.sh"

echo ""
echo "=========================================="
echo "  Setup Complete!"
echo "=========================================="
echo ""
echo "Next steps:"
echo "  1. Copy your .env file to /home/hotbox/app/.env"
echo "  2. Build the app: cd /home/hotbox/app && npm run build"
echo "  3. Reboot: sudo reboot"
echo "  4. App will auto-start on boot"
echo ""
echo "Useful commands:"
echo "  journalctl -u hotbox-server -f    # Server logs"
echo "  journalctl -u hotbox-kiosk -f     # Kiosk logs"
echo "  systemctl status hotbox-server    # Server status"
echo "  systemctl status hotbox-kiosk     # Kiosk status"
echo ""
```
