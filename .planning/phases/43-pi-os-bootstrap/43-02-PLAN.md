<task type="auto">
  <name>Task 1: Create Chromium kiosk installation and launcher scripts</name>
  <files>pi/kiosk/install-kiosk.sh, pi/kiosk/kiosk.sh, pi/kiosk/xinitrc</files>
  <action>
Create `pi/kiosk/install-kiosk.sh` — installs minimal X11 + Chromium for kiosk mode:

1. **Install minimal X11** (not full desktop):
   - `xserver-xorg-core` — X server
   - `xinit` — startx command
   - `x11-xserver-utils` — xset, xrandr
   - `xdotool` — for cursor hiding/window management
   - Do NOT install a window manager or desktop environment

2. **Install Chromium:**
   - `chromium-browser` (Pi OS package name)
   - Create Chromium profile directory at `/home/hotbox/.config/chromium`
   - Pre-configure: disable first-run wizard, disable translation prompts, disable crash reporter

3. **Install screen utilities:**
   - `unclutter` — auto-hide mouse cursor after idle
   - `xscreensaver` is NOT installed (we don't want screensaver)

4. **Disable screen blanking:**
   - Create `/etc/X11/xorg.conf.d/10-blanking.conf` to disable DPMS and screensaver

Script must source `hotbox.conf`, run as root, be idempotent, use `set -euo pipefail`.

Create `pi/kiosk/kiosk.sh` — the kiosk launcher (runs as hotbox user):
1. Wait for X server to be ready (`until xdotool getactivewindow; do sleep 0.5; done` pattern with timeout)
2. Disable screen blanking via xset (`xset s off`, `xset -dpms`, `xset s noblank`)
3. Hide cursor with `unclutter -idle 0.5 -root &`
4. Launch Chromium in kiosk mode:
   ```
   chromium-browser \
     --kiosk \
     --noerrdialogs \
     --disable-infobars \
     --disable-translate \
     --no-first-run \
     --disable-features=TranslateUI \
     --check-for-update-interval=31536000 \
     --disable-session-crashed-bubble \
     --disable-component-update \
     --autoplay-policy=no-user-gesture-required \
     --start-fullscreen \
     --window-size=1920,1080 \
     --window-position=0,0 \
     --touch-events=enabled \
     --enable-touch-drag-drop \
     "http://localhost:${HOTBOX_PORT}"
   ```
5. If Chromium exits (crash), wait 3 seconds and restart it (infinite loop)
6. Log to `/var/log/hotbox-kiosk.log`

Create `pi/kiosk/xinitrc` — X11 init file for startx:
```bash
#!/bin/bash
source /home/hotbox/app/pi/config/hotbox.conf
exec /home/hotbox/app/pi/kiosk/kiosk.sh
```

This file gets symlinked to `/home/hotbox/.xinitrc` by the install script.

  <done>install-kiosk.sh installs minimal X11 + Chromium. kiosk.sh launches fullscreen Chromium at localhost:HOTBOX_PORT with auto-restart. xinitrc wires startx to kiosk launcher.</done>

<task type="auto">
  <name>Task 2: Create touchscreen configuration and calibration</name>
  <files>pi/kiosk/touch-calibrate.sh</files>
  <action>
Create `pi/kiosk/touch-calibrate.sh` — touchscreen setup and calibration utility:

1. **Detect touchscreen device:**
   - Use `xinput list` to find touchscreen input devices
   - Common Pi touchscreen device names: "WaveShare", "eGalax", "ILITEK", "Goodix"
   - Print detected touch devices for user reference

2. **Map touch to display:**
   - Use `xinput map-to-output <device> <output>` to map touch input to correct display
   - Auto-detect primary display output via `xrandr --query`
   - Handle common Pi display outputs: HDMI-1, HDMI-2, DSI-1

3. **Rotation support:**
   - Accept `--rotate` flag with values: normal, left, right, inverted
   - Use `xrandr --output <display> --rotate <rotation>`
   - Apply matching coordinate transformation matrix to touch input via xinput
   - Transformation matrices:
     - normal: `1 0 0 0 1 0 0 0 1`
     - left: `0 -1 1 1 0 0 0 0 1`
     - right: `0 1 0 -1 0 1 0 0 1`
     - inverted: `-1 0 1 0 -1 1 0 0 1`

4. **Persist calibration:**
   - Write detected settings to `/etc/X11/xorg.conf.d/40-touch.conf`
   - Save rotation preference to `hotbox.conf` as `HOTBOX_DISPLAY_ROTATION`

5. **Usage output:**
   - `./touch-calibrate.sh` — auto-detect and configure
   - `./touch-calibrate.sh --rotate left` — rotate display and touch
   - `./touch-calibrate.sh --list` — list detected touch devices

Script sources `hotbox.conf`, can run as root or with sudo.

Update `pi/kiosk/install-kiosk.sh` to:
- Install `xinput` (part of `x11-xserver-utils`, already listed)
- Create `/etc/X11/xorg.conf.d/` directory if not exists
- Call `touch-calibrate.sh` at end of installation (auto-detect mode)
