<task type="auto">
  <name>Task 1: Create customer-aware pricing calculation module</name>
  <files>scripts/customers/pricing.ts</files>
  <action>
Create a pure-function pricing module that calculates customer-specific retail prices using the customer's markup percentage. This follows the same pure-function pattern as scripts/pipeline/pricing-rules.ts — no API dependencies, testable, composable.

**Functions to implement:**

1. `calculateCustomerRetailPrice(wholesaleCost: number, customerMarkupPercent: number, rounding?: 'none' | 'nearest-99' | 'nearest-dollar'): number`
   - Formula: `wholesaleCost * (1 + customerMarkupPercent / 100)`
   - Apply rounding rules (same logic as existing calculateRetailPrice in pricing-rules.ts)
   - This replaces the template preset markup with the customer's own markup

2. `calculateCustomerVariantPrice(customerRetailPrice: number, sizeUpcharge: number): number`
   - Simple: `customerRetailPrice + sizeUpcharge`
   - Size upcharges remain the same regardless of customer (they're cost-based, not markup-based)

3. `calculateCustomerMargin(customerRetailPrice: number, totalCost: number): { dollars: number; percent: number }`
   - `dollars = customerRetailPrice - totalCost`
   - `percent = (dollars / customerRetailPrice) * 100`
   - totalCost = wholesaleCost + decorationCost (same as existing calculateTotalCost)

4. `calculateCustomerRoyalty(customerRetailPrice: number, royaltyPercent: number): number`
   - Formula: `customerRetailPrice * (royaltyPercent / 100)`
   - This is the per-unit royalty amount owed to the brand customer
   - Round to 2 decimal places (money)

5. `calculateCustomerPricingSummary(params: { wholesaleCost: number; decorationCost: number; customerMarkupPercent: number; royaltyPercent: number; rounding?: 'none' | 'nearest-99' | 'nearest-dollar'; sizeUpcharges?: Record<string, number>; }): CustomerPricingSummary`
   - Returns a complete pricing breakdown:
     ```typescript
     interface CustomerPricingSummary {
       wholesaleCost: number;
       decorationCost: number;
       totalCost: number;
       retailPrice: number;
       margin: { dollars: number; percent: number };
       royaltyPerUnit: number;
       netAfterRoyalty: number; // retailPrice - totalCost - royaltyPerUnit
       variantPrices?: Record<string, number>; // size -> price (if sizeUpcharges provided)
     }
     ```

**Critical: All money calculations must round to 2 decimal places using Math.round(value * 100) / 100 at each step.** This prevents floating-point drift. The CONTEXT.md emphasizes: "Markup and royalty calculations must be dead accurate. This is money — no rounding surprises, no calculation bugs."

Export all functions and the CustomerPricingSummary type. Use ESM with .js extensions.

<task type="auto">
  <name>Task 2: Add customer pricing API endpoint and dashboard integration</name>
  <files>scripts/pipeline/preview-server.ts, scripts/pipeline/preview.html</files>
  <action>
**API endpoint:**

Add `GET /api/customers/:id/pricing?style=STYLE` endpoint to preview-server.ts:
- Loads the customer by ID (from customer store)
- If `style` query param provided: looks up product cost data from cost-history.json to get wholesaleCost and decorationCost for that specific product
- If no style param: uses a provided wholesaleCost and decorationCost from query params (`?wholesaleCost=10&decorationCost=2`)
- Calls calculateCustomerPricingSummary with customer's markupPercent and royaltyPercent
- Returns `{ ok: true, pricing: CustomerPricingSummary, customer: { name, markupPercent, royaltyPercent } }`
- If customer not found: `{ ok: false, error: "Customer not found" }` with 404

Also add `GET /api/customers/:id/logos` endpoint:
- Loads the customer by ID
- For each logoKey in customer.logoKeys, look up the logo entry from logos.json registry
- Returns `{ ok: true, logos: Array<{ key: string, displayName: string, filePath: string }> }`
- This endpoint lets the UI and product pipeline quickly resolve a customer's assigned logos

**Dashboard integration in preview.html:**

Add a "Pricing Preview" section to each customer card (or as an expandable detail when clicking a customer card):
- Shows a quick pricing calculation using a sample wholesale cost (e.g., $10.00 as default, with an input to change it)
- Displays: Retail Price, Margin %, Royalty per unit, Net after royalty
- Updates in real-time as the user changes the sample wholesale cost
- This gives the owner an instant sense of what each customer's markup means in dollar terms

Add a "Customer Logos" section to the customer detail view:
- When viewing/editing a customer, show their assigned logos as thumbnails (fetched via GET /api/customers/:id/logos)
- Each logo thumbnail is the actual logo image (loaded via /api/logo-file/:key)

**Keep the UI additions minimal** — this is a utility preview, not a full pricing dashboard. The detailed pricing dashboard already exists for products. This just surfaces the customer-specific calculation so the owner can verify their markup settings make sense.
