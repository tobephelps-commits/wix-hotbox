  <name>Task 1: Initialize Vite + React + TypeScript project with Fastify static serving</name>
  <files>ui/package.json, ui/vite.config.ts, ui/tsconfig.json, ui/tsconfig.app.json, ui/index.html, ui/src/main.tsx, ui/src/vite-env.d.ts, src/app.ts, package.json</files>
  <action>
  1. Create `ui/` directory at project root (separate from backend `src/`).

  2. Initialize React project manually (NOT create-vite — we control the structure):
     - `ui/package.json` with dependencies: react, react-dom, and devDependencies: vite, @vitejs/plugin-react, typescript, @types/react, @types/react-dom
     - `ui/tsconfig.json` extending a `tsconfig.app.json` for React-specific settings
     - `ui/tsconfig.app.json` with: target ES2022, module ESNext, jsx react-jsx, strict true, moduleResolution bundler
     - `ui/index.html` — Vite entry point with `<div id="root">` and `<script type="module" src="/src/main.tsx">`
     - `ui/src/main.tsx` — ReactDOM.createRoot rendering `<App />`
     - `ui/src/vite-env.d.ts` — Vite client types reference

  3. Configure `ui/vite.config.ts`:
     - Output build to `../dist/public/` (so Fastify can serve it)
     - Dev server proxy: `/api` requests forward to `http://localhost:3456` (backend)
     - Dev server port: 5173 (Vite default)
     - Base: '/' (root-relative paths)

  4. Update root `package.json`:
     - Add scripts: `"ui:dev": "cd ui && npx vite"`, `"ui:build": "cd ui && npx vite build"`, `"ui:preview": "cd ui && npx vite preview"`
     - Update `"build"` script to also build UI: chain existing tsc build with ui:build

  5. Update `src/app.ts`:
     - Import and register `@fastify/static` to serve files from `dist/public/` in production
     - Configure: root path to `join(__dirname, 'public')`, prefix '/', decorateReply false (avoid conflict with API routes)
     - Add SPA fallback: for non-API GET requests that don't match a file, serve index.html (needed for client-side routing)
     - Only enable static serving when dist/public/ exists (skip in dev — Vite dev server handles it)
     - @fastify/static is already installed (Phase 44), just needs to be registered

  6. Install ui/ dependencies: run `cd ui && npm install` to generate ui/node_modules and ui/package-lock.json

  IMPORTANT: Do NOT use create-vite or any scaffolding tool. Create files manually for full control.
  IMPORTANT: The backend tsconfig.json has rootDir: "src" — do NOT change this. The ui/ directory has its own tsconfig.
  IMPORTANT: Add `ui/node_modules` and `ui/dist` to the root .gitignore if one exists.

<task type="auto">
  <name>Task 2: Create app layout shell with header, sidebar placeholder, and content area</name>
  <files>ui/src/App.tsx, ui/src/App.css, ui/src/index.css, ui/index.html</files>
  <action>
  1. Set up `ui/index.html` viewport meta for touch devices:
     - `<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">`
     - This prevents pinch-to-zoom in kiosk mode

  2. Create `ui/src/index.css` with global reset and touch-optimized base styles:
     - CSS reset (box-sizing border-box, margin 0, padding 0)
     - Root font-size: 16px, font-family: system-ui sans-serif
     - Body: full viewport height (100dvh), overflow hidden (app manages scrolling)
     - Color scheme CSS custom properties:
       - --color-bg: #0f0f1a (dark background)
       - --color-surface: #1a1a2e (surface/card color — matches v1.x header)
       - --color-sidebar: #141425 (slightly darker for sidebar)
       - --color-text: #e0e0e0 (light text)
       - --color-text-muted: #888
       - --color-accent: #6c63ff (accent/active color)
       - --color-border: #2a2a3e
     - Scrollbar styling for Chromium (thin, dark themed)
     - `touch-action: manipulation` on body (prevents double-tap zoom globally)

  3. Create `ui/src/App.tsx` layout shell:
     - Three-region CSS Grid layout: header (top, full width), sidebar (left), content (right)
     - Header: fixed height ~56px, dark background (--color-surface), displays "HotBox" title left-aligned, system status placeholder right-aligned
     - Sidebar: fixed width 200px, dark background (--color-sidebar), placeholder text "Navigation" — will be built in Plan 02
     - Content area: flex-grow, overflow-y auto with `-webkit-overflow-scrolling: touch` for momentum scroll, padding 24px
     - Content shows a placeholder: "Select a tab to get started"

  4. Create `ui/src/App.css` with layout styles:
     - Use CSS Grid: `grid-template-areas: "header header" "sidebar content"`, `grid-template-columns: 200px 1fr`, `grid-template-rows: 56px 1fr`
     - Full viewport height: 100dvh
     - Each region styled with appropriate colors and borders
     - Content area with smooth scrolling behavior

  IMPORTANT: Use CSS custom properties defined in index.css for all colors — no hardcoded colors in component CSS.
  IMPORTANT: Dark theme throughout — this is a kiosk display, not a white-background app.
  IMPORTANT: 100dvh not 100vh — handles mobile viewport correctly and future-proofs for LAN access (Phase 55).
  </action>

  - `cd ui && npx tsc --noEmit` passes
  - Visual: `cd ui && npx vite` → open http://localhost:5173 → dark app shell with header, sidebar, and content area visible
  </verify>

  - Ready for Plan 02 to populate sidebar navigation
