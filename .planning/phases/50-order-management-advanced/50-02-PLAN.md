  **OrdersTab.tsx:** Main orders tab container managing list/detail state.
  - State: `orders[]`, `selectedOrderId`, `filter` (status, search), `loading`, `totalCount`, `viewMode` ('list' | 'pipeline' — pipeline placeholder for Plan 03)
  - Fetch orders from `GET /api/orders?status=X&search=Y&limit=50&offset=0` on mount and filter change
  - Fetch summary from `GET /api/orders/summary` for status count badges
  - Layout: Left panel (order list with filters) + right panel (order detail when selected), or full-width list on narrow screens
  - Touch targets: minimum 44px tap areas for all interactive elements
  - Include a "Sync Orders" button that POSTs to `/api/orders/sync` with loading state

  **OrderList.tsx:** Scrollable order list with status filter tabs and search.
  - Status filter: horizontal scrollable pill/tab bar showing each status with count badge from summary. "All" tab plus one per active status. Touch-friendly pills (min 44px height).
  - Search: text input at top searching by name/email/order number
  - Each order row: order number, customer name, status badge (colored), total amount, date, item count
  - Status badge colors: new=blue, on-hold=orange, ordered=purple, received=teal, in-production=amber, packed=green, shipped=cyan, delivered=gray, cancelled=red
  - Selected state: highlight row, show detail in right panel
  - Empty state: "No orders found" message with suggestion to sync
  - Pagination: "Load more" button at bottom (increment offset by 50)

  **ContentArea.tsx:** Wire up OrdersTab — import and render `<OrdersTab />` when `activeTab === 'orders'` (same pattern as ProductsTab).

  **OrdersTab.css:** Styles for the orders layout.
  - Use CSS custom properties matching existing theme (var(--color-*) from App.css)
  - Master-detail layout: `.orders-layout` with grid (list 350px, detail 1fr) on wide screens, single column on narrow
  - Status filter pills: horizontal scroll, no wrap, gap 8px
  - Order rows: card-like with subtle border, 12px padding, hover/active states for touch
  - Touch-optimized: large tap targets, adequate spacing between interactive elements

    6. **Status history:** Timeline showing each status change with date and note. Most recent at top. Use colored dots matching status badge colors.
