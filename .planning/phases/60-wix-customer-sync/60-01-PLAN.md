  <action>
Create migration `006-wix-contacts.sql` with a `wix_contacts` table. This is SEPARATE from the existing B2B `customers` table — wix_contacts stores raw WIX CRM contact data.

Schema:
```sql
CREATE TABLE IF NOT EXISTS wix_contacts (
  wix_contact_id TEXT PRIMARY KEY,
  first_name TEXT,
  last_name TEXT,
  email TEXT,
  phone TEXT,
  company TEXT,
  job_title TEXT,
  customer_id TEXT,
  wix_created_date TEXT,
  wix_updated_date TEXT,
  last_synced_at TEXT NOT NULL DEFAULT (datetime('now')),
  created_at TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at TEXT NOT NULL DEFAULT (datetime('now')),
  FOREIGN KEY (customer_id) REFERENCES customers(id) ON DELETE SET NULL
);

CREATE INDEX IF NOT EXISTS idx_wix_contacts_email ON wix_contacts(email);
CREATE INDEX IF NOT EXISTS idx_wix_contacts_customer_id ON wix_contacts(customer_id);
```

The `customer_id` column is a nullable FK to the B2B customers table — allows optional linking of WIX contacts to business accounts.

Create `src/wix-contacts/types.ts` with:
- `WixContact` interface matching the SQLite table (camelCase)
- `WixApiContact` interface matching WIX Contacts API v4 response shape: `{ id, primaryInfo: { email, phone }, info: { name: { first, last }, company, jobTitle }, createdDate, updatedDate }`
- `WixContactsQueryResponse` interface: `{ contacts: WixApiContact[], pagingMetadata: { offset: number, count: number, total: number } }`
- `CustomerSyncHealth` interface mirroring `SyncHealth` from sync/types.ts but for customer sync: startedAt, lastTickAt, lastSuccessAt, consecutiveErrors, totalCycles, totalErrors, contactsSynced, lastTickDurationMs, avgTickDurationMs, maxTickDurationMs
- `CustomerSyncResult` interface: `{ contactsFetched: number, contactsCreated: number, contactsUpdated: number, contactsUnchanged: number, errors: string[] }`

Create `src/wix-contacts/api.ts` — WIX Contacts v4 REST API client. Follow the auth pattern from `src/orders/wix-sync.ts` (Bearer token + wix-site-id header).

Implement:

1. `getHeaders(config)` — returns `{ 'Content-Type': 'application/json', 'Authorization': 'Bearer ${config.wixApiKey}', 'wix-site-id': config.wixSiteId }`. Use a `WixConfig` type `{ apiKey: string; siteId: string }` matching existing pattern from sync/stock-sync.ts.

2. `queryContacts(wixConfig, options?)` — POST to `https://www.wixapis.com/contacts/v4/contacts/query`. Options: `{ offset?: number, limit?: number }`. Default limit 100 (conservative for rate limiting). Request body: `{ query: { paging: { offset, limit }, sort: [{ fieldName: 'createdDate', order: 'ASC' }] } }`. Returns `WixContactsQueryResponse`. Include 200ms delay between calls (same as WIX_RATE_LIMIT_DELAY_MS in stock-sync).

3. `fetchAllContacts(wixConfig)` — Async generator that pages through ALL contacts using queryContacts. Yields batches of `WixApiContact[]`. Stops when returned count < limit (no more pages). Logs progress: `[WixContacts] Fetched {n} contacts (offset {offset})`.

Error handling: Check response.ok, parse error body, throw descriptive error with status code and WIX error message. Match error pattern from wix-sync.ts (status-specific messages for 401/403/404).

Use native fetch (Node 18+). No axios or node-fetch.
