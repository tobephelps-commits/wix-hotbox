Create the system tab as a dashboard card layout (not master-detail — system info is naturally card-based):

**SystemTab.tsx** — Dashboard layout with sections:

**Section 1: System Health** (top row of cards)
Fetch from GET /api/system on mount, auto-refresh every 30 seconds:
- **Version Card**: version, Node.js version, platform/arch, uptime (formatted as Xd Xh Xm)
- **CPU Card**: load averages (1/5/15 min), core count. Color load values: green (<50%), yellow (50-80%), red (>80% of core count)
- **Memory Card**: used/total MB, usedPercent as progress bar. Color: green (<60%), yellow (60-85%), red (>85%)
- **Disk Card**: used/available/total MB, usedPercent as progress bar. Color: green (<70%), yellow (70-90%), red (>90%)
- **Temperature Card** (only show if temperature field present — Pi only): degrees C. Color: green (<60°), yellow (60-75°), red (>75°)
- **Database Card**: path (truncated), size in MB, migrations applied count
- **Network Card**: LAN addresses list, port, base URL (clickable)

Cards use CSS grid: 3 columns on desktop, 2 on tablet, 1 on mobile.
Each card: dark surface background, subtle border, label on top (muted), value large and prominent.

**Section 2: Sync Daemon** (below health cards)
Fetch from GET /api/sync/health on mount:
- Status indicator: green "Running" or gray "Stopped" badge
- If running: show tickCount, avgTickMs, lastTickAt (relative time), errors count
- "Start" button (disabled if running) → POST /api/sync/start
- "Stop" button (disabled if stopped) → POST /api/sync/stop
- "Run Once" button → POST /api/sync/run (single sync cycle)
- After any action, re-fetch /api/sync/health to update display
- Product mappings count from GET /api/sync/mappings (show as "X products mapped")
- "Audit Mappings" button → POST /api/sync/audit (shows loading, then result summary)

**SystemTab.css**:
- `.system-tab` scrollable container with padding
- `.system-section` with title and content
- `.health-grid` CSS grid (repeat(auto-fill, minmax(280px, 1fr))) with gap
- `.health-card` dark surface, border-radius, padding, flex column
- `.health-card__label` small muted text
- `.health-card__value` large prominent text
- `.health-card__bar` progress bar with color variants
- `.sync-controls` flex row with buttons and status badge
- `.sync-status--running` green, `.sync-status--stopped` gray
- Touch-friendly: 44px button heights, proper spacing
