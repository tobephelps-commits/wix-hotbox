  <action>
Create the inventory tab following the OrdersTab master-detail pattern:

**types.ts** — Define UI-side types mirroring backend monitor/types.ts:
- TrackedProduct (id, style, name, vendor, colors, sizes, priority, lastPolledAt, addedAt)
- InventorySnapshot (style, timestamp, vendor, skus: SkuSnapshot[])
- SkuSnapshot (color, size, totalQty, wellStocked, warehouses?)
- StockAlert (id, type, style, productName, color, size, previousQty, currentQty, timestamp, vendor, acknowledged)
- PollPriority = 'hot' | 'normal' | 'slow'
- AlertType = 'out-of-stock' | 'critical' | 'low-stock' | 'back-in-stock'

**InventoryTab.tsx** — Master-detail layout:
Left panel (350px):
- Header with "Inventory" title and "Add Product" button + "Poll Now" button
- Tracked products list fetched from GET /api/monitor/products
- Each item shows: style number, product name, vendor badge (SanMar/S&S), priority badge (color-coded: hot=red, normal=blue, slow=gray), last polled time (relative)
- Click to select product (sets selectedStyle state)
- Search input to filter by style/name
- Add product form (inline expandable): style input, name input, vendor dropdown (sanmar/ssactivewear), priority selector (hot/normal/slow) → POST /api/monitor/products
- Delete button per product → DELETE /api/monitor/products/:style (with confirmation)

Right panel (flexible):
- When no product selected: centered "Select a product to view inventory" placeholder
- When product selected: show product detail with:
  - Product header (name, style, vendor, priority with inline edit via PATCH /api/monitor/products/:style)
  - Inventory snapshot section: fetch GET /api/monitor/products/:style/snapshot
    - Grid/table of SKUs grouped by color, showing size columns with quantity values
    - Color-code quantities: green (wellStocked), yellow (low), red (0)
  - "No snapshot available" message if snapshot is null/empty

**InventoryTab.css** — Follow OrdersTab.css patterns:
- `.inventory-layout` with CSS grid (350px / 1fr), collapse to single column at 900px
- `.inventory-layout__list-panel` and `.inventory-layout__detail-panel`
- `.inventory-header` with title + action buttons
- `.tracked-product-item` with hover/active/selected states
- Priority badges: `.priority-badge--hot` (red), `.priority-badge--normal` (blue), `.priority-badge--slow` (gray)
- Stock quantity colors: `.qty--ok` (green), `.qty--low` (orange), `.qty--zero` (red)
- Add product form: `.add-product-form` with slide-down animation
- Touch-friendly: 44px min button/input heights, proper spacing
