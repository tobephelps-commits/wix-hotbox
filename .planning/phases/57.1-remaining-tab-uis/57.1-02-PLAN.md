**types.ts** — Define UI-side types mirroring backend customers/types.ts:
- CustomerAccount (id, name, contactName, email, phone?, logoKeys: string[], markupPercent, royaltyPercent, notes?, active, createdAt, updatedAt)
- RoyaltyLineItem (orderId, orderNumber, orderDate, lineItemName, quantity, retailPrice, royaltyRate, royaltyAmount, discounted)

- PricingResult (wholesaleCost, decorationCost, totalCost, markupPercent, markupAmount, retailPrice, royaltyPercent, royaltyAmount, profitPerUnit)

**CustomersTab.tsx** — Master-detail layout:
Left panel (350px):
- Header with "Customers" title and "New Customer" button
- Customer list fetched from GET /api/customers
- Each item shows: customer name (bold), contact name (muted), email, active/inactive badge
- Filter toggle: "Active" / "All" (default Active) using ?active=true query param
- Search input to filter by name/email (client-side filter on loaded list, since customer count is typically small)
- Click to select customer (sets selectedCustomerId state)

Right panel (flexible):
- When no customer selected AND not creating: centered "Select a customer or create a new one" placeholder
- **View mode** (default when customer selected): Display customer details
  - Customer header: name, contact, email, phone, active status badge
  - "Edit" button → switches to edit mode
  - "Delete" button → confirmation dialog → DELETE /api/customers/:id
  - Markup/Royalty percentages displayed prominently
  - Logo keys list (display as chips)
  - Notes section
  - Created/Updated timestamps
- **Edit/Create mode**: Form with fields:
  - name (required), contactName (required), email (required), phone (optional)
  - markupPercent (number input, required), royaltyPercent (number input, required)
  - logoKeys (comma-separated text input or tag-style input)
  - notes (textarea)
  - active (checkbox, default true for new)
  - "Save" button → POST /api/customers (create) or PATCH /api/customers/:id (update)
  - "Cancel" button → returns to view mode
  - Form validation: name, contactName, email required; markupPercent/royaltyPercent must be >= 0
