<objective>
Enable variant image switching so customers see color-specific product images when selecting variants.

Purpose: Currently, selecting a different color variant on the storefront does NOT change the product gallery images. The pipeline already assigns images to color choices via the WIX API, but the WIX Editor's Product Gallery widget needs manual configuration to activate the switching behavior. This plan verifies the API-level linking is correct and creates documentation for the required Editor configuration.

Output: Verification that API image-to-variant linking works, documentation for WIX Editor configuration, and human verification that images switch on the live storefront.
</objective>

   - If images show for wrong colors: Check that displayColor values match between variants and images

6. **Products to Prioritize**:

   - Products with 3+ color options
   - Best-selling products with high visibility
