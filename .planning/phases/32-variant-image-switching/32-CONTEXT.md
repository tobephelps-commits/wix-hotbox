# Phase 32: Variant Image Switching - Context

**Gathered:** 2026-02-03
**Status:** Ready for planning

<vision>
## How This Should Work

When a customer is browsing a product and clicks on a color swatch, the entire product gallery updates to show images of that color. All available angles — front, back, side, whatever the vendor provides — should appear for the selected color.

This is how major ecommerce sites work: click a color, see that color. No confusion about what you're buying. The customer should have instant visual feedback showing exactly what they'll receive.

</vision>

<essential>
## What Must Be Nailed

- **Instant visual feedback** — Customer clicks a color and immediately sees what they're getting
- **Accurate representation** — The images shown must truly match the selected color, no wrong images
- **Smooth experience** — The transition between colors should feel polished, not jarring

All three are equally important for this phase to succeed.

</essential>

<specifics>
## Specific Ideas

- Standard ecommerce pattern like Amazon/major retailers — click color, images update
- Logo overlays must carry through when switching colors — if the product has branded images, those should update too when selecting a different color
- Full gallery swap, not just the main image — all thumbnails and viewable images change to the selected color

</specifics>

<notes>
## Additional Context

This builds on the multi-angle image support (Phase 21) and logo overlay system (Phases 22-24). The expectation is that logo-branded images will also switch when the customer selects a different color variant.

</notes>
