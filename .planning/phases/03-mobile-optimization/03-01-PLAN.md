<objective>
Audit current mobile navigation state via Playwright browser automation at mobile viewport (375x812), research WIX API capabilities for mobile/responsive settings, and document precise WIX Editor instructions for mobile navigation optimization.

Purpose: Mobile visitors (50% of traffic) currently cannot access the majority of navigation items. The fixed 950px nav bar does not collapse, tap targets are 30px (below 44px WCAG minimum), and the hamburger icon does not function. This plan investigates what can be automated vs. what requires WIX Editor, then produces actionable documentation.

Output: MOBILE-NAV-OPTIMIZATION.md with step-by-step WIX Editor instructions for mobile menu, touch targets, and navigation hierarchy on mobile.
</objective>

4. If any mobile-relevant APIs exist, test them against site c744cbdb-46f8-4c66-ac76-eb31bd0d52c1
