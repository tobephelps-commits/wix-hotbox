<task type="auto">
  <name>Task 1: Audit mobile cart and checkout flow</name>
  <files>.planning/phases/03-mobile-optimization/MOBILE-CHECKOUT-FLOW.md</files>
  <action>
Audit the mobile shopping flow from product selection through checkout:

**Part A: Add to Cart Flow at 375x812**

1. Use browser_resize to set viewport to 375x812
2. Navigate to a product detail page
3. Attempt to select a variant (color/size) and add to cart at mobile viewport
4. Measure via browser_evaluate:
   - Cart icon/button position and visibility in header
   - Mini-cart or cart drawer behavior on mobile
   - Cart page layout at mobile viewport
   - Cart item display (product image, name, options, price, quantity)
   - "Proceed to Checkout" button position and size
5. Take screenshots of cart flow at mobile

**Part B: Checkout Flow at 375x812**

1. If possible without making a real purchase, navigate to the checkout page
2. Audit checkout layout on mobile:
   - Form field sizes and spacing (email, shipping address)
   - Payment method display (credit card fields, Sezzle BNPL)
   - Order summary visibility
   - "Place Order" button position and size
   - Policy display area (currently empty per CK-1)
   - Overall page width (horizontal overflow check)
3. Measure touch target sizes for form inputs and buttons
4. Check if Sezzle BNPL widget renders correctly on mobile (CK-5)
5. Take screenshots of checkout at mobile viewport

**Part C: Compile Checkout Documentation**

Create MOBILE-CHECKOUT-FLOW.md with:
1. **Current State** - Screenshots and measurements of cart and checkout on mobile
2. **Cart Page Optimization** - WIX Editor instructions for:
   a. Mobile cart layout (stacked items, clear imagery)
   b. Cart item display optimization (readable product names, visible options)
   c. Prominent "Proceed to Checkout" button placement
3. **Checkout Page Optimization** - WIX Editor instructions for:
   a. Mobile-friendly form layout (full-width inputs, proper spacing)
   b. Touch-friendly input fields (minimum 44px height)
   c. Payment method display on mobile
   d. Order summary positioning (visible without excessive scrolling)
4. **Verification Checklist** - How to test the complete mobile purchase flow

NOTE: Checkout optimization overlaps with Phase 4 (Checkout & Conversion Optimization). This plan focuses ONLY on mobile layout/usability of checkout. Phase 4 handles conversion elements like trust signals, policies, and recovery mechanisms.

**IMPORTANT:** Do NOT complete any actual purchase. Navigate as far as possible without submitting payment.

Create MOBILE-OPTIMIZATION-MASTER.md — a single consolidated guide for the store owner that combines all Phase 3 findings into a prioritized, ordered action plan.

**Document structure:**

1. **Executive Summary**
   - 10 mobile issues identified in Phase 1 audit
   - What CAN be automated via API (from Plan 01 research) vs. WIX Editor only
   - Estimated effort for store owner (grouped by priority)

2. **Pre-Requisites**
   - List any Phase 2 manual changes that MUST be completed first (from STATE.md's 17 pending WIX Editor changes)
   - Specifically: Navigation restructure (02-03) should be done before mobile nav optimization
   - Gallery standardization (02-05) should be done before mobile product page optimization

3. **Priority 1: Critical Fixes** (do these first)
   - Mobile-responsive layout activation (CR-1)
   - Mobile navigation / hamburger menu (MC-1)
   - Product gallery visibility on mobile (MC-2)
   - Reference: MOBILE-NAV-OPTIMIZATION.md and MOBILE-PRODUCT-PAGES.md sections

4. **Priority 2: High-Impact Improvements**
   - Add to Cart positioning on mobile (MC-3)
   - Color swatch sizing (MC-4)
   - 32-color-option handling (MC-5)
   - Tablet experience (MC-6)
   - Image lazy-loading (PT-1)
   - Reference: MOBILE-PRODUCT-PAGES.md sections

5. **Priority 3: Checkout Flow**
   - Cart page mobile layout
   - Checkout page mobile layout
   - Reference: MOBILE-CHECKOUT-FLOW.md sections

6. **Verification Steps**
   - How to test each fix on mobile (device or Chrome DevTools)
   - Key breakpoints to test: 375px (phone), 768px (tablet), 1024px (small desktop)
   - Specific checks for each priority group

7. **Cross-Reference: All Phase 3 Documents**
   - Link to MOBILE-NAV-OPTIMIZATION.md (detailed nav instructions)
   - Link to MOBILE-PRODUCT-PAGES.md (detailed product page instructions)
   - Link to MOBILE-CHECKOUT-FLOW.md (detailed checkout instructions)

**Writing guidelines:**
- Use numbered steps, not paragraphs
- Include specific WIX Editor UI paths
- Group related changes to minimize back-and-forth in the editor
- Note which changes affect ALL pages vs. specific pages
- Estimate effort as: Quick (5 min), Medium (15-30 min), Involved (30-60 min)
