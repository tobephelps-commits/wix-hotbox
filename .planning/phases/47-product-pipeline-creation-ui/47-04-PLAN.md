<task type="auto">
  <name>Task 1: Build pricing config, template selector, and creation flow</name>
  <files>ui/src/components/products/PricingConfig.tsx, ui/src/components/products/TemplateSelector.tsx, ui/src/components/products/CreateFlow.tsx, ui/src/components/products/CreationResult.tsx, ui/src/components/products/ProductsTab.tsx, ui/src/components/products/ProductsTab.css</files>
  <action>
1. **PricingConfig.tsx** — Pricing configuration panel (the 'configure' step):
   - Preset selector: dropdown or large touch buttons showing preset names from GET /api/pipeline/presets
   - When preset selected, populate: markup %, rounding mode, size upcharges
   - Editable fields: markup % (number input), rounding (3 radio buttons: nearest-99, nearest-dollar, none)
   - Size upcharges table: only show sizes in selectedSizes that are in UPCHARGE_SIZES (2XL+), with editable dollar amounts
   - Live price preview: show calculated retail price from wholesale cost + markup, and margin % below
   - Optional fields: decoration cost (number input, default 0), decoration type (dropdown: none, screen-print, embroidery, heat-transfer, dtg)
   - Optional: collection names (text input, comma-separated)
   - "Create Product" button at bottom

2. **TemplateSelector.tsx** — Template load/save UI:
   - Positioned above or alongside PricingConfig
   - Dropdown of saved templates from GET /api/pipeline/templates
   - "Load" button: populates PricingConfig fields from template settings
   - "Save as Template" button: saves current PricingConfig as a named template via POST /api/pipeline/templates
   - Template name input (shown when saving)
   - "Delete" button next to each template in dropdown

3. **CreateFlow.tsx** — Creation progress display (the 'creating' step):
   - Shows product name being created
   - Step-by-step progress: "Creating product..." -> "Adding media..." -> "Setting variants..." -> "Setting inventory..." -> "Adding to collections..."
   - Each step shows checkmark when complete, spinner when active
   - On error: show error message with "Retry" button
   - Calls POST /api/pipeline/create with assembled CuratedProduct data
   - On success: transitions to 'done' step

4. **CreationResult.tsx** — Success result display (the 'done' step):
   - Green success banner
   - Product ID and WIX URL (as a link)
   - Stats: variants created, images added, collections assigned
   - Warnings list (if any, yellow)
   - "Create Another" button -> returns to 'lookup' step (clears state)

5. **ProductsTab.tsx** — Wire the new steps:
   - 'configure' step renders PricingConfig + TemplateSelector, receives selectedColors, selectedSizes, preview data
   - 'creating' step renders CreateFlow
   - 'done' step renders CreationResult
   - Pass assembled CuratedProduct from configure -> creating step
  </action>
