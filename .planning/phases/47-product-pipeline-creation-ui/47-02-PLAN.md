  <files>src/pipeline/fetch-product.ts, src/pipeline/create-product.ts</files>
  <action>
1. **fetch-product.ts** — Rewrite for v2.0 unified vendor architecture:
   - Remove ALL SanMar-specific imports and the unifiedToProductData bridge function
   - The core function becomes simple: `fetchProductPreview(style: string, vendorId: VendorId)`:
     a. Get vendor adapter via `getVendor(vendorId)` from src/vendors/registry.ts
     b. Call `adapter.fetchAllProductData(style)` to get UnifiedProductData
     c. Call `buildProductPreview(unifiedData)` from mapper.ts to get ProductPreview
     d. Return `{ preview: ProductPreview, rawData: UnifiedProductData }` (rawData needed for create step)
   - Remove CLI runner block
   - Remove dotenv import
   - Export the ProductFetchResult interface: `{ preview: ProductPreview; rawData: UnifiedProductData }`

2. **create-product.ts** — Port the WIX creation orchestrator:
   - Core function: `createWixProduct(curated: CuratedProduct, rawData: UnifiedProductData): Promise<CreationResult>`
     a. Call buildCreateProductPayload(curated) -> createProduct(payload)
     b. Call buildMediaPayload(curated, rawData.media) -> addProductMedia(productId, media)
     c. Call buildVariantUpdates(curated, rawData) -> updateProductVariants(productId, variants)
     d. Build variant ID map from response, call buildInventoryUpdate -> updateInventory
     e. Handle collections via getCollectionByName + addProductToCollection
     f. Return CreationResult with productId, productUrl, variantsCreated, mediaAdded, warnings, collectionsAssigned
   - Keep CreationResult interface
   - Remove CLI runner, dotenv, logo overlay logic (logo system is Phase 48)
   - Remove batch creation logic (can be added later if needed)
   - Import from local src/pipeline/ modules only (mapper, wix-api, types, pricing-rules) and src/vendors/

<task type="auto">
  <name>Task 2: Create pipeline API routes and wire into Fastify</name>
  <files>src/routes/pipeline.ts, src/routes/index.ts</files>
  <action>
Create src/routes/pipeline.ts as a Fastify plugin with these endpoints:

1. **GET /api/pipeline/preview/:vendorId/:style** — Style lookup and preview
   - Validate vendorId is registered
   - Call fetchProductPreview(style, vendorId)
   - Return ProductPreview JSON (colors with images, sizes, pricing)
   - Cache rawData in a module-level Map keyed by `${vendorId}:${style}` with 10-minute TTL (avoids re-fetching vendor data between preview and create steps)

2. **POST /api/pipeline/create** — Create WIX product from curated selections
   - Request body: `{ vendorId, style, selectedColors: CuratedColor[], selectedSizes: string[], pricingPreset?: string, pricingConfig?: PricingConfig, collections?: string[], decorationCost?: number, decorationType?: string }`
   - Look up cached rawData from preview step (or re-fetch if expired)
   - Build CuratedProduct from request body + rawData
   - Call createWixProduct(curated, rawData)
   - Return CreationResult JSON

3. **GET /api/pipeline/presets** — List available pricing presets
   - Return PRICING_PRESETS object from pricing-rules.ts

4. **GET /api/pipeline/templates** — List saved templates
   - Call listTemplates() and return array

5. **POST /api/pipeline/templates** — Save a template
   - Request body: ProductTemplate (without createdAt/updatedAt — server sets those)
   - Call saveTemplate(name, template)
   - Return saved template

6. **DELETE /api/pipeline/templates/:name** — Delete a template
   - Call deleteTemplate(name)
   - Return { deleted: true }

In the plugin's registration hook, call `setWixConfig()` with fastify.config wixApiKey/wixSiteId and `setTemplatesDir()` with fastify.config.dataDir.

Wire into src/routes/index.ts:
- Import pipelineRoutes from './pipeline.js'
- Register: `fastify.register(pipelineRoutes, { prefix: '/pipeline' })`
  </action>
