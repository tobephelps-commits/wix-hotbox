  <name>Task 1: Build smoke test script</name>
  <files>scripts/smoke-test.ts, package.json</files>
  <action>
Create scripts/smoke-test.ts that validates the entire v0.2 system works end-to-end. The script should:

1. **TypeScript compilation check** — run `tsc --noEmit` and verify exit code 0.

2. **CLI help/dry-run validation** — for each CLI entry point, run it with help/info args that produce output without side effects and verify exit code 0:
   - `tsx scripts/pipeline/validate-pipeline.ts` (runs read-only health check)
   - `tsx scripts/monitor/manage.ts` (shows help)
   - `tsx scripts/sync/manage.ts` (shows help)
   - `tsx scripts/orders/manage.ts` (shows help)
   - `tsx scripts/orders/cart-cli.ts` (shows help/preview)
   - `tsx scripts/pipeline/margin-report.ts --help` or similar no-op
   - `tsx scripts/pipeline/sale-pricing.ts` (shows help)
   - `tsx scripts/pipeline/wix-coupons.ts` (shows help)

3. **Preview server API endpoint validation** — start the preview server programmatically on a random port, then HTTP GET each endpoint and verify it responds (200 or expected status):
   - GET / (HTML)
   - GET /api/presets (JSON array)
   - GET /api/templates (JSON)
   - GET /api/logos (JSON)
   - GET /api/margins (JSON)
   - GET /api/sales (JSON)
   - GET /api/inventory/products (JSON)
   - GET /api/inventory/alerts (JSON)
   - GET /api/inventory/health (JSON)
   - GET /api/orders (JSON)
   - GET /api/cart/preview (JSON)
   - GET /api/cart/history (JSON)
   - GET /api/printers (JSON)

4. **Module import validation** — dynamically import each barrel export and verify no import errors:
   - scripts/sanmar/index.ts
   - scripts/ss-activewear/index.ts
   - scripts/vendor/index.ts
   - scripts/pipeline/index.ts
   - scripts/monitor/index.ts
   - scripts/sync/index.ts
   - scripts/orders/index.ts

Use child_process.execSync for CLI checks and native fetch for HTTP checks. Output results in a clear table format: ✓ PASS / ✗ FAIL with details. Exit with code 0 if all pass, code 1 if any fail.

Add `"smoke-test": "npx tsx scripts/smoke-test.ts"` to package.json scripts.

Important implementation notes:
- Use `import { execSync } from 'node:child_process'` for CLI commands
- Use `import { createServer } from 'node:http'` if needed for server testing
- For preview server testing: import the server start function or start it as a child process, wait for it to listen, run HTTP checks, then kill it
- Set a 30-second timeout for the preview server startup
- CLI commands that require env vars (validate, etc.) may produce warnings but should still exit 0 — check exit code, not output content
- Wrap each test in try/catch so one failure doesn't block remaining tests
