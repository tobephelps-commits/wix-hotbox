**Architecture section — add these modules:**

### `scripts/ss-activewear/` — S&S Activewear API Client
REST-based client for querying S&S Activewear catalog. Rate-limited to 60 req/min.
- Product search and details
- Inventory by style
- Style/color/size resolution

### `scripts/vendor/` — Multi-Vendor Registry
Unified vendor adapter interface for SanMar and S&S Activewear.
- VendorAdapter interface (product, inventory, media, pricing)
- Vendor registry with factory pattern
- Shared types (UnifiedProduct, UnifiedInventory, etc.)

### `scripts/orders/` — Order Management
Complete order lifecycle from WIX sync to fulfillment:
- WIX Orders API client (V1 eCommerce)
- Local order store with JSON persistence
- Invoice PDF generation (PDFKit)
- Shipping label PDF generation
- Cross-platform print service
- SanMar cart automation (Playwright browser)
- Cart consolidation engine

**Troubleshooting table — add v0.2 errors:**

| Error | Cause | Fix |
|-------|-------|-----|
| `S&S API 401 Unauthorized` | S&S credentials missing or invalid | Check SS_API_KEY and SS_ACCOUNT_NUMBER in .env |
| `Rate limit exceeded for S&S Activewear` | More than 60 requests/minute to S&S | Wait 60 seconds and retry; the rate limiter handles this automatically |
| `No orders with status 'new' found` | Cart fill has no orders to process | Only orders with 'new' status are eligible for cart fill |
| `Playwright browser not found` | Playwright browsers not installed | Run `npx playwright install chromium` |
| `Template 'X' not found` | Template name doesn't match | Check names with `--list-templates`; names are case-insensitive |
| `Logo 'X' not found in registry` | Logo key not in data/logos.json | Register the logo in data/logos.json first |

**Key Behaviors — add:**

- **Multi-vendor support.** Use `--vendor ss` to fetch from S&S Activewear. Default is SanMar.
- **Templates save time.** Save pricing, collections, and overlay settings as reusable templates.
- **Orders sync from WIX.** Run `npm run orders:sync` to pull new orders. Manual orders can be created directly.
- **Cart fill is preview-first.** `npm run cart` shows what would be added to the SanMar cart without acting. `npm run cart:fill` actually opens a browser.
- **Invoices and labels are PDFs.** Generated locally in data/invoices/ and data/labels/. Print via configured printers or download from dashboard.
