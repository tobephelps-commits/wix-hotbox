  <name>Task 1: Create OrderCreateForm component</name>
  <files>ui/src/components/orders/OrderCreateForm.tsx, ui/src/components/orders/OrderCreateForm.css</files>
  <action>
Create a modal form component for manual order creation. The form must collect data matching the CreateOrderInput interface from src/orders/types.ts:

**Form sections:**
1. **Source** — select dropdown: "manual", "phone", "walk-in" (source field, required)
2. **Customer Info** — firstName, lastName, email, phone (all optional)
3. **Shipping Address** — company, firstName, lastName, addressLine1, addressLine2, city, state, postalCode, country (optional collapsible section)
4. **Line Items** — repeatable row group:
   - productName (text, required)
   - vendorStyle (text, optional)
   - color (text, optional)
   - size (text, optional)
   - quantity (number, required, min 1)
   - unitPrice (number, required, min 0)
   - Total auto-calculated (quantity × unitPrice)
   - "Add Item" button, "Remove" button per row
5. **Notes** — textarea (optional)
6. **Financials** — auto-calculated from line items:
   - Subtotal (sum of line item totals)
   - Shipping Cost (editable number input, default 0)
   - Tax (editable number input, default 0)
   - Discount (editable number input, default 0)
   - Total = subtotal + shipping + tax - discount (read-only)

**Behavior:**
- On submit: POST /api/orders with CreateOrderInput body
- On success: call onCreated callback with the new order, close modal
- On error: show error message inline
- Cancel button closes modal
- Validate at least 1 line item with productName and quantity

**Styling:**
- Follow existing modal patterns (overlay with centered card, like LogoManager delete dialog)
- Use existing design tokens from Phase 58 (--radius-md, --spacing-*, --font-size-*, --shadow-depth-2)
- Touch-friendly: 56px+ button heights, generous padding, large inputs matching existing form patterns in CustomersTab
- BEM naming: order-create-form__*
