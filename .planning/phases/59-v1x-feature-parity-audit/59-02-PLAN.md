  <name>Task 1: Create shipping label PDF generator</name>
  <files>src/orders/label-template.ts, src/orders/index.ts</files>
  <action>
Create `src/orders/label-template.ts` following the same pattern as invoice-generator.ts and production-sheet.ts:

**Label content (4x6 inch label, standard shipping label size):**
1. **FROM section** (top) — HotBox Clothing return address:
   - Brand name (using BRAND_NAME from pdf-template.ts)
   - Static return address (configurable constant)
2. **TO section** (center, larger text) — Shipping address from order:
   - Company (if present)
   - firstName lastName
   - addressLine1
   - addressLine2 (if present)
   - city, state postalCode
   - country
3. **Order reference** (bottom) — Order number and date in small text

**Implementation:**
- Import PDFKit, use BRAND_NAME and constants from pdf-template.ts
- Export `generateLabel(order: OrderWithDetails): Promise<Buffer>`
- Page size: [288, 432] (4x6 inches at 72 DPI)
- Use Helvetica font (built into PDFKit, no font files needed)
- FROM address: 10pt font, top-left
- TO address: 14pt bold font, centered vertically
- Order # reference: 8pt font, bottom
- If no shippingAddress on order, throw descriptive error

Add `export { generateLabel } from './label-template.js';` to src/orders/index.ts barrel export.
