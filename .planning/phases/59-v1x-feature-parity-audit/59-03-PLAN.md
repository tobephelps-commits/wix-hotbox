  <name>Task 1: Create CartFillModal component</name>
  <files>ui/src/components/orders/CartFillModal.tsx, ui/src/components/orders/CartFillModal.css</files>
  <action>
Create a modal component for cart automation workflow with three views: preview, filling, and history.

**CartFillModal props:**
- `onClose: () => void`
- `onComplete: () => void` (refresh orders after cart fill)

**Views (internal state machine):**

1. **Vendor Selection + Preview** (initial view):
   - Two vendor buttons: "SanMar" and "S&S Activewear" (large touch-friendly buttons)
   - On vendor select: fetch GET /api/orders/cart/preview?vendor={vendor}
   - Show preview: item count, order count, scrollable list of consolidated cart items (vendorStyle, color, size, qty, sourceOrders)
   - "Fill Cart" button to proceed (disabled if no items)
   - "View History" link/button

2. **Filling Progress** view:
   - Show "Filling {vendor} cart..." with spinner
   - Call POST /api/orders/cart/fill with { vendor, headless: true }
   - On response, show results:
     - Status badge (success/partial/failed)
     - Item results list: each item with success/failure indicator
     - Success count / total count
     - Error details for failed items
   - "Done" button calls onComplete and closes

3. **History** view:
   - Fetch GET /api/orders/cart/history?limit=10
   - Show list of past fills: vendor, date, status, item count, success/failed counts
   - "Back" button returns to preview view

**Styling:**
- Full-screen modal overlay (like LogoManager delete dialog pattern but larger)
- Use design tokens: --radius-md, --shadow-depth-2, --spacing-*
- Touch-friendly: 56px+ buttons, generous padding
- BEM naming: cart-fill-modal__*
- Status colors: success=green, partial=orange, failed=red (use existing status-badge patterns)
