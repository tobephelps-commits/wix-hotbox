<task type="auto">
  <name>Task 1: Add batch create API endpoint</name>
  <files>src/routes/pipeline.ts</files>
  <action>
Add a POST /api/pipeline/batch endpoint to pipeline routes that accepts an array of style numbers with shared configuration and creates products sequentially, streaming progress via SSE.

**Endpoint: POST /api/pipeline/batch**
Request body:
```json
{
  "items": [
    { "vendorId": "sanmar", "styleNumber": "PC54" },
    { "vendorId": "sanmar", "styleNumber": "DT6000" }
  ],
  "pricingConfig": { "markupPercent": 100, "rounding": "nearest-99", "sizeUpcharges": {} },
  "presetKey": "standard-tee",
  "decorationCost": 0,
  "decorationType": "none",
  "collections": []
}
```

**Response:** SSE stream (text/event-stream) with events:
- `event: progress` — `{ index, total, style, status: "fetching" | "creating" | "done" | "error", message? }`
- `event: complete` — `{ created: number, failed: number, results: [{ style, success, productId?, error? }] }`

**Implementation:**
1. Set Content-Type to text/event-stream, Connection to keep-alive, Cache-Control to no-cache
2. For each item in batch:
   a. Send progress event (status: "fetching")
   b. Call the existing pipeline fetchProductPreview to get vendor data
   c. Send progress event (status: "creating")
   d. Call createWixProduct with the fetched data and shared pricing config
   e. Send progress event (status: "done" or "error")
3. After all items, send complete event with summary
4. Limit batch to 50 items (return 400 if exceeded)

Use existing pipeline module imports (fetchProductPreview, createWixProduct, etc.) — check current exports from src/pipeline/ to understand available functions. Use `reply.raw` for SSE streaming (Fastify pattern for raw response handling).
