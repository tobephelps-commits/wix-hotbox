<task type="auto">
  <name>Task 2: Build cross-platform print service</name>
  <files>scripts/orders/print-service.ts</files>
  <action>
Create scripts/orders/print-service.ts that abstracts sending PDFs to printers.

**Strategy:** Use child_process.exec to invoke platform-specific print commands. No additional npm dependencies needed.

**Functions:**

1. `printPdf(pdfPath: string, printerName?: string): Promise<PrintResult>`
   - Detect platform via process.platform
   - **Windows:** Use PowerShell: `Start-Process -FilePath "${pdfPath}" -Verb Print` (default printer) or `Out-Printer -Name "${printerName}"` for specific printer
   - **macOS:** `lp -d "${printerName}" "${pdfPath}"` or `lp "${pdfPath}"` for default
   - **Linux:** Same as macOS (`lp` command)
   - Return { success: boolean; message: string; printerUsed: string }
   - On error, return { success: false, message: error description } — don't throw

2. `listPrinters(): Promise<string[]>`
   - **Windows:** PowerShell `Get-Printer | Select-Object Name` — parse output
   - **macOS/Linux:** `lpstat -a` — parse output
   - Return array of printer names

3. `printInvoice(order: Order): Promise<PrintResult>`
   - Generate invoice PDF via generateInvoice (import from invoice-generator)
   - Save to temp path in data/invoices/
   - Call printPdf with the saved path
   - Use env INVOICE_PRINTER for printer name (optional — default printer if not set)
   - Return result

4. `printShippingLabel(order: Order): Promise<PrintResult>`
   - Generate label PDF via generateShippingLabel
   - Save to temp path in data/labels/
   - Call printPdf with the saved path
   - Use env LABEL_PRINTER for printer name (optional — different printer for thermal labels)
   - Return result

**PrintResult type:** { success: boolean; message: string; printerUsed: string; filePath: string }

**CLI runner (bottom of file):**
If run directly:
- `--list-printers` — list available printers
- `--test-print` — generate demo invoice PDF, print to default printer
