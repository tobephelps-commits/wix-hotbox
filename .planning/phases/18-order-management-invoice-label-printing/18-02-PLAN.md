<task type="auto">
  <name>Task 1: Create invoice template layout module</name>
  <files>scripts/orders/invoice-template.ts</files>
  <action>
Install PDFKit: `npm install pdfkit @types/pdfkit`

Create scripts/orders/invoice-template.ts that defines the invoice layout constants and helper functions.

**Brand constants:**
- BRAND_NAME: 'HotBox Clothing'
- BRAND_COLOR: '#E31837' (red — use as accent, not dominant)
- BRAND_SECONDARY: '#333333' (dark gray for text)
- BRAND_LIGHT: '#F5F5F5' (light gray for table header background)
- LOGO_PATH: path.resolve to media/logos/BB.png (the Big Barn logo — use as company logo)
- PAGE_MARGIN: 50
- FONT_SIZE_TITLE: 24
- FONT_SIZE_HEADING: 14
- FONT_SIZE_BODY: 10
- FONT_SIZE_SMALL: 8

**Layout helper functions (all accept PDFKit.PDFDocument as first arg):**

1. `drawHeader(doc, order)` — Logo top-left (120px wide), "INVOICE" title top-right in BRAND_COLOR, order number and date below title. Draw a thin BRAND_COLOR horizontal rule below.

2. `drawCustomerInfo(doc, order)` — Two-column layout: "Bill To" on left (customer name, billing address), "Ship To" on right (shipping address). If no shipping address, show "Same as billing" or "Local Pickup". Use FONT_SIZE_BODY.

3. `drawLineItemsTable(doc, order)` — Table with columns: Item, Qty, Unit Price, Total. Header row with BRAND_LIGHT background and bold text. Each line item as a row. Alternating subtle row shading for readability. Right-align price columns. Show color/size in parentheses after product name if present.

4. `drawTotals(doc, order)` — Right-aligned summary: Subtotal, Shipping (if > 0), Tax (if > 0), Discount (if > 0), then a bold Total line with BRAND_COLOR accent.

5. `drawFooter(doc)` — Bottom of page: "Thank you for your business!" centered in FONT_SIZE_SMALL. Company name below.

Export all functions and constants.
  </action>
  <verify>npx tsc --noEmit passes</verify>
  <done>Invoice template module defines all layout sections with brand styling</done>
</task>

<task type="auto">
  <name>Task 2: Build invoice PDF generator with CLI</name>
  <files>scripts/orders/invoice-generator.ts</files>
  <action>
Create scripts/orders/invoice-generator.ts that composes the template functions into a complete invoice.

**Main function:**
```typescript
export async function generateInvoice(order: Order): Promise<Buffer>
```
- Create a new PDFDocument (letter size 8.5x11, margins from template constants)
- Call drawHeader, drawCustomerInfo, drawLineItemsTable, drawTotals, drawFooter in sequence
- Collect document stream into Buffer and return it

**File output helper:**
```typescript
export async function saveInvoice(order: Order, outputPath: string): Promise<string>
```
- Call generateInvoice, write Buffer to outputPath
- Return the absolute path written
- Default outputPath pattern: `data/invoices/INV-{orderNumber}.pdf`

**Ensure data/invoices/ directory:**
- Create data/invoices/ on first use (mkdirSync recursive)
- Add data/invoices/ pattern to .gitignore if not already present

**CLI runner (bottom of file):**
If run directly:
- Accept --demo flag to generate a demo invoice with sample data (hardcoded sample Order with 3 line items, a shipping address, tax, and discount)
- Print "Invoice saved to: data/invoices/INV-DEMO.pdf"
- Open the PDF with the default system viewer (`start` on Windows, `open` on macOS) using child_process.exec

Add npm script to package.json: `"invoice:demo": "npx tsx scripts/orders/invoice-generator.ts --demo"`
