<task type="auto">
  <name>Task 2: Add order dashboard API endpoints to preview server</name>
  <files>scripts/pipeline/preview-server.ts</files>
  <action>
Add order management HTTP endpoints to the existing preview server. Import from scripts/orders/index.ts.

**New endpoints:**

1. `GET /api/orders` — List orders
   - Query params: ?status=new&source=wix (optional filters)
   - Returns JSON: { orders: Order[], count: number }

2. `GET /api/orders/:id` — Get single order by ID or order number
   - If param is numeric, look up by orderNumber; otherwise by id
   - Returns JSON: { order: Order }
   - 404 if not found

3. `POST /api/orders` — Create manual order
   - Body: { customer: OrderCustomer, lineItems: OrderLineItem[], shippingAddress?: OrderAddress, billingAddress?: OrderAddress, shippingCost?: number, tax?: number, notes?: string }
   - Calculate subtotal and total from lineItems
   - Returns 201 JSON: { order: Order }

4. `PATCH /api/orders/:id/status` — Update order status
   - Body: { status: OrderStatus, note?: string }
   - Validate transition; return 400 with error message if invalid
   - Returns JSON: { order: Order }

5. `POST /api/orders/sync` — Trigger WIX order sync
   - Body: { days?: number } (optional, default 7)
   - Returns JSON: { result: SyncResult }

6. `GET /api/orders/:id/invoice` — Generate and return invoice PDF
   - Set Content-Type: application/pdf
   - Set Content-Disposition: inline; filename="INV-{orderNumber}.pdf"
   - Stream the PDF buffer in response
   - 404 if order not found

7. `GET /api/orders/:id/label` — Generate and return shipping label PDF
   - Same headers as invoice
   - 400 if order has no shipping address
   - Stream the PDF buffer

8. `POST /api/orders/:id/print-invoice` — Print invoice to configured printer
   - Returns JSON: { result: PrintResult }

9. `POST /api/orders/:id/print-label` — Print shipping label
   - Returns JSON: { result: PrintResult }

10. `GET /api/printers` — List available printers
    - Returns JSON: { printers: string[] }

**Integration notes:**
- Follow the existing request handling pattern in preview-server.ts (url parsing, readBody helper, JSON responses)
- Use the same error response pattern: { error: string } with appropriate status codes
- Add endpoint routing in the existing request handler switch/if-chain
- Import orders module at top of file alongside existing imports
  </action>
