<task type="auto">
  <name>Task 1: Build local order store with lifecycle management</name>
  <files>scripts/orders/order-store.ts</files>
  <action>
Create scripts/orders/order-store.ts — JSON-file-backed order storage following the same pattern as scripts/monitor/store.ts (loadConfig/saveConfig pattern with data/ directory).

**Storage file:** data/orders/orders.json (gitignored)
**Data shape:** { orders: Order[], lastSync: string (ISO-8601), nextOrderNumber: number }

**Functions:**

1. `loadOrders(): OrderStore` — Read data/orders/orders.json, return parsed. Create file with empty orders array if missing. Ensure data/orders/ directory exists.

2. `saveOrders(store: OrderStore): void` — Write atomically (write to .tmp then rename, same pattern used elsewhere).

3. `getOrder(id: string): Order | undefined` — Find by id.

4. `getOrderByNumber(orderNumber: number): Order | undefined` — Find by orderNumber.

5. `addOrder(order: Omit<Order, 'id' | 'orderNumber' | 'createdAt' | 'updatedAt' | 'statusHistory'>): Order` — Generate crypto.randomUUID() for id, auto-increment orderNumber from store.nextOrderNumber, set createdAt/updatedAt to now, initialize statusHistory with first entry, save and return.

6. `upsertWixOrder(order: Order): Order` — Find existing by wixOrderId. If exists, update fields (but preserve local status if it's been advanced beyond the WIX mapping). If new, add with source='wix'. Return the order.

7. `updateOrderStatus(id: string, newStatus: OrderStatus, note?: string): Order` — Validate transition using OrderStatusTransition from types.ts. Throw descriptive error if invalid transition (e.g., "Cannot transition from 'delivered' to 'new'"). Update status, updatedAt, append to statusHistory. Save and return.

8. `listOrders(filter?: { status?: OrderStatus; source?: OrderSource }): Order[]` — Return filtered list, sorted by updatedAt DESC.

9. `getNextOrderNumber(): number` — Return current nextOrderNumber without incrementing.

Add data/orders/ to .gitignore if not already present.
  </action>
  <verify>npx tsc --noEmit passes</verify>
  <done>Order store supports CRUD, lifecycle transitions, and WIX order upsert</done>

2. `autoSync(): Promise<SyncResult>` — Convenience: sync last 7 days. Log summary.

Handle errors gracefully — if WIX API fails (missing permissions, network error), log the error and return it in errors array rather than throwing. This ensures the order dashboard still works with manual orders even if WIX sync is broken.

Log each new order found: "[ORDER SYNC] New order #10043 from WIX — John Doe, $125.00"

<task type="auto">
  <name>Task 3: Build order management CLI</name>
  <files>scripts/orders/manage.ts</files>
  <action>
Create scripts/orders/manage.ts — CLI for order management, following the same pattern as scripts/monitor/manage.ts and scripts/sync/manage.ts.

**Commands:**

1. `list` — List all orders in a table: #Number | Source | Status | Customer | Total | Updated
   - Support --status flag to filter by status
   - Support --source flag to filter by source (wix/manual)
   - Color-code statuses in output (green for delivered, red for cancelled, yellow for in-production)

2. `add` — Create a manual order interactively from args:
   - --customer "First Last"
   - --email "email@example.com" (optional)
   - --phone "555-1234" (optional)
   - --item "Product Name" --qty 2 --price 25.00 (repeatable for multiple items)
   - --shipping 9.99 (optional, default 0)
   - --tax 5.00 (optional, default 0)
   - --notes "Phone order from regular customer" (optional)
   - Calculate subtotal from items, total from subtotal + shipping + tax
   - Print confirmation: "Order #10044 created — $59.99"

3. `status` — Update order status:
   - --order 10043 (order number)
   - --set "ordered" (new status)
   - --note "Ordered from SanMar PO#12345" (optional note)
   - Validate transition, print new status

4. `view` — View order details:
   - --order 10043
   - Print full order details with status history timeline

5. `sync` — Run WIX order sync:
   - --days 30 (optional, default 7)
   - Print sync results summary

Add npm scripts to package.json:
- "orders": "npx tsx scripts/orders/manage.ts"
- "orders:list": "npx tsx scripts/orders/manage.ts list"
- "orders:add": "npx tsx scripts/orders/manage.ts add"
- "orders:sync": "npx tsx scripts/orders/manage.ts sync"
  </action>
