  <name>Task 1: Add bulk status update function to order-store.ts</name>
  <files>scripts/orders/order-store.ts</files>
  <action>
Add a new exported function `updateOrderStatusBulk` that accepts an array of order IDs, a target status, and an optional note.

Implementation:
1. Load store once at start
2. Iterate through order IDs, validate each transition using ORDER_STATUS_TRANSITIONS
3. Track successes and failures separately (don't fail entire batch on one invalid transition)
4. Save store once at end
5. Return result object: { updated: Order[], failed: { id: string, reason: string }[] }

Function signature:
```typescript
export async function updateOrderStatusBulk(
  ids: string[],
  newStatus: OrderStatus,
  note?: string,
): Promise<{ updated: Order[]; failed: { id: string; reason: string }[] }>
```

Handle edge cases:
- Empty ids array returns empty results (no error)
- Non-existent order ID adds to failed array with "Order not found"
- Invalid transition adds to failed array with transition error message
- Single save at end for performance (batch file I/O)
  </action>

<task type="auto">
  <name>Task 3: Add bulk operations API endpoints to preview-server.ts</name>
  <files>scripts/pipeline/preview-server.ts</files>
  <action>
Add three new API endpoints for bulk operations:

1. `POST /api/orders/bulk/status` - Bulk status update
   - Body: { orderIds: string[], status: OrderStatus, note?: string }
   - Response: { updated: Order[], failed: { id: string, reason: string }[] }
   - Calls updateOrderStatusBulk from order-store

2. `POST /api/orders/bulk/production-sheets` - Batch production sheet generation
   - Body: { orderIds: string[] }
   - Response: { paths: string[], failed: { orderNumber: number, reason: string }[] }
   - Loads orders by ID, calls generateBatchProductionSheets

3. `POST /api/orders/bulk/production-sheets/zip` - Batch production sheets as ZIP download
   - Body: { orderIds: string[] }
   - Response: application/zip file download
   - Generates sheets to temp directory, creates ZIP with archiver, streams response
   - Cleans up temp files after streaming

Import statements to add:
```typescript
import { updateOrderStatusBulk } from '../orders/order-store.js';
import { generateBatchProductionSheets } from '../orders/production-sheet.js';
import archiver from 'archiver';
import os from 'node:os';

```

Note: archiver is already a project dependency from invoice generation. If not, install with `npm install archiver @types/archiver`.
