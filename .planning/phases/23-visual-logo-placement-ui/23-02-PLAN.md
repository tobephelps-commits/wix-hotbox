<task type="auto">
  <name>Task 1: Add alignment guides, visual feedback, and responsive polish</name>
  <files>scripts/pipeline/preview.html</files>
  <action>
Enhance the drag-and-drop placement with alignment helpers and visual polish.

**Alignment guides (~40 lines CSS + ~30 lines JS):**
- Add center crosshair guides — two thin dashed lines (1px, rgba(108,99,255,0.4)) that show the horizontal and vertical center of the container. These should be visible at all times as a subtle reference, helping users center logos visually.
- Add snap-to-center behavior: when the logo center is within 8px of the container center (horizontally or vertically), snap to exactly center and briefly flash the corresponding guide line to full opacity (rgba(108,99,255,0.8)) for 300ms. Use `requestAnimationFrame` for the flash animation, not CSS transitions (to avoid interfering with drag performance).
- Show a temporary position label when snapping: "Centered" or "Center X" / "Center Y" appears near the guide line briefly.

**Visual feedback improvements:**
- On drag start: logo opacity drops to 0.85, subtle box-shadow appears (`0 2px 8px rgba(0,0,0,0.3)`), and a slight scale-up (1.02x via transform) to give a "lifted" feel. On drop: animate back to normal opacity/shadow over 150ms.
- Handle hover states: handles grow from 10px to 12px on hover, with a smooth 100ms transition.
- When logo is at minimum or maximum scale, briefly flash the scale label red to indicate the limit has been reached.

**Responsive behavior:**
- Below 700px viewport width (matching existing mobile breakpoint): angle cards stack vertically, and the placement container takes full card width.
- The logo placement area should have a minimum height of 200px even on small screens so there's enough room to interact.
- On window resize, recalculate logo position proportionally so the placement stays accurate. Use the ResizeObserver already set up in Plan 01's engine.

**Coordinate display improvement:**
- Format the coordinate display as a clean pill: "x: 0.50 · y: 0.33 · 25%" with monospace font, semi-transparent dark background, positioned at top-right of the container (not bottom, to avoid overlapping with the scale slider).
- Add a small "copy" icon/button next to the coords that copies "0.50,0.33" to clipboard on click (for users who want to use the CLI with exact coordinates).

**Keyboard accessibility:**
- When the logo div is focused (tabIndex=0), arrow keys nudge the logo by 1px (or 5px with Shift held). This allows precise pixel-level adjustment after rough drag positioning.
- Escape key deselects the logo (removes focus and visual selection state).
  </action>
