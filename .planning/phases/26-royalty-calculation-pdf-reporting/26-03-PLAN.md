  <action>
Add a "Royalty Reports" section to the preview.html dashboard. Follow the established dashboard patterns (inline sections, card-based layout, fetch-based API calls).

**Navigation:** Add a "Royalty" nav button to the existing navigation bar (same pattern as Orders, Customers, etc.). Wire it to show/hide the royalty section.

**Section layout:**

1. **Controls bar (top of section):**
   - Customer dropdown (`<select>`) populated from GET /api/customers?active=true. Each option shows customer name. Default to first customer or placeholder "Select customer...".
   - Date range inputs: two `<input type="date">` fields for Start and End. Default Start to first day of current month, End to today.
   - "Generate Report" button — fetches GET /api/customers/:id/royalty?start=...&end=... and displays results.
   - "Download PDF" button — opens GET /api/customers/:id/royalty/pdf?start=...&end=... in a new tab (or uses window.open). Only enabled after a report has been generated. If the PDF endpoint returns 501 (Plan 02 not yet deployed), show a brief toast/message "PDF generation not yet available".

2. **Report summary cards (shown after report generated):**
   - Display a row of summary cards (same compact card style as pricing preview):
     - "Orders: [N]"
     - "Total Units: [N]"
     - "Revenue: $X,XXX.XX"
     - "Total Royalty: $X,XXX.XX" (emphasized, brand color)
   - If discountedLineItems > 0: show a subtle note "[N] line items with royalty waived"

3. **Line-item table (main content):**
   - HTML table with columns matching the PDF layout: Date, Order #, Product, Qty, Unit Price, Royalty/Unit, Total.
   - Date formatted as MM/DD/YY.
   - Product column: productName with (color, size) in lighter text if present.
   - Right-align numeric columns (Qty, Unit Price, Royalty/Unit, Total).
   - Discounted rows: show "$0.00" with "(disc.)" label, use lighter text (#999) for the entire row.
   - Alternating row striping (even rows light gray background).
   - Sticky header row for scrolling long tables.
   - Show "No orders found for this customer in the selected period." if lineItems array is empty.

4. **Totals row at bottom of table:**
   - Bold totals row with total units, total revenue, total royalty.
   - Brand color for the royalty total.

**CSS additions (embedded in the existing `<style>` block):**
- `.royalty-controls` — flex row with gap for controls bar
- `.royalty-summary` — flex row for summary cards
- `.royalty-table` — styled table matching existing dashboard tables
- `.royalty-discounted` — lighter text color for discounted rows
- `.royalty-total-row` — bold totals row styling

**JavaScript additions (embedded in the existing `<script>` block):**
- `loadRoyaltyCustomers()` — fetch customers and populate dropdown
- `generateRoyaltyReport()` — fetch report from API and render table
- `downloadRoyaltyPdf()` — open PDF in new tab
- Wire Generate button to generateRoyaltyReport(), Download PDF button to downloadRoyaltyPdf()
- Auto-load customers when Royalty section becomes visible (same pattern as other sections)

**Key behaviors:**
- Selecting a different customer clears the previous report
- Changing dates clears the previous report
- Download PDF button disabled until a report is displayed
- Loading spinner while fetching report (use existing spinner pattern if present, or simple "Loading..." text)
- Format all dollar amounts with $ and 2 decimal places, add comma separators for values over $1000
