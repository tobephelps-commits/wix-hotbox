Create scripts/customers/royalty-statement.ts following the same PDFKit pattern as scripts/orders/invoice-generator.ts and invoice-template.ts. This file contains both layout helpers and the generation entry point (single file since it's a focused, self-contained concern).

**Layout design (clean, minimal — like an accounting ledger per CONTEXT.md):**

Page: Letter size (8.5 x 11"), margins 50px. Same PDFKit setup as invoice-generator.ts.

**Header section:**
- Customer's brand logo at top-left. Resolve the FIRST logo from the customer's logoKeys using the logo registry (data/logos.json). Load with: read data/logos.json, find entry by key, resolve filePath to absolute path. If customer has no logos or logo file not found, skip the image (don't fail).
- "ROYALTY STATEMENT" title at top-right in brand color (#E31837), Helvetica-Bold, 20pt.
- Below title (right-aligned): customer name, period "January 1, 2026 — January 31, 2026" (format start/end dates as Month Day, Year), generated date.
- Horizontal rule below header (same style as invoice-template.ts).

**Customer info section:**
- Left column: Customer name (bold), contact name, email.
- Right column: Royalty rate displayed as "Royalty Rate: X%", "Report Period: [formatted dates]".
- Spacing matches invoice-template.ts drawCustomerInfo pattern.

**Line items table:**
- Column headers with light gray background (#F5F5F5): "Date", "Order #", "Product", "Qty", "Unit Price", "Royalty/Unit", "Total"
- Column widths (approximate proportions of page width):
  - Date: 12% (show as MM/DD/YY)
  - Order #: 8%
  - Product: 30% (productName, truncate with ellipsis if too long; show color/size in parentheses if present)
  - Qty: 7% (right-aligned)
  - Unit Price: 13% (right-aligned, $XX.XX)
  - Royalty/Unit: 15% (right-aligned, $XX.XX — show "$0.00" for discounted items)
  - Total: 15% (right-aligned, $XX.XX)
- Alternating row shading (even rows get #FAFAFA, same as invoice-template.ts).
- Discounted line items: show royalty columns as "$0.00" with a small "(disc.)" label next to the $0.00 royalty/unit to indicate the royalty was zeroed. Use slightly lighter text color (#999) for discounted rows.
- **Page overflow handling:** Track Y position. When Y exceeds (page height - 150px), add a new page and redraw column headers. This is important for customers with many orders.

**Totals section (right-aligned, same layout as invoice drawTotals):**
- "Total Orders: [N]"
- "Total Units: [N]"
- "Total Revenue: $X,XXX.XX" (use Intl.NumberFormat or manual comma formatting)
- Thin horizontal rule.
- "**Total Royalty: $X,XXX.XX**" in bold with brand color (#E31837), larger font.
- If discountedLineItems > 0: small note below totals: "[N] line items had royalty waived (discount applied)"

**Footer (bottom of last page):**
- Thin horizontal rule.
- "This statement was generated on [date] by HotBox Clothing" centered, small font.
- "Questions? Contact [no email needed, just the company name]" centered.

**Functions to export:**

1. `async function generateRoyaltyStatement(report: RoyaltyReport, customer: CustomerAccount): Promise<Buffer>`
   - Main entry point. Creates PDFDocument, composes sections, returns Buffer.
   - Reads logo registry to resolve customer's first logo for the header.
   - Follows same Buffer collection pattern as invoice-generator.ts.

2. `async function saveRoyaltyStatement(report: RoyaltyReport, customer: CustomerAccount, outputPath?: string): Promise<string>`
   - Generates the PDF and saves to disk.
   - Default output path: `data/royalty-statements/ROYALTY-{customerName}-{start}-to-{end}.pdf` (slugify customer name: lowercase, spaces to hyphens).
   - Ensure output directory exists (mkdir recursive).
   - Return absolute path to saved file.

**Implementation notes:**
- Import PDFDocument from 'pdfkit' (already a project dependency).
- Import RoyaltyReport from './royalty.js' and CustomerAccount from './types.js'.
- Use fs.readFileSync for logo registry (same as overlay.ts loads it).
- Use path.resolve with __dirname pattern (same as invoice-template.ts) for resolving logo file paths.
- Numbers formatted with $ and .toFixed(2). For totals over $1000, add comma separators: use `value.toLocaleString('en-US', { minimumFractionDigits: 2, maximumFractionDigits: 2 })`.
- Date formatting: use `new Date(isoString).toLocaleDateString('en-US', { year: 'numeric', month: 'long', day: 'numeric' })` for header dates, `MM/DD/YY` format for table rows.
