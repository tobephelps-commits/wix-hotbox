Create ui/src/components/logos/ directory with LogoManager component.

**LogoManager.tsx** — Full logo management panel:

**Logo Grid:**
- Fetch logos from GET /api/logos on mount
- Display logos in a responsive grid of cards (3 columns desktop, 2 tablet, 1 mobile)
- Each card shows: logo thumbnail (from /api/logos/file/{key}), displayName, key, defaultScale/opacity badge
- Cards have 44px minimum touch targets
- Empty state: "No logos yet. Upload your first logo to get started." with upload prompt

**Upload Flow:**
- "Upload Logo" button at top of grid (prominent, touch-friendly)
- On click: show inline form with fields for Key (auto-generated from display name, editable), Display Name (required)
- File input accepting image/* (PNG, JPEG, WebP, GIF)
- On submit: read file as ArrayBuffer, POST to /api/logos/upload with raw body and X-Logo-Key + X-Logo-Display-Name headers
- Show loading spinner during upload, success toast on completion, error message on failure
- Auto-generate key from display name: lowercase, replace spaces with dashes, strip non-alphanumeric except dash/underscore

**Edit Metadata:**
- Tap/click a logo card to expand inline edit form
- Editable fields: displayName (text), defaultScale (range 0.05-0.80, step 0.05), defaultOpacity (range 0.1-1.0, step 0.05), defaultBlendMode (select: multiply, screen, overlay, over)
- Save button calls PUT /api/logos/:name
- Cancel button collapses form

**Delete:**
- Delete button (trash icon) on each card, requires confirmation dialog
- "Delete {displayName}? This cannot be undone." with Cancel/Delete buttons
- Calls DELETE /api/logos/:name
- Remove card from grid on success

**LogoManager.css** — Dark theme styles matching existing ProductsTab.css patterns:
- Card background: var(--color-surface)
- Border: 1px solid var(--color-border)
- Hover: border-color change
- Touch targets: minimum 44px
- Grid: CSS Grid with auto-fill, minmax(200px, 1fr)
- Upload form: inline expansion, not modal (touch-friendly)
- Range inputs styled to match dark theme

**Props interface:**
```typescript
interface LogoManagerProps {
  onClose: () => void;  // Return to previous view
  onLogoSelect?: (logoKey: string) => void;  // Optional: select a logo (used by placement editor)
}
```
