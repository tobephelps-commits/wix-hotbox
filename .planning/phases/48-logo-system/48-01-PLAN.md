<task type="auto">
  <name>Task 2: Create Fastify route plugin for logo API endpoints</name>
  <files>src/routes/logos.ts, src/routes/index.ts</files>
  <action>
Create src/routes/logos.ts as a Fastify plugin following the same pattern as routes/vendors.ts and routes/pipeline.ts.

At plugin registration, call `setDataDir(fastify.config.dataDir)` to initialize the logo service.

**Endpoints:**

1. **GET /** — List all logos and position presets
   - Returns: `{ logos: Record<string, LogoRegistryEntry>, positionPresets: Record<string, LogoPosition> }`

2. **POST /upload** — Upload a new logo
   - Expects raw binary body with headers: `x-logo-key`, `x-logo-display-name`
   - Collect request body as Buffer (use request.body with Fastify raw body parsing — add `addContentTypeParser` for image/* to collect raw buffer)
   - Call processLogoUpload(buffer, displayName, key, displayName)
   - Returns: `{ ok: true, logo: { key, entry } }`

3. **PUT /:name** — Update logo metadata
   - Body: `{ displayName?, defaultScale?, defaultOpacity?, defaultBlendMode? }`
   - Call updateLogo(name, updates)
   - Returns: `{ ok: true, logo: updated }`

4. **DELETE /:name** — Remove a logo (also deletes file)
   - Call removeLogo(name, true)
   - Returns: `{ ok: true }`

5. **GET /file/:name** — Serve logo PNG file
   - Load logo entry, resolve file path, read file, return with `content-type: image/png` and cache headers (`cache-control: public, max-age=3600`)

6. **POST /overlay** — Generate overlay preview
   - Body: `{ imageUrl: string, logoName: string, position: LogoPosition, scale?: number, opacity?: number, blendMode?: string }`
   - Call compositeLogoOnImage(imageUrl, config)
   - Return JPEG buffer with `content-type: image/jpeg`

**Raw body parsing for upload:** Register a content type parser for `image/*` and `application/octet-stream` that collects the raw Buffer. Example:
```
fastify.addContentTypeParser(['image/png', 'image/jpeg', 'image/webp', 'image/gif', 'application/octet-stream'], { parseAs: 'buffer' }, (req, body, done) => { done(null, body); });
```

**Register in routes/index.ts:** Add `import logoRoutes from './logos.js';` and `await fastify.register(logoRoutes, { prefix: '/logos' });` after the pipeline routes registration.
