<task type="auto">
  <name>Task 2: Create vendor API routes and wire into Fastify</name>
  <files>src/routes/vendors.ts, src/routes/index.ts</files>
  <action>
Create vendor routes and register in the router:

1. **src/routes/vendors.ts** — New Fastify route plugin with these endpoints:

   **GET /api/vendors** — List registered vendors.
   - Import both adapters (triggers auto-registration): `import '../vendors/sanmar/adapter.js'` and `import '../vendors/ss-activewear/adapter.js'`.
   - Call listVendors() from src/vendors/registry.js.
   - Return `{ vendors: [{ id, name }] }` for each registered vendor.

   **GET /api/vendors/:vendorId/credentials** — Check if vendor credentials are configured.
   - Parse vendorId from params, call getVendor(id).
   - Call adapter.validateCredentials().
   - Return `{ vendor: id, configured: boolean }`.
   - On unknown vendor, return 400 with error message.

   **GET /api/vendors/:vendorId/styles/:style** — Fetch product data for a style.
   - Parse vendorId and style from params.
   - Call adapter.fetchAllProductData(style).
   - Return the UnifiedProductData object directly.
   - On error, return 500 with `{ error: message }`.
   - On unknown vendor, return 400.

   Use Fastify plugin pattern:
   ```typescript
   export default async function vendorRoutes(fastify: FastifyInstance) { ... }
   ```

2. **src/routes/index.ts** — Add vendor routes registration:
   - Import vendorRoutes from './vendors.js'.
   - Register: `fastify.register(vendorRoutes, { prefix: '/vendors' })`.
   - Keep existing health and system routes.
  </action>
  <verify>npm run dev starts successfully. curl http://localhost:3456/api/vendors returns vendor list. curl http://localhost:3456/api/vendors/sanmar/credentials returns configured status (true/false depending on .env).</verify>
  <done>Vendor API routes created: GET /api/vendors, GET /api/vendors/:vendorId/credentials, GET /api/vendors/:vendorId/styles/:style. Routes registered in Fastify router.</done>
