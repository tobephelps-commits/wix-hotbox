<task type="auto">
  <name>Task 1: Add overlay API endpoints to preview server</name>
  <files>scripts/pipeline/preview-server.ts</files>
  <action>
Add the following API endpoints to the preview server:

1. **GET /api/logos** — List available logos from registry
   - Returns: `{ logos: Record<string, LogoRegistryEntry>, positionPresets: Record<string, LogoPosition> }`
   - Uses loadLogoRegistry() from overlay.ts

2. **POST /api/overlay** — Generate a single overlaid image
   - Request body: `{ imageUrl: string, logoName: string, position: string, scale?: number, opacity?: number }`
   - position can be a preset name (e.g., "center-chest") or custom "x,y" format
   - Calls compositeLogoOnImage() with the provided config
   - Returns the JPEG buffer directly with Content-Type: image/jpeg
   - This is the core endpoint the preview UI uses to show live overlay results
   - Error handling: 400 if missing required fields, 404 if logo not found, 500 if compositing fails

3. **GET /api/overlays/:filename** — Serve a previously-generated overlay image
   - Serves files from media/overlays/ directory
   - Content-Type: image/jpeg
   - 404 if file not found
   - This allows the preview UI to reference saved overlay images

**Implementation notes:**
- Follow existing preview server URL parsing pattern (split pathname, match segments)
- Follow existing CORS header pattern
- POST /api/overlay should parse JSON body using the existing body-reading pattern in the server
- Buffer response for /api/overlay: set Content-Type to image/jpeg, Content-Length to buffer.length, write buffer directly to response
- Import overlay functions at top of file: compositeLogoOnImage, loadLogoRegistry, getLogoEntry, getPositionPreset, listLogos
  </action>

- `npx tsc --noEmit` passes
- Start preview server and test: `curl http://localhost:3456/api/logos` returns JSON with positionPresets
  </verify>
  <done>
- GET /api/logos returns logo registry

  <action>
Add logo overlay controls to the product preview HTML page. The controls should appear AFTER the product images are loaded and BEFORE the "Create Product" button.

**UI additions:**

1. **Logo Overlay Section** — a collapsible section (like the color/size selectors) titled "Logo Overlay (Optional)":
   - **Logo selector**: dropdown populated from GET /api/logos (logo names as values, displayNames as labels). First option: "None (no overlay)" selected by default.
   - **Position selector**: dropdown populated from GET /api/logos positionPresets (preset names). Default: "center-chest". Also has a "Custom..." option that shows two number inputs for x,y coordinates (0.0-1.0).
   - **Scale slider**: range input 0.10 to 0.60, step 0.05, default from logo registry entry's defaultScale. Shows current value as percentage label (e.g., "25%").
   - **Preview button**: "Preview Overlay" button that calls POST /api/overlay with the first product front image URL and current logo settings. Shows the result in an img element below.

2. **Overlay Preview Image** — an img element that shows the overlay result:
   - Initially hidden (display: none)
   - When "Preview Overlay" is clicked, shows a loading spinner, calls POST /api/overlay, creates a blob URL from the response, sets img src
   - Should be a reasonable size (max-width: 400px) for quick visual check
   - Below the image, show overlay details: "Logo: {name} | Position: {preset} | Scale: {percent}%"

3. **Integration with Create Product**:
   - When "Create Product" is clicked and a logo is selected (not "None"), include overlay config in the create request body
   - The existing POST /api/create endpoint will need the overlay config — but since the CLI handles the actual overlay (not the server), the preview server's create endpoint should accept and pass through the overlay config OR the preview is informational only and the CLI handles creation
   - **Decision**: Keep it simple. The preview overlay is for visual verification only. The actual logo overlay during product creation is handled by the CLI (Plan 14-02). The preview UI just shows what it will look like. Add a note below the overlay preview: "Logo will be applied to all product images during creation. Overlaid images saved to media/overlays/"
