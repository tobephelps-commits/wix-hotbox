<task type="auto">
  <name>Task 1: Add --logo CLI flags and overlay integration to create-product</name>
  <files>scripts/pipeline/create-product.ts</files>
  <action>
Add three new CLI flags to the argument parser in create-product.ts:

1. `--logo NAME` — Logo name from the registry (e.g., "bigbarn", "board30")
2. `--logo-position PRESET` — Position preset name (e.g., "center-chest") or custom "x,y" coordinates (e.g., "0.5,0.3")
3. `--logo-scale N` — Logo scale as proportion of image width (0.1-0.8, default from logo registry entry)

Also add two info-only flags:
4. `--list-logos` — Print available logos and exit (same early-exit pattern as --list-presets)
5. `--list-positions` — Print available position presets and exit

**Argument parsing additions:**
- Parse --logo, --logo-position, --logo-scale from process.argv following the existing pattern
- --logo-position defaults to "center-chest" if --logo is provided but --logo-position is not
- --logo-scale defaults to the logo registry entry's defaultScale if not specified
- If --logo is provided but the logo name is not found in registry, show available logos and exit with error

**Logo overlay precedence (similar to pricing precedence):**
- CLI --logo > template logoOverlay > no overlay (default)
- CLI --logo-position > template logoOverlay.position > "center-chest"
- CLI --logo-scale > template logoOverlay.scale > logo registry defaultScale

**Integration into product creation flow:**
After buildMediaPayload() produces the WixMediaItem[] array and BEFORE passing to createWixProduct:

1. If logo overlay is configured (via --logo flag or template):
   a. Build LogoOverlayConfig from CLI flags + template + registry defaults
   b. Extract image URLs from the WixMediaItem[] array (only items with URLs, which is all of them)
   c. Call overlayProductImages(urls, config, 'media/overlays/') to composite logos onto all product images
   d. Print: "Logo overlay: Applied {logoName} at {position} to {count} images"
   e. Print: "Overlaid images saved to media/overlays/"
   f. Print: "Note: Upload overlaid images to WIX Media Manager to replace SanMar photos"
   g. The WIX product is still created with SanMar URLs (original images) — the overlaid images are saved locally for the owner to upload manually through WIX Editor
   h. This matches the existing workflow: "owner replaces with mockups post-creation" (PROJECT.md decision)

2. If no logo overlay configured, skip silently (no change to existing flow)

**Template application:**
When a template is applied (--template flag), check for template.logoOverlay field:
- If template has logoOverlay and no --logo CLI flag, use template's logo settings
- If --logo CLI flag provided, it overrides template logo settings entirely
- Print template application summary including logo if applied: "  Logo: {name} at {position}"

**Output additions:**
Add to the creation result output:
```
  Logo overlay: {logoName} at {position} (saved to media/overlays/)
```
Or if no overlay:
```
  Logo overlay: none
```

export interface ProductTemplate {
  // ... existing fields ...
  /** Logo overlay settings (optional) */

    position: string;
