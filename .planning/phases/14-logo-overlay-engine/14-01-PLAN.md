2. Add overlay types to scripts/pipeline/types.ts:

```typescript
/** Logo placement position as proportional coordinates (0.0-1.0) */
export interface LogoPosition {
  /** Horizontal center point (0.0 = left edge, 0.5 = center, 1.0 = right edge) */
  x: number;
  /** Vertical center point (0.0 = top, 0.5 = center, 1.0 = bottom) */
  y: number;
}

/** Logo overlay configuration for a single product */
export interface LogoOverlayConfig {
  /** Logo name (key in logos.json registry) */
  logoName: string;
  /** Position on the product image (proportional coordinates) */
  position: LogoPosition;
  /** Logo size as proportion of product image width (0.0-1.0, default 0.25) */
  scale?: number;
  /** Opacity (0.0-1.0, default 0.88) */
  opacity?: number;
  /** Blend mode for screen-print effect (default "multiply") */
  blendMode?: string;
}

/** Logo entry in the logo registry (data/logos.json) */
export interface LogoRegistryEntry {
  /** Display name (e.g., "Big Barn Crossfit") */
  displayName: string;
  /** Path to PNG file relative to project root (e.g., "media/logos/bigbarn.png") */
  filePath: string;
  /** Default scale when applied (0.0-1.0) */
  defaultScale: number;
  /** Default blend mode */
  defaultBlendMode: string;
  /** Default opacity */
  defaultOpacity: number;
}

/** Logo registry file structure (data/logos.json) */
export interface LogoRegistry {
  logos: Record<string, LogoRegistryEntry>;
  /** Named position presets for quick placement */
  positionPresets: Record<string, LogoPosition>;
}
```

3. Create scripts/pipeline/overlay.ts with:

**Logo registry functions:**
- `loadLogoRegistry(): LogoRegistry` — reads data/logos.json, returns parsed registry. Creates default empty registry if file doesn't exist.
- `getLogoEntry(logoName: string): LogoRegistryEntry` — gets a logo by name from registry, throws clear error if not found.
- `getPositionPreset(presetName: string): LogoPosition` — gets a position preset by name, throws clear error if not found. Also accepts "x,y" format for custom coordinates (e.g., "0.5,0.3").
- `listLogos(): string[]` — returns available logo names.
- `listPositionPresets(): Record<string, LogoPosition>` — returns all position presets.

**Position presets to include in default registry:**
- "center-chest": { x: 0.5, y: 0.33 }
- "left-chest": { x: 0.35, y: 0.28 }
- "full-front": { x: 0.5, y: 0.40 }
- "center-back": { x: 0.5, y: 0.30 }
- "left-sleeve": { x: 0.25, y: 0.25 }

**Image compositing function:**
- `compositeLogoOnImage(imageSource: string | Buffer, config: LogoOverlayConfig): Promise<Buffer>` — the core function:
  1. If imageSource is a string URL (starts with http), download the image to a Buffer using fetch()
  2. If imageSource is a string file path, read from disk
  3. If imageSource is a Buffer, use directly
  4. Load the logo PNG from the registry entry's filePath
  5. Get product image dimensions via sharp(imageBuffer).metadata()
  6. Resize logo to `config.scale * productWidth` (default 0.25), maintaining aspect ratio with `fit: 'inside'` and `withoutEnlargement: true`
  7. Calculate pixel position: left = (width * position.x) - (logoWidth / 2), top = (height * position.y) - (logoHeight / 2). Clamp to image bounds.
  8. Composite using sharp(imageBuffer).composite([{ input: resizedLogo, top, left, blend: config.blendMode ?? 'multiply', opacity: config.opacity ?? 0.88 }])
  9. Output as JPEG buffer with quality 85 and mozjpeg: true
  10. Return the buffer

**Batch overlay function:**
- `overlayProductImages(imageUrls: string[], config: LogoOverlayConfig, outputDir: string): Promise<string[]>` — applies overlay to multiple images:
  1. Create outputDir if it doesn't exist (use `media/overlays/` as default)
  2. For each image URL, call compositeLogoOnImage()
  3. Save each result to outputDir with filename pattern `{md5hash}_overlay.jpg`
  4. Return array of local file paths
  5. Process images sequentially (not parallel) to avoid memory pressure with large images

**Important implementation notes:**
- Use dynamic import for Sharp: `const sharp = (await import('sharp')).default` — Sharp is ESM-compatible but may need default import handling
- Actually test: `import sharp from 'sharp'` at top level should work with NodeNext module resolution. Use static import.
- All file paths should use path.resolve() for Windows compatibility
- Download timeout: 30 seconds per image
- If download fails, log warning and skip that image (don't fail the whole batch)
