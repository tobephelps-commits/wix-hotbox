**2. SSE reading via fetch + ReadableStream:**

```javascript
async function startBatch(request) {
  batchStartBtn.disabled = true;
  batchProgressContainer.style.display = 'block';
  batchProgressContainer.innerHTML = '';
  batchSummaryBar.style.display = 'none';

  try {
    var res = await fetch('/api/batch-create', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(request)
    });

    var reader = res.body.getReader();
    var decoder = new TextDecoder();
    var buffer = '';

    while (true) {
      var chunk = await reader.read();
      if (chunk.done) break;

      buffer += decoder.decode(chunk.value, { stream: true });
      var lines = buffer.split('\n');
      buffer = lines.pop(); // Keep incomplete line in buffer

      for (var i = 0; i < lines.length; i++) {
        var line = lines[i].trim();
        if (line.startsWith('data: ')) {
          var json = JSON.parse(line.slice(6));
          handleBatchEvent(json);
        }
      }
    }
  } catch (err) {
    setStatus('Batch error: ' + (err.message || err), 'error');
  }

  batchStartBtn.disabled = false;
}
```

  ```html
        <span class="dot"></span>          <!-- done -->
      </div>
    </div>
  </div>
  ```

Stage icons and colors:
- `queued`: ○ (gray) — Waiting in queue
- `fetching`: ⟳ (blue, spinning via CSS animation) — Fetching from vendor
- `creating`: ⟳ (blue, spinning) — Creating WIX draft
- `media`: ⟳ (blue, spinning) — Adding images
- `variants`: ⟳ (blue, spinning) — Updating variants
- `done`: ✓ (green) — Created! N variants, N images. Link to WIX product.
- `error`: ✗ (red) — Error message

**Progress dots:** A row of 4 small dots representing pipeline stages (queued → fetch → create → done). Each dot fills as the item progresses. Use CSS transitions for smooth fill animation.

**Card behavior:**
- On `queued`: Create the card with all dots empty except first
- On stage change: Update stage text, fill next dot, animate icon
- On `done`: Fill all dots green, show result link, fade card slightly to indicate completion
- On `error`: Fill current dot red, show error message, add retry icon (future enhancement)
