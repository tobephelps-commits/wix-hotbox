<task type="auto">
  <name>Task 1: Create iterative multi-pass test runner</name>
  <files>tests/iterative-runner.ts, package.json</files>
  <action>
  Create tests/iterative-runner.ts (run with tsx):
  - Accept CLI args: --passes N (default 3), --project api|ui|all (default all)
  - For each pass (1..N):
    1. Run `npx playwright test --project={project} --reporter=json` via child_process.execSync or spawn
    2. Parse the JSON output to extract test results (pass/fail/skip per test)
    3. Store results per test name per pass
  - After all passes, analyze results:
    - "stable-pass": passed in ALL passes
    - "stable-fail": failed in ALL passes
    - "flaky": passed in some, failed in others (the key finding)
    - "skipped": skipped in all passes
  - Output summary to console:
    ```
    ═══════════════════════════════════════
    ITERATIVE TEST REPORT ({N} passes)
    ═══════════════════════════════════════
    Total tests: XX
    Stable pass: XX
    Stable fail: XX
    Flaky:       XX
    Skipped:     XX

    FLAKY TESTS:
    - test name (passed X/N, failed Y/N)
    - test name (passed X/N, failed Y/N)

    STABLE FAILURES:
    - test name (error message from last run)
    ═══════════════════════════════════════
    ```
  - Write JSON report to test-results/iterative-report.json
  - Exit code: 0 if no stable failures, 1 if any stable failures exist (flaky tests are warnings, not failures)

  Add npm scripts to package.json:
  - "test:iterative": "tsx tests/iterative-runner.ts"
  - "test:iterative:5": "tsx tests/iterative-runner.ts --passes 5"
  - "test:api:iterative": "tsx tests/iterative-runner.ts --project api"
  - "test:ui:iterative": "tsx tests/iterative-runner.ts --project ui"
  </action>
  <verify>npm run test:iterative -- --passes 2 completes and produces report</verify>
  <done>Iterative runner executes multi-pass test runs, identifies flaky tests, outputs summary with exit codes</done>
</task>
