<task type="auto">
  <name>Task 2: Create test fixtures, server harness, and DB utilities</name>
  <files>tests/fixtures.ts, tests/helpers/server.ts, tests/helpers/db.ts, tests/helpers/api.ts</files>
  <action>
  Create tests/helpers/server.ts:
  - Import buildApp from src/app.ts (the Fastify app builder)
  - Export startTestServer(port?: number) that:
    1. Creates a temp directory for test data (using fs.mkdtempSync)
    2. Sets environment: PORT=3457, DATA_DIR=tempDir, NODE_ENV=test, LOG_DIR=tempDir/logs
    3. Builds the Fastify app via buildApp()
    4. Starts listening on the test port
    5. Returns { app, baseUrl, dataDir, cleanup } where cleanup stops server and removes temp dir
  - Export stopTestServer(server) that closes Fastify and cleans up temp dir
  - Handle the case where vendor API credentials aren't set (tests should work without real vendor APIs)

  Create tests/helpers/db.ts:
  - Export seedTestOrders(dataDir) that inserts sample order data for testing
  - Export seedTestCustomers(dataDir) that inserts sample customer data
  - Export seedTestLogos(dataDir) that copies a small test PNG to logos dir
  - Use better-sqlite3 directly to insert into the test database at dataDir/hotbox.db
  - Sample data should be minimal but cover the key fields (order with 2 line items, customer with markup, etc.)

  Create tests/helpers/api.ts:
  - Export apiClient(baseUrl) factory that returns convenience methods:
    - get(path), post(path, body), patch(path, body), delete(path)
    - Each returns { status, body, headers }
    - Uses native fetch (Node 18+)

  Create tests/fixtures.ts:
  - Import { test as base, expect } from '@playwright/test'
  - Extend base test with custom fixtures:
    - `server`: starts test server in beforeAll, stops in afterAll (worker-scoped)
    - `api`: provides apiClient connected to the test server
    - `seededServer`: like server but also runs all seed functions
  - Export { test, expect } with the extended fixtures
  - This is the single import point for all test files

  Important: The server fixture must handle the case where app.ts reads config — ensure test env vars override production values. Set WIX_API_KEY and WIX_SITE_ID to dummy values so the app boots without real credentials.
  </action>
