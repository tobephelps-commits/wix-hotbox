<task type="auto">
  <name>Task 1: Create Playwright site verification script</name>
  <files>scripts/verify-site-fixes.ts, scripts/verify-site-fixes-config.ts</files>
  <action>
Install Playwright as a dev dependency (`npm install -D playwright`). Create a TypeScript verification script that tests the live site (https://www.hotboxclothing.shop) at three viewports.

Create `scripts/verify-site-fixes-config.ts` with:
- Site URL constant
- Viewport definitions: mobile (375x812), tablet (768x1024), desktop (1440x900)
- Test timeout settings (30s per check)

Create `scripts/verify-site-fixes.ts` that runs these checks and reports results:

**Homepage checks:**
- H1 heading exists (AC-2) — check for `heading level=1` in accessibility tree
- Logo alt text is descriptive, not "Hotbox_edited.jpg" (AC-1) — check alt attribute
- Copyright year is 2026, not 2022 (AC-3) — text content check
- Footer has navigation links (AC-3) — check for link elements in footer
- No chat widget blocking interactions (CR-2) — check for chat widget overlay elements

**Navigation checks:**
- "Shop All" or equivalent browse-all page exists (CR-5) — navigate to expected URL, check not 404
- Navigation has 6 or fewer top-level items (NV-1) — count nav items
- URL slugs are descriptive, not /shop-1, /blank-2 (NV-5) — check known page URLs

**Mobile checks (375x812 viewport):**
- Body scroll width equals viewport width (CR-1) — `document.body.scrollWidth <= 375`
- Hamburger menu icon visible (MC-1) — check for hamburger/menu-toggle element
- Product gallery shows images (MC-2) — navigate to a collection page, count visible product images
- Add to Cart within 1.5 viewport heights (MC-3) — check button Y position on product page

**Product page checks:**
- Size guide info section present (CK-2 — already done) — check for size guide text
- Related products section present (NV-6) — check for related/recommended products widget

**Checkout checks (non-destructive):**
- Checkout policies visible (CK-1 — already done) — navigate to checkout-like page or check API

For each check, output:
```
[PASS] AC-2: Homepage H1 heading exists
[FAIL] MC-1: No hamburger menu found at mobile viewport
[SKIP] CK-3: Variant image switching (requires manual verification)
```

End with summary: `X/Y checks passed, Z failed, W skipped`

Mark checks that require visual/subjective verification as SKIP with explanation.

Use `chromium` browser (Playwright's default). Handle network errors gracefully — if site is unreachable, report all checks as ERROR. Use `page.goto()` with `waitUntil: 'networkidle'` for reliable loading.

Do NOT use `describe/it/expect` test framework syntax — this is a standalone script, not a test suite. Use plain console output.

</task>
