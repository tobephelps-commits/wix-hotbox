  <name>Task 2: Create SMS sender with phone formatting</name>
  <files>src/notifications/sms-sender.ts, src/notifications/index.ts</files>
  <action>
Create src/notifications/sms-sender.ts:

**Twilio config interface (local to this file):**
- TwilioConfig { accountSid: string, authToken: string, phoneNumber: string }
- isTwilioConfigured(config: Config): boolean — returns true only if all three fields are non-empty

**Phone number formatting:**
- formatPhoneE164(phone: string): string | null
- Accept common US formats: (555) 123-4567, 555-123-4567, 5551234567, +15551234567
- Strip non-digit characters, prepend +1 if 10 digits, keep as-is if already starts with +
- Return null if number doesn't result in valid E.164 format (10 or 11 digits after stripping)

**Send function:**
- sendOrderSms(config: Config, db: Database, orderId: number, template: NotificationTemplate, context: NotificationContext): Promise<SendResult>
- Flow:
  1. Check isTwilioConfigured() — if not, return { success: false, error: 'Twilio not configured' }
  2. Check context.customerPhone exists — if not, return { success: false, error: 'No phone number' }
  3. Format phone to E.164 — if null, return { success: false, error: 'Invalid phone number format' }
  4. Render body from template using renderTemplate()
  5. Truncate to 1600 chars (SMS segment limit is 160 but Twilio handles multi-segment)
  6. Log notification as 'pending' via logNotification()
  7. Create Twilio client: new Twilio(config.twilioAccountSid, config.twilioAuthToken)
  8. Send: client.messages.create({ body, from: config.twilioPhoneNumber, to: formattedPhone })
  9. On success: updateLogStatus() to 'sent' with sentAt
  10. On failure: updateLogStatus() to 'failed' with error message
  11. Return SendResult (never throw — best-effort)

Update src/notifications/index.ts barrel to export:
- export { sendOrderSms, formatPhoneE164, isTwilioConfigured } from './sms-sender.js'
  </action>
