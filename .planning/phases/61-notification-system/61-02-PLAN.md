<task type="auto">
  <name>Task 1: Create email sender with HTML templates</name>
  <files>src/notifications/email-sender.ts</files>
  <action>
Create src/notifications/email-sender.ts that sends customer-facing order status emails.

**Email config:** Reuse the same SMTP pattern from src/sync/notifications.ts (nodemailer.createTransport). Accept NotificationConfig from sync/types.ts — the same SMTP credentials serve both internal sync digests and customer-facing notifications.

**HTML email builder:**
- buildOrderStatusEmail(context: NotificationContext, bodyTemplate: string, subjectTemplate: string): { subject: string, html: string, text: string }
- Render subject using renderTemplate() from store
- Build clean HTML email with:
  - Inline CSS (email clients strip <style> tags)
  - HotBox brand header (simple text header, no images — keeps it lightweight)
  - Rendered body template as main content
  - Order number prominently displayed
  - Footer with "HotBox Clothing" and "This is an automated notification"
- Also generate plain-text version (strip HTML, keep content) for email clients that don't support HTML

**Send function:**
- sendOrderEmail(config: NotificationConfig, db: Database, orderId: number, template: NotificationTemplate, context: NotificationContext): Promise<SendResult>
- Flow:
  1. Render subject + body from template using context
  2. Build HTML + text email
  3. Log notification as 'pending' via logNotification()
  4. Send via nodemailer transport
  5. On success: updateLogStatus() to 'sent' with sentAt timestamp
  6. On failure: updateLogStatus() to 'failed' with error message
  7. Return SendResult (never throw — best-effort like sync notifications)
- If config.enabled is false, return { success: true } immediately (no-op)
- If context.customerEmail is missing/empty, return { success: false, error: 'No email address' }

**Stage-specific subject defaults** (used when template subject is empty):
- ordered: "[HotBox] Order #{{orderNumber}} — Placed with Supplier"
- received: "[HotBox] Order #{{orderNumber}} — Materials Received"
- in-production: "[HotBox] Order #{{orderNumber}} — In Production"
- packed: "[HotBox] Order #{{orderNumber}} — Ready to Ship"
- shipped: "[HotBox] Order #{{orderNumber}} — Shipped!"
- delivered: "[HotBox] Order #{{orderNumber}} — Delivered"
- cancelled: "[HotBox] Order #{{orderNumber}} — Cancelled"
  </action>
  <verify>npx tsc --noEmit src/notifications/email-sender.ts</verify>
  <done>Email sender compiles, uses existing nodemailer dep, logs delivery attempts to notification_log.</done>
</task>
