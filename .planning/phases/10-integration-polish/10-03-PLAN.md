**# HotBox Pipeline Operations Guide**

**## Quick Reference**
A cheat-sheet table of every npm script with one-line description:
| Command | What it does |
|---------|-------------|
| `npm run validate` | Health check all systems (read-only) |
| `npm run validate -- PC61` | Health check + test SanMar data for style PC61 |
| `npm run fetch-product -- PC61` | Fetch and display SanMar data for a style |
| `npm run preview` | Start visual preview/curation server (localhost:3456) |
| `npm run create-product -- PC61` | Quick-create WIX draft (all colors/sizes, default pricing) |
| `npm run monitor:add -- PC61 "Essential Tee"` | Track a style for inventory monitoring |
| `npm run monitor:list` | Show all tracked styles |
| `npm run monitor:poll` | Run one inventory check |
| `npm run monitor:start` | Start continuous monitoring loop |
| `npm run sync:scan` | Auto-discover WIX products matching tracked styles |
| `npm run sync:list` | Show product mappings (SanMar style -> WIX product) |
| `npm run sync:run` | Run one sync cycle (update WIX visibility from stock) |
| `npm run sync:start` | Start continuous sync loop (monitor + sync + notify) |

**## Common Workflows**

**### Adding a New Product**
Step-by-step from SanMar style number to published WIX product:
1. `npm run validate -- STYLE` to verify the style exists and check data quality
2. `npm run preview` to start the curation server
3. Open http://localhost:3456 in browser
4. Enter style number, review colors/sizes/pricing
5. Select desired colors and sizes, choose pricing preset
6. Click "Create WIX Draft"
7. Review draft in WIX Dashboard, add custom images/descriptions, publish when ready

**### Monitoring Inventory**
How to track SanMar stock levels:
1. `npm run monitor:add -- STYLE "Product Name"` for each product
2. `npm run monitor:poll` to test (one-time check)
3. `npm run monitor:start` for continuous monitoring
4. `npm run monitor -- alerts` to review past alerts

**### Syncing Stock to WIX**
How to keep WIX product visibility in sync with SanMar inventory:
1. `npm run sync:scan` to auto-discover WIX products matching tracked styles
2. `npm run sync:list` to verify mappings look correct
3. `npm run sync:run` to test (one-time sync)
4. `npm run sync:start` for continuous sync with email notifications

**### Setting Up Email Notifications**
How to enable stock change email alerts (Gmail example):
1. Set env vars in .env: SMTP_HOST=smtp.gmail.com, SMTP_PORT=587, SMTP_USER=your@gmail.com, SMTP_PASS=app-password
2. Set NOTIFY_TO=owner@email.com, NOTIFY_FROM=alerts@hotboxclothing.shop, NOTIFY_ENABLED=true
3. Test: `npm run sync -- notify-test`
4. Gmail note: use App Password (not regular password) -- requires 2FA enabled

**## Troubleshooting**

Common errors and solutions, organized by symptom:

| Error | Cause | Fix |
|-------|-------|-----|
| "Connection refused" on SanMar API | Port 8080 blocked | Ensure outbound port 8080 is open to ws.sanmar.com |
| "Invalid credentials" on SanMar | Wrong/expired creds | Check SANMAR_* env vars. Contact sanmarintegrations@sanmar.com |
| "Style not found" | Typo or discontinued | Verify style number on sanmar.com. Style codes are case-insensitive |
| "401 Unauthorized" on WIX | Bad/expired API key | Regenerate key: WIX Dashboard > Developer Tools > API Keys |
| "WIX product not found" in sync | Product deleted from WIX | Run `npm run sync:scan` to refresh mappings |
| "Media upload failed" | SanMar CDN or WIX media issue | Product created without images. Add images manually in WIX Editor |
| Email notification not sending | SMTP config wrong | Check SMTP_* vars. Run `npm run sync -- notify-test` to test. Check spam folder |
| "Pricing data unavailable" | SanMar pricing API down | Product created with $0 price. Set price manually in WIX or retry later |

**## Architecture Overview**
Brief explanation of the 4 modules:
- `scripts/sanmar/` -- SanMar API client (SOAP endpoints for product, pricing, inventory, media)
- `scripts/pipeline/` -- Product creation pipeline (SanMar data -> WIX draft products)
- `scripts/monitor/` -- Inventory monitoring (poll SanMar, detect stock changes, alert)
- `scripts/sync/` -- Stock sync to WIX (update variant visibility based on inventory)

**## Data Files**
What's stored where:
- `data/monitor/config.json` -- monitoring configuration (poll interval, thresholds)
- `data/monitor/tracked.json` -- list of tracked SanMar styles
- `data/monitor/snapshots/` -- latest inventory snapshots per style
- `data/monitor/alerts.json` -- alert history (last 1000 entries)
- `data/sync/product-map.json` -- SanMar style -> WIX product ID mappings
- `.env` -- credentials (never commit this file)
