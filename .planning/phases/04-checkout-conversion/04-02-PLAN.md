<objective>
Create brand-specific size guide info sections via the WIX Stores Catalog V3 API and bulk-add them to all relevant products.

Purpose: CK-2 (no size guide on any product) was identified as a HIGH severity issue in Phase 1. A clothing store selling Bella+Canvas, Next Level, Gildan, North Face, Adidas, and other brands has zero size chart information. Size uncertainty is a top reason for cart abandonment in apparel e-commerce. The WIX Info Sections API allows creating reusable info sections and bulk-assigning them to products programmatically.
Output: Brand-specific size guide info sections created and assigned to all 105 products.
</objective>

<tasks>

<task type="auto">
  <name>Task 1: Identify all product brands and create size guide info sections</name>
  <files>None (API-only -- no local files modified)</files>
  <action>
1. Use WIX MCP ReadFullDocsArticle to read the Info Sections API Create method:
   https://dev.wix.com/docs/rest/business-solutions/stores/catalog-v3/info-sections-v3/create-info-section

2. Query all products via WIX API to identify distinct brands:
   - Use the catalog API to query products
   - Extract brand names from product data (look at product names, descriptions, and additionalInfo fields)
   - Group products by brand

3. Research size charts for each identified brand. Common SanMar brands include:
   - **Bella+Canvas** (fitted/unisex cuts -- runs slim)
   - **Next Level** (fashion fit -- similar to Bella+Canvas)
   - **Gildan** (traditional/relaxed fit -- runs true to size or slightly large)
   - **Port & Company** (traditional fit)
   - **The North Face** (outdoor/performance fit)
   - **Adidas** (athletic/sport fit)
   - **Nike** (athletic fit)
   - **Sport-Tek** (athletic/moisture-wicking)
   - **District** (fashion fit)

4. Create size guide info sections for each brand using the Info Sections API:
   - POST to create each info section
   - Title: "[Brand Name] Size Guide"
   - Content should include a size chart table in rich text/HTML with:
     - Size names (XS, S, M, L, XL, 2XL, 3XL, etc.)
     - Chest measurements (inches)
     - Body length (inches)
     - Where applicable: waist, hip measurements for specific garment types
   - Include a note: "Measurements are approximate. When between sizes, we recommend sizing up for a relaxed fit or staying true to size for a fitted look."

5. For brands where exact measurements are not available from product data, create a general size guide:
   - Title: "General Apparel Size Guide"
   - Include standard US apparel sizing chart
   - Note that fit may vary by brand

6. Also create a "How to Measure" info section:
   - Title: "How to Measure"
   - Content: Instructions for measuring chest, body length, and sleeve length
   - This section gets added to ALL products regardless of brand
  </action>
  <verify>WIX API returns successful creation responses for each info section. List info sections to confirm all were created with correct titles and content.</verify>
  <done>Size guide info sections created for each distinct brand found in the catalog plus a general guide and a "How to Measure" section.</done>
</task>

<task type="auto">
  <name>Task 2: Bulk-assign size guide info sections to all products</name>
  <files>None (API-only -- no local files modified)</files>
  <action>
1. Use WIX MCP ReadFullDocsArticle to read the Bulk Add Info Sections To Products method:
   https://dev.wix.com/docs/rest/business-solutions/stores/catalog-v3/products-v3/bulk-add-info-sections-to-products

2. For each brand group identified in Task 1:
   a. Collect all product IDs belonging to that brand
   b. Get the info section ID for that brand's size guide
   c. Use Bulk Add Info Sections To Products API to assign the brand-specific size guide to all products of that brand

3. For ALL products regardless of brand:
   a. Use Bulk Add Info Sections To Products API to assign the "How to Measure" info section to all 105 products

4. For products where the brand could not be determined:
   a. Assign the "General Apparel Size Guide" info section

5. Verify by querying a sample of products (one per brand) that the info sections are attached:
   - Use Get Product API to check that info sections appear in the product data
   - Verify at least 3 products from different brands

6. Document which brands were identified, how many products each brand has, and which size guide was assigned.
  </action>
  <verify>Query 3+ sample products from different brands -- each should have both a brand-specific (or general) size guide AND the "How to Measure" info section in their info sections list.</verify>
  <done>All products have appropriate size guide info sections assigned. Brand-specific guides for identified brands, general guide for unidentified brands, and "How to Measure" on all products. CK-2 resolved.</done>
</task>
