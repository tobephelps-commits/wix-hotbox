<task type="auto">
  <name>Task 2: Create CHECKOUT-CONVERSION-GUIDE.md with all remaining manual fixes</name>
  <files>.planning/phases/04-checkout-conversion/CHECKOUT-CONVERSION-GUIDE.md</files>
  <action>
Create a comprehensive guide at .planning/phases/04-checkout-conversion/CHECKOUT-CONVERSION-GUIDE.md that covers all remaining checkout and conversion optimizations the store owner needs to implement manually.

Structure the guide as follows:

**1. Executive Summary**
- What was already automated in Plans 04-01 and 04-02
- What remains for manual implementation
- Estimated total effort

**2. Already Completed (Phase 4 Automated)**
- Checkout policies configured (04-01)
- Size guides added to all products (04-02)
- List what's now live

**3. WIX Dashboard Configuration (No Editor Required)**
Priority order:

a. **Abandoned Cart Recovery** (HIGH priority)
   - Location: WIX Dashboard > eCommerce > Abandoned Carts (or Automations)
   - Enable automated abandoned cart emails
   - Configure timing (e.g., 1 hour, 24 hours after abandonment)
   - Customize email content with brand voice
   - Consider including a discount code for recovery

b. **Order Confirmation & Shipping Emails** (MEDIUM priority)
   - Location: WIX Dashboard > eCommerce > Email Notifications
   - Customize order confirmation email
   - Customize shipping notification email
   - Ensure emails include return policy link

c. **Shipping Settings** (MEDIUM priority)
   - Location: WIX Dashboard > eCommerce > Shipping & Fulfillment
   - Review shipping rates and regions
   - Consider free shipping threshold (e.g., "Free shipping on orders over $75")
   - Configure shipping display on product pages if available

d. **Tax Settings** (LOW priority -- verify only)
   - Location: WIX Dashboard > eCommerce > Tax
   - Verify tax is correctly configured for shipping regions

**4. WIX Editor Fixes (Requires Editor Access)**
Priority order:

a. **CK-3: Variant Image Switching** (HIGH priority)
   - Issue: Selecting a different color does not change the product photo
   - Location: WIX Editor > Product Page template
   - Instructions: Check product gallery widget settings for "Link gallery images to product options" or equivalent
   - Note: This requires that each product variant has a corresponding image uploaded in the WIX product media gallery. If images are mockups with specific colorways, each color variant needs its own mockup image.
   - Impact: Customers can preview their color choice before purchasing

b. **Trust Signals on Product Pages** (MEDIUM priority)
   - Add a "Secure Checkout" badge or text near the Add to Cart button
   - Add payment method icons (Visa, Mastercard, PayPal, Apple Pay, etc.)
   - Consider adding a brief "Custom Made to Order" note
   - Consider adding "Free Returns on Defective Items" badge (per return policy)

c. **Cart Page Upsell/Cross-Sell** (LOW priority)
   - If WIX supports it, add "You might also like" or "Complete the look" suggestions to the cart page
   - This builds on the Related Products work from Phase 2 Plan 02-05

**5. Verification Checklist**
Complete flow test after all manual fixes are applied.

**6. Audit Results**
Include the Playwright audit findings from Task 1:
- Screenshots/snapshots of current checkout state
- Current payment methods detected
- Current form fields present
- Any issues found

The guide should follow the same format as MOBILE-OPTIMIZATION-MASTER.md (Priority-based sections, effort estimates, step-by-step instructions).
