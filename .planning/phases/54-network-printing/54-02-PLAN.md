<task type="auto">
  <name>Task 1: Create printing API routes</name>
  <files>src/routes/printing.ts</files>
  <action>
  Create `src/routes/printing.ts` as Fastify plugin with endpoints:

  **Printer Discovery:**
  - POST /api/printing/discover -- Trigger mDNS printer discovery on LAN. Body: { timeout?: number } (default 5000ms). Calls discoverPrinters(timeout). Returns { printers: PrinterInfo[], count: number }.

  - GET /api/printing/printers/:uri/status -- Get real-time printer status. URI is base64-encoded printer URI (to avoid path issues). Decode URI, call getPrinterStatus(decodedUri). Return PrinterInfo with current state. 400 if URI decode fails.

  - POST /api/printing/printers/test -- Test printer connectivity. Body: { uri: string }. Call testPrinter(uri). Return { reachable: boolean, name?: string, error?: string }.

  **Saved Printer Management (in-memory config, stored in fastify.config):**
  - GET /api/printing/saved -- List saved printers. Read from a module-level savedPrinters Map<string, PrinterInfo> (loaded from config file on init). Return { printers: PrinterInfo[], defaultPrinterId?: string }.

  - POST /api/printing/saved -- Save a printer. Body: PrinterInfo (from discovery result). Add to savedPrinters map. Write config to disk (JSON file in dataDir: printers.json). Return 201 with saved printer.

  - DELETE /api/printing/saved/:id -- Remove saved printer. Delete from map and persist. Return 204 on success, 404 if not found.

  - PUT /api/printing/default/:id -- Set default printer. Validate printer exists in saved map. Update defaultPrinterId. Persist. Return { defaultPrinterId: string }. 404 if not found.

  **Print Jobs:**
  - POST /api/printing/print -- Print a document. Body: { printerUri: string, documentBuffer: string (base64-encoded PDF), documentName: string, copies?: number, mediaSize?: 'letter'|'a4', orientation?: 'portrait'|'landscape', colorMode?: 'color'|'monochrome' }. Decode base64 to Buffer, call printDocument(). Return PrintJobResult. 400 if printerUri or documentBuffer missing.

  - GET /api/printing/jobs/:printerUri/:jobId/status -- Get job status. printerUri is base64-encoded. Decode, call getJobStatus(decodedUri, jobId). Return job state.

  - POST /api/printing/jobs/:printerUri/:jobId/cancel -- Cancel a print job. printerUri is base64-encoded. Decode, call cancelJob(decodedUri, jobId). Return { success, error? }.

  **Config persistence helpers (module-level):**
  - `loadPrinterConfig(dataDir)`: Read printers.json from dataDir, parse into savedPrinters map and defaultPrinterId. Handle file-not-found gracefully (empty config).
  - `savePrinterConfig(dataDir)`: Write current savedPrinters map and defaultPrinterId to printers.json.
  - Call loadPrinterConfig in plugin registration (using fastify.config.dataDir).

  Follow existing route patterns from orders.ts and customers.ts for validation, error responses, and Fastify plugin structure.
