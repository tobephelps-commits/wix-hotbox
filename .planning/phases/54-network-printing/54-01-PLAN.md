<task type="auto">
  <name>Task 1: Install dependencies and create printer types</name>
  <files>package.json, src/printing/types.ts</files>
  <action>
  Install `ipp` package for IPP protocol communication: `npm install ipp`
  Install types if available: `npm install -D @types/ipp` (if exists, otherwise declare module)

  Also install `bonjour-service` for mDNS printer discovery on LAN: `npm install bonjour-service`

  Create `src/printing/types.ts`:

  - `PrinterInfo`: id (string, derived from URI hash), name (string), uri (string, e.g. ipp://192.168.1.100:631/ipp/print), location? (string), model? (string), state ('idle'|'processing'|'stopped'|'unknown'), supportsColor (boolean), supportsDuplex (boolean), discoveredAt (string ISO), source ('mdns'|'manual')

  - `PrintJobRequest`: printerUri (string), documentBuffer (Buffer), documentName (string), copies? (number, default 1), mediaSize? ('letter'|'a4', default 'letter'), orientation? ('portrait'|'landscape', default 'portrait'), colorMode? ('color'|'monochrome')

  - `PrintJobResult`: success (boolean), jobId? (number), jobUri? (string), error? (string), printerState? (string)

  - `PrinterConfig`: savedPrinters (PrinterInfo[]) -- manually added printers, defaultPrinterId? (string)

  - `DocumentType`: 'invoice' | 'production-sheet' | 'royalty-statement' | 'custom'
  </action>
  <verify>npx tsc --noEmit --pretty 2>&1 | head -20</verify>

<task type="auto">
  <name>Task 2: Implement printer discovery and print job submission</name>
  <files>src/printing/discovery.ts, src/printing/print-job.ts, src/printing/index.ts</files>
  <action>
  Create `src/printing/discovery.ts`:

  - `discoverPrinters(timeout?)`: Use bonjour-service to browse for `_ipp._tcp` and `_ipps._tcp` services on LAN. Listen for `timeout` ms (default 5000). Map each discovered service to PrinterInfo: construct URI from host+port+txtRecord path, extract name/model/location from txtRecord. Return PrinterInfo[].

  - `getPrinterStatus(uri)`: Send IPP Get-Printer-Attributes request to URI. Extract printer-state, printer-state-reasons, color-supported, sides-supported. Return PrinterInfo with current state. Use `ipp` package for IPP request.

  - `testPrinter(uri)`: Validate printer is reachable and accepts IPP. Send Get-Printer-Attributes, return { reachable: boolean, name?, error? }.

  Module-level state: discoveredPrinters Map<string, PrinterInfo> for caching recent discovery results.

  Create `src/printing/print-job.ts`:

  - `printDocument(request)`: Send IPP Print-Job request with PDF buffer. Set operation attributes: printer-uri, job-name (documentName), document-format ('application/pdf'). Set job attributes: copies, media (map mediaSize to IPP media keyword: 'letter' → 'na_letter_8.5x11in', 'a4' → 'iso_a4_210x297mm'), orientation-requested, print-color-mode. Parse IPP response for job-id and job-state. Return PrintJobResult.

  - `getJobStatus(printerUri, jobId)`: Send IPP Get-Job-Attributes for job status check. Return { state: string, stateReasons: string[] }.

  - `cancelJob(printerUri, jobId)`: Send IPP Cancel-Job request. Return { success: boolean, error? }.

  IPP protocol details:
  - Use `ipp` package: `ipp.Printer(uri)`, `printer.execute(operation, message, callback)`
  - Operations: 'Get-Printer-Attributes', 'Print-Job', 'Get-Job-Attributes', 'Cancel-Job'
  - Version: IPP/1.1 (widely supported)
  - Content type for print: application/pdf

  Create `src/printing/index.ts` barrel:
  - Re-export all types
  - Re-export discovery functions
  - Re-export print-job functions
  </action>
  <verify>npx tsc --noEmit --pretty 2>&1 | head -20</verify>
  <done>Printer discovery via mDNS, print job via IPP, job status/cancel, barrel exports</done>
</task>
