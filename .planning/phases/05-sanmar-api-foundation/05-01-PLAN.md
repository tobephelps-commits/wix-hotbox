<task type="auto">
  <name>Task 3: Build auth credential module</name>
  <files>scripts/sanmar/auth.ts</files>
  <action>
Create the auth module that loads credentials from environment and builds auth objects for both API families.

**scripts/sanmar/auth.ts:**

1. Import `dotenv/config` at top (auto-loads .env file)
2. Import `SanMarAuth`, `PromoStandardsAuth`, `SanMarCredentials` from `./types/index.js`

3. `loadCredentials(): SanMarCredentials` function:
   - Read SANMAR_CUSTOMER_NUMBER, SANMAR_USERNAME, SANMAR_PASSWORD from process.env
   - Throw descriptive error if any are missing: "Missing SanMar credential: {VAR_NAME}. Set it in .env file. See .env.example for required variables."
   - Return typed credentials object

4. `getSanMarAuth(): SanMarAuth` function:
   - Call loadCredentials()
   - Return { sanMarCustomerNumber, sanMarUserName, sanMarUserPassword } mapped from credentials

5. `getPromoStandardsAuth(wsVersion?: string): PromoStandardsAuth` function:
   - Call loadCredentials()
   - Default wsVersion to '2.0.0'
   - Return { wsVersion, id: credentials.username, password: credentials.password }
   - NOTE: PromoStandards uses `id` (not customerNumber) which maps to sanmar.com username

6. `validateCredentials(): boolean` function:
   - Attempt loadCredentials()
   - Return true if all three env vars present, false otherwise
   - Do NOT throw — this is for pre-flight checks

Export all 4 functions.

IMPORTANT: Do NOT hardcode any credentials. Do NOT log credential values. The auth module is a pure function of environment variables.
  </action>

  </verify>
