**scripts/sanmar/index.ts:**
Public API barrel export for the SanMar client library. This is the main entry point other scripts import from.

Re-export selectively (NOT wildcard — curate the public API):

From services:
- getProductByStyle, getProductByStyleAndColor, getProductVariant, extractUniqueColors, extractAvailableSizes
- getStylePricing, getVariantPricing, isSaleActive, getEffectivePrice, getSuggestedRetail
- getStyleInventory, getInventoryBatch, getTotalQuantity, isInStock, isWellStocked
- getProductImages, getFrontImages, getSwatchImages, getImagesByColor, groupImagesByColor

From auth:
- validateCredentials

From client:
- describeClient, clearClientCache (for debugging/recovery)

From types (re-export all types):
- All interfaces from types/index.ts

From constants:
- WSDL_URLS, WAREHOUSES, RESTRICTED_BRANDS, ACTIVE_PRODUCT_STATUSES, PRICING_CODES, INVENTORY_CAP

From utils:
- SanMarError, SanMarErrorType (for error handling by consumers)

Do NOT export: internal auth builders (getSanMarAuth, getPromoStandardsAuth), raw getClient, raw service functions that take query objects (expose convenience functions only), retry internals.

**scripts/sanmar/demo.ts:**
A runnable demo script that exercises every service module. Run with: `npx tsx scripts/sanmar/demo.ts [style]`

1. Parse command-line argument: style number (default to "PC61" — Port & Company Essential Tee, a very common SanMar style that should always exist)

2. Validate credentials: Call validateCredentials(). If false, print setup instructions and exit:
   ```
   SanMar API credentials not configured.

   To set up:
   1. Copy .env.example to .env
   2. Fill in your SanMar credentials:
      - SANMAR_CUSTOMER_NUMBER: Your SanMar account number
      - SANMAR_USERNAME: Your sanmar.com login username
      - SANMAR_PASSWORD: Your sanmar.com login password

   Don't have API access? Email sanmarintegrations@sanmar.com
   ```

3. Run demo sections with clear headers:

   **Section 1: Product Info**
   - Call getProductByStyle(style)
   - Print: style, brand, title, description (truncated to 100 chars)
   - Print: number of colors, number of sizes
   - Print: sample of first 3 colors with catalogColor → displayColor mapping
   - Print: available sizes list

   **Section 2: Pricing**
   - Call getStylePricing(style)
   - Print: piece price, case price, effective price (sale-aware)
   - Print: sale status (active/inactive, dates if active)
   - Print: price code and suggested retail markup
   - Print formatted summary via formatPricingSummary()

   **Section 3: Inventory**
   - Call getStyleInventory(style)
   - Print: total SKUs with inventory data
   - Print: first 5 SKUs with per-warehouse breakdown
   - Print: summary (in-stock count, out-of-stock count, well-stocked count)
   - Print formatted summary via formatInventorySummary() (first 10 rows)

   **Section 4: Media Content**
   - Call getProductImages(style)
   - Print: total images found
   - Print: image count by classType (Front, Rear, Swatch, Primary, High)
   - Print: first 3 image URLs

   **Section 5: Client Debug Info**
   - Call describeClient on product info client
   - Print: available SOAP methods (from describe())
   - This validates WSDL parsing is working

4. Error handling: Wrap each section in try/catch. If a section fails, print the SanMarError with suggestion and continue to next section. Don't let one failure stop the whole demo.

5. Exit with summary: "Demo complete. X/5 sections succeeded."

Add npm script: `"demo": "npx tsx scripts/sanmar/demo.ts"` to package.json.
Also add: `"demo:style": "npx tsx scripts/sanmar/demo.ts"` (same thing, just alias for clarity)
