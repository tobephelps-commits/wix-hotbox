  <files>scripts/pipeline/templates.ts, scripts/pipeline/types.ts, data/templates.json</files>
  <action>
Create `scripts/pipeline/templates.ts` — a module for saving, loading, listing, and deleting product templates. Follow the same patterns as `data/collections.json` (local JSON file, gitignored).

**ProductTemplate interface** (add to types.ts):
```typescript
interface ProductTemplate {
  name: string;                    // Template display name (e.g., "BigBarn Tee")
  description?: string;            // Optional description
  pricingPreset?: string;          // Key into PRICING_PRESETS (e.g., "standard-tee")
  pricingConfig?: PricingConfig;   // Custom override (takes precedence over pricingPreset)
  selectedSizes?: string[];        // Default sizes to select (e.g., ["S", "M", "L", "XL", "2XL"])
  colorFilter?: 'all' | string[]; // "all" = all available, or specific catalog colors
  collections?: string[];          // Default collection names
  createdAt: string;               // ISO timestamp
  updatedAt: string;               // ISO timestamp
}
```

All fields except `name`, `createdAt`, `updatedAt` are optional — a template can specify just pricing, just collections, or any combination. When applied, template values serve as defaults that CLI flags can still override.

**templates.ts functions:**
- `loadTemplates(): Promise<Record<string, ProductTemplate>>` — Read data/templates.json, return empty object if file doesn't exist
- `saveTemplate(template: ProductTemplate): Promise<void>` — Save/overwrite by name, update timestamps, write to data/templates.json
- `getTemplate(name: string): Promise<ProductTemplate | null>` — Get single template by name (case-insensitive match)
- `deleteTemplate(name: string): Promise<boolean>` — Remove template, return true if it existed
- `listTemplates(): Promise<ProductTemplate[]>` — Return all templates sorted by name

**data/templates.json format:**
```json
{
  "templates": {},
  "lastUpdated": "2026-01-31T..."
}
```

Add `data/templates.json` to .gitignore (same line as collections.json pattern — check if there's already a data/ gitignore pattern).

Use fs/promises for file I/O. Use path.resolve with __dirname for the data file path. Handle concurrent access safely by reading before writing (no file locking needed for single-user CLI tool).
  </action>

  <done>ProductTemplate type exported from types.ts. templates.ts exports loadTemplates, saveTemplate, getTemplate, deleteTemplate, listTemplates. data/templates.json gitignored.</done>
