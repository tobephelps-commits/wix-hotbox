<task type="auto">
  <name>Task 2: Update mapper for per-variant pricing</name>
  <files>scripts/pipeline/mapper.ts</files>
  <action>
Modify `mapper.ts` to calculate per-variant prices:

1. **Add import for pricing calculation:**
```typescript
import { calculateVariantPrice, calculateRetailPrice } from './pricing-rules.js';
```

2. **Update `buildCreateProductPayload`:**

The base product `priceData.price` should be the MINIMUM variant price (the price for standard sizes). This is the price WIX shows as the product listing price.

Change:
```typescript
priceData: {
  price: curated.basePrice,
},
```
To:
```typescript
priceData: {
  price: calculateRetailPrice(curated.wholesaleCost, curated.pricingConfig.markupPercent, curated.pricingConfig.rounding),
},
```

Also update `costAndProfitData`:
```typescript
costAndProfitData: {
  itemCost: curated.wholesaleCost,
},
```
(This stays the same -- wholesale cost doesn't change.)

3. **Update `buildVariantUpdates` for per-variant pricing:**

Change the price assignment inside the nested loop from:
```typescript
price: curated.basePrice,
```
To:
```typescript
price: calculateVariantPrice(curated.wholesaleCost, size, curated.pricingConfig),
```

This means 2XL variants will have a higher price than S/M/L/XL variants.

4. **Update the console log in create-product.ts** that says "all priced at $X.XX":

In `create-product.ts`, change the verification console.log from:
```typescript
console.log(`  ✓ Verified: ${variantCount} variants, all priced at $${curated.basePrice.toFixed(2)}`);
```
To:
```typescript
const basePrice = calculateRetailPrice(curated.wholesaleCost, curated.pricingConfig.markupPercent, curated.pricingConfig.rounding);
console.log(`  ✓ Verified: ${variantCount} variants, base price $${basePrice.toFixed(2)} (${curated.pricingConfig.markupPercent}% markup)`);
```

Add the import at top of create-product.ts:
```typescript
import { calculateRetailPrice } from './pricing-rules.js';
```

5. **Update the CLI runner in create-product.ts:**

The CLI auto-curate block currently sets `basePrice`. Change it to use a pricing config:

```typescript
import { getPresetConfig } from './pricing-rules.js';
```

Replace:
```typescript
basePrice: price ?? data.preview.pricing.suggestedRetail,
```

With:
```typescript
pricingConfig: {
  markupPercent: 100,
  rounding: 'nearest-99',
  sizeUpcharges: {},
},
```

If `--price` is provided via CLI, use a fixed-price config instead (markup calculated from wholesale):
```typescript
pricingConfig: price != null
  ? { markupPercent: ((price / data.preview.pricing.wholesalePrice) - 1) * 100, rounding: 'none', sizeUpcharges: {} }
  : getPresetConfig('standard-tee'),
```

**Important notes:**
- The cost field in WixVariantUpdate stays as `wholesaleCost` (same for all variants)
- Only the price field varies per variant (based on size upcharges)
- Weight still comes from SanMar per-variant data (unchanged)
- SKU format unchanged: `{style}-{catalogColor}-{size}`
