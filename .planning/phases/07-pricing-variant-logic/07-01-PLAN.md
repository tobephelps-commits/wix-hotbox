**Types:**

```typescript
/** Configuration for calculating retail prices from wholesale cost */
export interface PricingConfig {
  /** Base markup percentage applied to wholesale cost (e.g., 100 = double the wholesale price) */
  markupPercent: number;
  /** Price rounding rule */
  rounding: 'none' | 'nearest-99' | 'nearest-dollar';
  /** Size-specific price adjustments. Key is size label (e.g., "2XL"), value is dollar amount to add */
  sizeUpcharges: Record<string, number>;
}
```

**Calculation functions:**

1. `calculateRetailPrice(wholesaleCost: number, markupPercent: number, rounding: PricingConfig['rounding']): number`
   - Formula: `wholesaleCost * (1 + markupPercent / 100)`
   - Rounding: 'nearest-99' rounds to X.99 (e.g., 24.50 -> 24.99), 'nearest-dollar' rounds to nearest whole dollar, 'none' rounds to 2 decimal places
   - Returns the calculated retail price

2. `calculateVariantPrice(wholesaleCost: number, size: string, config: PricingConfig): number`
   - Applies base markup, then adds size upcharge if the size has one
   - Formula: `calculateRetailPrice(wholesaleCost, config.markupPercent, config.rounding) + (config.sizeUpcharges[size] ?? 0)`
   - The size upcharge is applied AFTER rounding (it's a flat dollar add-on, not a percentage)

3. `calculateMargin(retailPrice: number, wholesaleCost: number): { dollars: number; percent: number }`
   - Returns profit in dollars and as a percentage of retail price
   - Used for UI display so the owner can see their margin

**Size upcharge constants:**

```typescript

/** Get a pricing preset by key, falling back to 'custom' if not found */
export function getPricingPreset(key: string): PricingPreset {
  return PRICING_PRESETS[key] ?? PRICING_PRESETS['custom'];
}

/** Get just the config from a preset */
export function getPresetConfig(key: string): PricingConfig {
  return getPricingPreset(key).config;
}
```

**Notes:**
- Markup percentages are based on typical custom apparel margins (wholesale cost * 2 = 100% markup for basic tees)
- Size upcharges vary by category -- outerwear extended sizes cost significantly more at wholesale

- Presets use spread for DEFAULT_SIZE_UPCHARGES so modifications to individual presets don't mutate the default
