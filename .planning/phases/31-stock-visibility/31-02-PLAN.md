
2. After updateProductVariants() call, add inventory update step:

The current flow is:
  a. createProduct() → returns product with ID
  b. addProductMedia() → uploads images
  c. updateProductVariants() → returns array of WixVariant with IDs

Add new step after (c):
  d. Build SKU → variantId map from returned variants
  e. Call buildInventoryUpdate() with the map
  f. Call updateInventory() to set quantities

```typescript
// After variant update returns variants with IDs
const updatedVariants = await updateProductVariants(createdProduct.id, variantPayload);

// Build SKU -> variantId map for inventory update
const variantIdMap = new Map<string, string>();
for (const v of updatedVariants) {
  variantIdMap.set(v.variant.sku, v.id);
}

// Set initial inventory quantities
console.log(`[Pipeline] Setting inventory levels for ${updatedVariants.length} variants...`);
const inventoryPayload = buildInventoryUpdate(curated, inventory, variantIdMap);
await updateInventory(createdProduct.id, inventoryPayload);
console.log('[Pipeline] Inventory levels set.');
```

3. Update createProductFromStyle() and any CLI product creation functions similarly

Note: inventory parameter may be empty array if inventory fetch failed - buildInventoryUpdate handles this by defaulting to qty=0.
