<task type="auto">
  <name>Task 1: Define WIX V1 product types and pipeline intermediate types</name>
  <files>scripts/pipeline/types.ts</files>
  <action>
Create TypeScript interfaces for:

**WIX V1 Create Product request body:**
```
WixCreateProductRequest {
  product: {
    name: string              // Max 80 chars. Format: "{brandName} {productTitle}"
    productType: "physical"
    visible: false            // ALWAYS false -- draft-first workflow
    description: string       // Rich text from SanMar productDescription
    brand: string             // SanMar brandName
    weight: number            // SanMar pieceWeight (from first variant)
    manageVariants: true      // ALWAYS true -- we need per-variant pricing
    priceData: { price: number }  // Base price (will be overridden per variant)
    costAndProfitData: { itemCost: number }  // Wholesale cost from SanMar
    productOptions: WixProductOption[]
    additionalInfoSections: WixInfoSection[]
  }
}
```

**WixProductOption** -- maps to Color and Size options:
```
WixProductOption {
  name: string          // "Color" or "Size"
  optionType?: "color" | "drop_down"  // "color" for Color option, "drop_down" for Size
  choices: WixChoice[]
}

WixChoice {
  value: string         // Display color name or size label
  description: string   // Same as value for simplicity
}
```

**WixInfoSection** for additionalInfoSections:
```
WixInfoSection {
  title: string
  description: string   // Rich text
}
```

**WixAddMediaRequest** -- for POST /products/{id}/media:
```
WixMediaItem {
  url: string           // External image URL from SanMar CDN
  choice?: {
    option: string      // "Color"
    choice: string      // Display color name
  }
}
```

**WixUpdateVariantsRequest** -- for PATCH /products/{id}/variants:
```
WixVariantUpdate {
  choices: Record<string, string>  // { "Color": "Black", "Size": "M" }
  price: number                    // Retail price for this variant
  cost: number                     // Wholesale cost
  weight: number                   // Variant weight
  sku: string                      // SanMar inventoryKey or "{style}-{color}-{size}"
  visible: boolean                 // true if in stock, false if not
}
```

**Pipeline intermediate types** (the curated selection before WIX creation):
```
CuratedProduct {
  style: string                    // SanMar style number
  brandName: string
  productTitle: string
  description: string
  selectedColors: CuratedColor[]   // Owner-selected colors
  selectedSizes: string[]          // Owner-selected sizes
  basePrice: number                // Retail price to charge
  wholesaleCost: number            // SanMar effective price
}

CuratedColor {
  catalogColor: string             // SanMar mainframe color (for API queries)
  displayColor: string             // Human-readable color name (for WIX display)
}

ProductPreview {
  style: string
  brandName: string
  productTitle: string
  description: string
  availableColors: ColorPreview[]
  availableSizes: string[]
  pricing: PricingPreview
}

ColorPreview {
  catalogColor: string
  displayColor: string
  swatchUrl: string | null         // Swatch image URL
  frontImageUrl: string | null     // Front product image URL
  inStock: boolean                 // Has any size in stock
}

PricingPreview {
  wholesalePrice: number           // SanMar effective price
  suggestedRetail: number          // SanMar suggested retail
  saleActive: boolean
}
```

Export all types. Use `interface` (not `type alias`) per project convention.

<task type="auto">
  <name>Task 2: Build SanMar-to-WIX mapper functions</name>
  <files>scripts/pipeline/mapper.ts</files>
  <action>
Create mapper functions that transform SanMar data + curation choices into WIX V1 API payloads.

**Import from** `../sanmar/index.js` for SanMar types and from `./types.js` for pipeline types.

**Functions to create:**

1. `buildProductPreview(products: ProductInfo[], pricing: PricingInfo, images: MediaContent[], inventory: SkuInventory[]): ProductPreview`
   - Extract unique colors with swatch/front image URLs from media
   - Extract available sizes in SanMar sort order
   - Check inventory per color (any size in stock = color is in stock)
   - Build pricing preview from effective price and suggested retail

2. `buildCreateProductPayload(curated: CuratedProduct): WixCreateProductRequest`
   - Name: `${curated.brandName} ${curated.productTitle}` (truncate to 80 chars)
   - productType: "physical", visible: false, manageVariants: true
   - priceData.price: curated.basePrice
   - costAndProfitData.itemCost: curated.wholesaleCost
   - productOptions: Build Color option (optionType "color") with selected display colors, Size option (optionType "drop_down") with selected sizes
   - description: curated.description (pass through -- SanMar provides HTML-safe text)
   - brand: curated.brandName
   - additionalInfoSections: empty array (size guides already added in Phase 4)

3. `buildMediaPayload(curated: CuratedProduct, imagesByColor: Map<string, MediaContent[]>): WixMediaItem[]`
   - For each selected color, get front image and assign to Color choice
   - Add general product images (primary/high-res) without choice assignment
   - Use SanMar CDN URLs directly (WIX accepts external URLs in V1 addProductMedia)
   - Limit to 15 total images (WIX media limit per product)
   - Priority: 1 front image per color + general product images

4. `buildVariantUpdates(curated: CuratedProduct, products: ProductInfo[], pricing: PricingInfo, inventory: SkuInventory[]): WixVariantUpdate[]`
   - For each selected color × selected size combination:
     - choices: { "Color": displayColor, "Size": size }
     - price: curated.basePrice (same for all variants in Phase 6 -- Phase 7 adds variable pricing)
     - cost: wholesale effective price
     - weight: pieceWeight from matching ProductInfo
     - sku: `${style}-${catalogColor}-${size}` format
     - visible: true if that color+size combo has inventory (isInStock)

**Key mapping rules:**
- ALWAYS use displayColor (not catalogColor) in WIX-facing data -- WIX shows these to customers
- Use catalogColor ONLY for SanMar API queries
- Product is ALWAYS created as invisible (draft-first per PROJECT.md decision)
- Price is uniform across variants for Phase 6 (Phase 7 handles variable pricing)

Export all functions.
