  <name>Task 1: Build SanMar product data fetcher</name>
  <files>scripts/pipeline/fetch-product.ts</files>
  <action>
Create a module that fetches ALL SanMar data needed for a given style number in a single coordinated call.

**Function:**

`fetchProductData(style: string): Promise<ProductData>`

This function queries 4 SanMar API endpoints and returns aggregated results:

1. `getProductByStyle(style)` → product info array (all colors/sizes)
2. `getStylePricing(style)` → pricing info
3. `getStyleInventory(style)` → inventory per SKU
4. `getProductImages(style)` → all media content

**Run queries in parallel** using Promise.all -- all 4 are independent.

**Return type:**
```
ProductData {
  style: string
  products: ProductInfo[]        // All active products for style
  pricing: PricingInfo           // Style-level pricing
  inventory: SkuInventory[]      // Per-SKU inventory
  images: MediaContent[]         // All images
  imagesByColor: Map<string, MediaContent[]>  // Pre-grouped for mapper
  preview: ProductPreview        // Pre-built preview from mapper
}
```

After all 4 queries return:
- Call `groupImagesByColor(images)` to build imagesByColor map
- Call `buildProductPreview(products, pricing, images, inventory)` to build preview

**Error handling:**
- If style not found (INVALID_STYLE error), throw with clear message: "Style '{style}' not found in SanMar catalog"
- If any query fails, let the SanMar error propagate (already classified by Phase 5 error types)
- Log progress: "Fetching {style}... product info ✓ pricing ✓ inventory ✓ images ✓"

**CLI runner** (bottom of file, runs when executed directly):

<task type="auto">
  <name>Task 2: Build WIX product creation orchestrator</name>
  <files>scripts/pipeline/create-product.ts, scripts/pipeline/index.ts</files>
  <action>
Create the orchestrator that takes a CuratedProduct and executes the full WIX creation flow.

**Main function:**

`createWixProduct(curated: CuratedProduct, productData: ProductData): Promise<CreationResult>`

**Execution flow:**
1. Build product payload: `buildCreateProductPayload(curated)`
2. Create WIX product: `createProduct(payload)` → get productId
3. Build media payload: `buildMediaPayload(curated, productData.imagesByColor)`
4. Add media to product: `addProductMedia(productId, mediaPayload)`
5. Build variant updates: `buildVariantUpdates(curated, productData.products, productData.pricing, productData.inventory)`
6. Update variants: `updateProductVariants(productId, variantUpdates)`
7. Verify: `getProduct(productId)` → confirm variant count and visibility

**Return type:**
```
CreationResult {
  productId: string
  productUrl: string             // WIX product page URL
  variantsCreated: number        // Number of color×size variants
  mediaAdded: number             // Number of images attached
  status: "draft"                // Always draft (visible: false)
}
```

**Console output during execution:**
```

  ✓ Media added: 8 images (5 color-specific, 3 general)
  ✓ Variants updated: 15 variants (5 colors × 3 sizes)
  ✓ Verified: 15 variants, all priced at $12.99

Draft product ready for review:
```

**CLI runner** (for testing end-to-end without the preview UI):
```
if (process.argv[1] && import.meta.url.endsWith(process.argv[1].replace(/\\/g, '/'))) {
  // Quick-create mode: fetch style, auto-select ALL colors and sizes, create draft
  const style = process.argv[2];
  if (!style) { console.error('Usage: npx tsx scripts/pipeline/create-product.ts <STYLE> [--price N]'); process.exit(1); }

  const priceArg = process.argv.indexOf('--price');
  const price = priceArg !== -1 ? parseFloat(process.argv[priceArg + 1]) : null;

  const data = await fetchProductData(style);

  // Auto-curate: select all available colors and sizes
  const curated: CuratedProduct = {
    style: data.style,
    brandName: data.preview.brandName,
    productTitle: data.preview.productTitle,
    description: data.preview.description,
    selectedColors: data.preview.availableColors.map(c => ({
      catalogColor: c.catalogColor,
      displayColor: c.displayColor
    })),
    selectedSizes: data.preview.availableSizes,
    basePrice: price ?? data.preview.pricing.suggestedRetail,
    wholesaleCost: data.preview.pricing.wholesalePrice
  };

  const result = await createWixProduct(curated, data);
  // Print result summary
}
```
