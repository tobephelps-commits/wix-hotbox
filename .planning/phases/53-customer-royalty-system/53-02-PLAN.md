  <name>Task 1: Port pricing functions and royalty calculation engine</name>
  <files>src/customers/pricing.ts, src/customers/royalty.ts</files>
  <action>
  Port `src/customers/pricing.ts` from `scripts/customers/pricing.ts`:
  All pure functions, no DB dependency. Round at each step: Math.round(value * 100) / 100.

  - `calculateCustomerRetailPrice(wholesaleCost, markupPercent, rounding?)`: Apply markup, optional rounding ('none'|'nearest-99'|'nearest-dollar')
  - `calculateCustomerVariantPrice(retailPrice, sizeUpcharge)`: Add size upcharge to base retail
  - `calculateCustomerMargin(retailPrice, totalCost)`: Return { dollars, percent }
  - `calculateCustomerRoyalty(retailPrice, royaltyPercent)`: Per-unit royalty on retail price
  - `calculateCustomerPricingSummary(params)`: Main entry point returning full CustomerPricingSummary. Params: { wholesaleCost, decorationCost, customerMarkupPercent, royaltyPercent, rounding?, sizeUpcharges? }

  Port `src/customers/royalty.ts` from `scripts/customers/royalty.ts`:
  Pure functions operating on Order[] and CustomerAccount from v2.0 types.

  - `matchOrdersToCustomer(orders, customerName)`: Filter orders where order.collection matches customerName (case-insensitive). Import Order type from ../orders/types.js.
  - `filterOrdersByDateRange(orders, start, end)`: Filter by createdAt within range, exclude cancelled status.
  - `isDiscountedLineItem(lineItem, order)`: Return true if order.discount > 0 (conservative heuristic from phase 26).
  - `calculateRoyaltyForLineItem(lineItem, order, royaltyPercent)`: Calculate per-line-item royalty. If discounted, royaltyPerUnit=0. Otherwise royaltyPerUnit = unitPrice * royaltyPercent / 100, rounded.
  - `generateRoyaltyReport(params)`: Main entry point. Params: { customer: CustomerAccount, orders: Order[], periodStart, periodEnd }. Matches orders, filters by date, calculates per-line-item, aggregates totals. Returns RoyaltyReport.

  Key adaptation: Import Order and OrderLineItem from `../orders/types.js` (v2.0 types, not v1.x).
  </action>
