<task type="auto">
  <name>Task 1: Create customer CRUD and pricing routes</name>
  <files>src/routes/customers.ts</files>
  <action>
  Create `src/routes/customers.ts` as Fastify plugin with endpoints:

  **Customer CRUD:**
  - GET /api/customers -- List customers. Query param: active=true|false (default: all). Returns CustomerAccount[].
  - GET /api/customers/:id -- Get single customer by ID. 404 if not found.
  - POST /api/customers -- Create customer. Body: CreateCustomerInput (name, contactName, email, markupPercent, royaltyPercent, logoKeys?, phone?, notes?, active?). Validate: name required, markupPercent >= 0, royaltyPercent >= 0. Return 201 with created CustomerAccount.
  - PATCH /api/customers/:id -- Update customer. Body: UpdateCustomerInput (partial). Return updated CustomerAccount. 404 if not found.
  - DELETE /api/customers/:id -- Delete customer. Return 204 on success, 404 if not found.

  **Customer Pricing:**
  - POST /api/customers/:id/pricing -- Calculate pricing for a customer. Body: { wholesaleCost, decorationCost?, rounding?, sizeUpcharges? }. Uses customer's markupPercent and royaltyPercent. Returns CustomerPricingSummary. 404 if customer not found.

  Validation: Return 400 with descriptive error for missing/invalid fields. Follow existing pattern from orders.ts routes.
  </action>
  <verify>npx tsc --noEmit --pretty 2>&1 | head -20</verify>
  <done>Customer CRUD + pricing endpoint, validation, proper HTTP status codes</done>
</task>
