  <name>Task 1: Create customer migration and port types</name>
  <files>src/db/migrations/005-customers.sql, src/customers/types.ts</files>
  <action>
  Create SQLite migration `005-customers.sql` with table:

  `customers` table:
  - id TEXT PRIMARY KEY (UUID v4, generated by application)
  - name TEXT NOT NULL UNIQUE (brand/company name, used for order matching)
  - contact_name TEXT NOT NULL
  - email TEXT NOT NULL
  - phone TEXT (nullable)
  - logo_keys TEXT NOT NULL DEFAULT '[]' (JSON array of logo registry keys)
  - markup_percent REAL NOT NULL DEFAULT 0 (single markup % for all products)
  - royalty_percent REAL NOT NULL DEFAULT 0 (royalty rate for reporting)
  - notes TEXT (nullable)
  - active INTEGER NOT NULL DEFAULT 1 (boolean: 1=active, 0=inactive)
  - created_at TEXT NOT NULL DEFAULT (datetime('now'))
  - updated_at TEXT NOT NULL DEFAULT (datetime('now'))

  Add indexes: customers(active), customers(name).

  Port `src/customers/types.ts` from `scripts/customers/types.ts`:
  - `CustomerAccount`: id, name, contactName, email, phone?, logoKeys (string[]), markupPercent, royaltyPercent, notes?, active (boolean), createdAt, updatedAt
  - `CustomerPricingSummary`: wholesaleCost, decorationCost, totalCost, retailPrice, margin { dollars, percent }, royaltyPerUnit, netAfterRoyalty, variantPrices?
  - `RoyaltyLineItem`: orderId, orderNumber, orderDate, productName, sku, color, size, quantity, unitPrice, royaltyRate, royaltyPerUnit, royaltyTotal, discounted
  - `RoyaltyReport`: customerId, customerName, royaltyRate, periodStart, periodEnd, generatedAt, lineItems, totalUnits, totalRevenue, totalRoyalty, discountedLineItems, orderCount
  - `CreateCustomerInput`: Omit<CustomerAccount, 'id' | 'createdAt' | 'updatedAt'>
  - `UpdateCustomerInput`: Partial<CreateCustomerInput>
  </action>

<task type="auto">
  <name>Task 2: Port customer store to SQLite with barrel exports</name>
  <files>src/customers/store.ts, src/customers/index.ts</files>
  <action>
  Port `src/customers/store.ts` from `scripts/customers/store.ts`, converting JSON to SQLite:

  All functions take Database as first parameter (v2.0 pattern):

  - `listCustomers(db, activeOnly?)`: SELECT from customers, optionally WHERE active=1. Map rows to CustomerAccount[] (parse logo_keys JSON, convert active integer to boolean).
  - `getCustomer(db, id)`: SELECT by id, return CustomerAccount | null.
  - `getCustomerByName(db, name)`: SELECT WHERE name = ? (case-insensitive via COLLATE NOCASE), return CustomerAccount | null. Used by royalty system for order matching.
  - `addCustomer(db, input)`: Generate UUID v4 for id, INSERT into customers. Parse logoKeys to JSON string for logo_keys column. Return created CustomerAccount.
  - `updateCustomer(db, id, updates)`: UPDATE customers SET ... WHERE id. Only update provided fields. Set updated_at to current datetime. Return updated CustomerAccount.
  - `deleteCustomer(db, id)`: DELETE from customers WHERE id. Return boolean success.

  Row-to-CustomerAccount mapping helper:
  - `rowToCustomer(row)`: Convert SQLite row (snake_case, integer booleans, JSON strings) to CustomerAccount (camelCase, real booleans, parsed arrays).

  Use crypto.randomUUID() for ID generation (Node.js built-in).

  Create `src/customers/index.ts` barrel export:
  - Re-export all types from types.ts
  - Re-export all store functions
  </action>

  <done>Customer store uses SQLite via Database parameter, CRUD operations complete, barrel exports all public API</done>
