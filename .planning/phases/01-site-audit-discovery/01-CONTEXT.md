# Phase 1: Site Audit & Discovery - Context

**Gathered:** 2026-01-29
**Status:** Ready for planning

<vision>
## How This Should Work

A full X-ray of the store. Every page, every product, every navigation path mapped out so we know exactly what we're working with before changing anything. This isn't a surface-level glance — it's a comprehensive snapshot of the entire store state.

The audit covers everything equally: how customers navigate the store, how the product catalog is organized, and how the overall experience feels. No area gets skipped or glossed over.

The output should be an honest assessment — no sugarcoating, no fluff. Just a clear picture of what's actually going on and what needs to change, so the right things get fixed in the right order.

</vision>

<essential>
## What Must Be Nailed

- **Brutal honesty** — Don't sugarcoat findings. Call out what's broken, what's weak, and what's hurting the business. The whole point is to know the truth so we fix the right things.
- **Complete coverage** — Navigation, catalog structure, and overall experience all get equal attention. Nothing gets missed that would change the plan later.
- **Client landing pages** — The store serves separate landing pages for multiple clients, each with their own curated product selection. This multi-client experience needs to be understood thoroughly — it's a core part of how the store operates and needs to be cleaned up.

</essential>

<specifics>
## Specific Ideas

- Navigation is already suspected to be confusing — audit should confirm and detail exactly where customers get lost
- Mobile experience is rough — needs to be documented with specifics on what's broken
- Multiple client-specific landing pages exist with curated product selections — this is a key part of the store architecture that needs special attention
- The per-client experience needs to be cleaner and more focused — audit should assess how well (or poorly) this currently works

</specifics>

<notes>
## Additional Context

The store is live and losing conversions — that's why UX improvements come before SanMar integration in the roadmap. The audit needs to surface the conversion killers so Phases 2-4 can target them directly.

The multi-client landing page setup is a distinctive feature of this store. Understanding how it currently works (and where it falls short) is critical context for every phase that follows.

</notes>
