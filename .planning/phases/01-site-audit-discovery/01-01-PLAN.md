<task type="auto">
  <name>Task 1: Connect to WIX store and map all pages and site structure</name>
  <files>.planning/phases/01-site-audit-discovery/SITE-STRUCTURE.md</files>
  <action>
    1. Use ListWixSites to find the HotBox Clothing site and capture the site ID
    2. Use WixREADME to understand available APIs, then use SearchWixRESTDocumentation to find APIs for:
       - Querying site pages/routes
       - Reading site menu/navigation structure
       - Getting site properties and metadata
    3. Use ReadFullDocsArticle to get the exact API schemas, then CallWixSiteAPI to:
       - List ALL pages on the site (including hidden/unpublished)
       - Get the site navigation menus and their hierarchy
       - Get site properties (name, URL, settings)
    4. For each page found: record its title, URL path, type (static, dynamic, product, landing), visibility status
    5. Map the navigation hierarchy: which menus exist, what links they contain, what's the nesting structure
    6. Identify ALL client-specific landing pages — these are a core feature per CONTEXT.md. For each: record the client name, URL, what products/content it shows

    Write everything to SITE-STRUCTURE.md with these sections:
    - **Site Overview** (site ID, URL, name, key settings)
    - **Page Inventory** (table of ALL pages with path, title, type, visibility)
    - **Navigation Hierarchy** (tree view of all menus and their items)
    - **Client Landing Pages** (dedicated section per CONTEXT.md — each client page with its purpose, products, and current state)
    - **Structural Observations** (orphan pages, dead links, navigation gaps — be brutally honest per CONTEXT.md)
  </action>
  <verify>
    - SITE-STRUCTURE.md exists and contains all five sections
    - Site ID is captured and documented
    - Every page on the site is accounted for in the inventory
    - Client landing pages are individually documented
    - Navigation hierarchy is fully mapped
  </verify>
  <done>Complete site structure document with page inventory, navigation map, client landing page analysis, and structural observations. Site ID captured for use by subsequent plans.</done>
</task>
