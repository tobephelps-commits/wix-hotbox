<task type="auto">
  <name>Task 1: Create orders database migration</name>
  <files>src/db/migrations/002-orders.sql</files>
  <action>
Create SQLite migration with these tables:

**orders** table:
- `id` TEXT PRIMARY KEY (UUID)
- `wix_order_id` TEXT UNIQUE (nullable, for WIX-sourced orders)
- `order_number` INTEGER UNIQUE NOT NULL (auto-incrementing display number, starts at 1001)
- `source` TEXT NOT NULL DEFAULT 'wix' (enum: 'wix', 'manual')
- `status` TEXT NOT NULL DEFAULT 'new' (enum: new, ordered, received, in-production, packed, shipped, delivered, cancelled, on-hold)
- `customer_first_name` TEXT
- `customer_last_name` TEXT
- `customer_email` TEXT
- `customer_phone` TEXT
- `billing_address` TEXT (JSON blob — AddressInfo)
- `shipping_address` TEXT (JSON blob — AddressInfo)
- `collection` TEXT (pickup label category: "Big Barn", "Board30", etc.)
- `notes` TEXT
- `subtotal` REAL NOT NULL DEFAULT 0
- `shipping_cost` REAL NOT NULL DEFAULT 0
- `tax` REAL NOT NULL DEFAULT 0
- `discount` REAL NOT NULL DEFAULT 0
- `total` REAL NOT NULL DEFAULT 0
- `last_sync_error` TEXT (quick WIX sync failure indicator)
- `created_at` TEXT NOT NULL DEFAULT (datetime('now'))
- `updated_at` TEXT NOT NULL DEFAULT (datetime('now'))

**order_items** table:
- `id` INTEGER PRIMARY KEY AUTOINCREMENT
- `order_id` TEXT NOT NULL REFERENCES orders(id) ON DELETE CASCADE
- `product_name` TEXT NOT NULL
- `sku` TEXT
- `quantity` INTEGER NOT NULL DEFAULT 1
- `unit_price` REAL NOT NULL DEFAULT 0
- `total_price` REAL NOT NULL DEFAULT 0
- `vendor_style` TEXT
- `vendor` TEXT (sanmar, ss, etc.)
- `color` TEXT
- `size` TEXT
- `image_url` TEXT
- `created_at` TEXT NOT NULL DEFAULT (datetime('now'))

**order_status_history** table:
- `id` INTEGER PRIMARY KEY AUTOINCREMENT
- `order_id` TEXT NOT NULL REFERENCES orders(id) ON DELETE CASCADE
- `status` TEXT NOT NULL
- `note` TEXT
- `created_at` TEXT NOT NULL DEFAULT (datetime('now'))

**order_errors** table:
- `id` INTEGER PRIMARY KEY AUTOINCREMENT
- `order_id` TEXT NOT NULL REFERENCES orders(id) ON DELETE CASCADE
- `operation` TEXT NOT NULL (sync, cart-fill, print-invoice, print-label, status-update)
- `message` TEXT NOT NULL
- `retry_count` INTEGER NOT NULL DEFAULT 0
- `resolved` INTEGER NOT NULL DEFAULT 0 (boolean)
- `created_at` TEXT NOT NULL DEFAULT (datetime('now'))

Add indexes:
- `idx_orders_status` ON orders(status)
- `idx_orders_wix_order_id` ON orders(wix_order_id)
- `idx_orders_order_number` ON orders(order_number)
- `idx_orders_created_at` ON orders(created_at)
- `idx_order_items_order_id` ON order_items(order_id)
- `idx_order_status_history_order_id` ON order_status_history(order_id)
- `idx_order_errors_order_id` ON order_errors(order_id)
- `idx_order_errors_resolved` ON order_errors(resolved)

Use addresses as JSON blobs (not separate table) because they're always loaded with the order and rarely queried independently. This matches the v1.x pattern where addresses are embedded in the order object.
  </action>

<task type="auto">
  <name>Task 2: Create order TypeScript types</name>
  <files>src/orders/types.ts</files>
  <action>
Create TypeScript type definitions porting from v1.x `scripts/orders/types.ts`. Adapt for SQLite-backed storage:

**OrderStatus** type: 'new' | 'ordered' | 'received' | 'in-production' | 'packed' | 'shipped' | 'delivered' | 'cancelled' | 'on-hold'

**ORDER_STATUS_TRANSITIONS** constant: Map each status to valid next statuses (same as v1.x):
- new → [ordered, on-hold, cancelled]
- on-hold → [new, ordered, cancelled]
- ordered → [received, on-hold, cancelled]
- received → [in-production, on-hold, cancelled]
- in-production → [packed, on-hold, cancelled]
- packed → [shipped, on-hold, cancelled]
- shipped → [delivered, on-hold, cancelled]
- delivered → [] (terminal)
- cancelled → [] (terminal)

**OrderSource** type: 'wix' | 'manual'

**OrderAddress** interface: firstName, lastName, addressLine1, addressLine2?, city, state, postalCode, country, phone?, company?

**OrderLineItem** interface: id (number), orderId (string), productName, sku?, quantity, unitPrice, totalPrice, vendorStyle?, vendor?, color?, size?, imageUrl?, createdAt

**OrderStatusEntry** interface: id (number), orderId (string), status (OrderStatus), note?, createdAt

**OrderError** interface: id (number), orderId (string), operation (OrderErrorOperation), message, retryCount, resolved (boolean), createdAt

**OrderErrorOperation** type: 'sync' | 'cart-fill' | 'print-invoice' | 'print-label' | 'status-update'

**Order** interface: id, wixOrderId?, orderNumber, source (OrderSource), status (OrderStatus), customerFirstName?, customerLastName?, customerEmail?, customerPhone?, billingAddress? (OrderAddress), shippingAddress? (OrderAddress), collection?, notes?, subtotal, shippingCost, tax, discount, total, lastSyncError?, createdAt, updatedAt

**OrderWithDetails** interface: Order & { items: OrderLineItem[], statusHistory: OrderStatusEntry[], errors: OrderError[] }

**OrderFilter** interface: status?, source?, search? (string for name/email/order# search), limit?, offset?

**OrderSummary** interface: statusCounts (Record<OrderStatus, number>), errorCount, totalOrders, lastSync?

**CreateOrderInput** interface: source, customerFirstName?, customerLastName?, customerEmail?, customerPhone?, billingAddress?, shippingAddress?, collection?, notes?, subtotal, shippingCost, tax, discount, total, items (array of Omit<OrderLineItem, 'id' | 'orderId' | 'createdAt'>)

**Helper function** `isValidTransition(from: OrderStatus, to: OrderStatus): boolean` — checks ORDER_STATUS_TRANSITIONS map.

**Constants:**
- `ORDER_STATUSES`: array of all valid statuses in lifecycle order
- `TERMINAL_STATUSES`: ['delivered', 'cancelled']
- `ACTIVE_STATUSES`: all non-terminal statuses
- `AGING_THRESHOLDS`: Record mapping status to hours threshold (new: 48, in-production: 72, packed: 24) — for dashboard aging alerts
  </action>
