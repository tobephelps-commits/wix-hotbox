  <name>Task 1: Create order API routes</name>
  <files>src/routes/orders.ts</files>
  <action>
Create Fastify route plugin following the pattern in src/routes/vendors.ts and src/routes/pipeline.ts.

Export default async function accepting (fastify, opts). Access fastify.db and fastify.config.

**Endpoints:**

`GET /` — List orders
- Query params: status?, source?, search?, limit? (default 50), offset? (default 0)
- Call listOrders(fastify.db, filter)
- Return { orders, totalCount, limit, offset }

`GET /summary` — Order summary
- Call getOrderSummary(fastify.db)
- Return OrderSummary

`GET /summary/extended` — Extended summary with metrics
- Call getOrderSummaryExtended(fastify.db)
- Return ExtendedOrderSummary

`GET /errors` — Orders with unresolved errors
- Call getOrdersWithErrors(fastify.db)
- Return { orders }

`GET /:id` — Get order details
- Call getOrder(fastify.db, id)
- Return 404 if not found
- Return OrderWithDetails

`POST /` — Create manual order
- Body: CreateOrderInput
- Call createOrder(fastify.db, body)
- Return 201 with created OrderWithDetails

`PATCH /:id/status` — Update order status
- Body: { status: OrderStatus, note?: string }
- Call updateOrderStatus(fastify.db, id, status, note)
- Return 400 if invalid transition (catch error, return message)
- Return 404 if order not found
- Return updated Order

`POST /bulk/status` — Bulk status update
- Body: { orderIds: string[], status: OrderStatus, note?: string }
- Call updateOrderStatusBulk(fastify.db, orderIds, status, note)
- Return { succeeded, failed }

`POST /sync` — Trigger WIX order sync
- Body: { days?: number } (optional)
- Call syncWithRetry(fastify.config, fastify.db, { days })
- Return SyncResult

`POST /sync/reset` — Reset and resync all WIX orders
- Call clearWixOrders(fastify.db) then syncWithRetry
- Return SyncResult with cleared count

`DELETE /:id` — Delete order
- Call deleteOrder(fastify.db, id)
- Return 404 if not found
- Return 204 no content

**Error handling pattern:**
- Validation errors → 400 with { error: message }
- Not found → 404 with { error: 'Order not found' }
- Internal errors → let Fastify global handler catch (500)

**Route ordering:** Register bulk endpoints (POST /bulk/status) BEFORE parameterized routes (GET /:id) to prevent "bulk" being matched as an id parameter. This is a known issue from Phase 41.
