<task type="auto">
  <name>Task 1: Add cost/margin and sale API endpoints to preview server</name>
  <files>scripts/pipeline/preview-server.ts</files>
  <action>
  Add new endpoints to the preview server (follow existing patterns in the file):

  **Cost/Margin endpoints:**
  - `GET /api/margins` — Return all tracked product costs from cost-tracker.ts (getAllProductCosts). Response: array of ProductCostRecord objects.
  - `GET /api/margins/:style` — Return single product cost details with history (getProductCost + getCostHistory). Response: { current: ProductCostRecord, history: CostHistoryEntry[] }.

  **Sale endpoints:**
  - `GET /api/sales` — Return all sales (listSales). Optional query param ?status=active|scheduled|ended.
  - `POST /api/sales` — Create a new sale. Body: { name, discountType, discountValue, productStyles, startDate, endDate }. Call createSale, then if startDate is now/past, call applySale. Return created sale.
  - `POST /api/sales/:id/apply` — Manually apply a scheduled sale (applySale).
  - `POST /api/sales/:id/revert` — Revert an active sale (revertSale).
  - `POST /api/sales/:id/cancel` — Cancel a sale (cancelSale).
  - `POST /api/sales/check` — Run checkAndProcessSales to process scheduled/expired sales.

  Import from cost-tracker.ts and sale-pricing.ts. Follow existing endpoint patterns for error handling (try/catch, 400/404/500 status codes, JSON responses).

  Keep all new endpoints AFTER the existing ones to minimize merge conflicts. Group under comments: // Cost/Margin API (Phase 15) and // Sale Pricing API (Phase 15).
  </action>
  <verify>npx tsc --noEmit passes. Starting preview server shows no import errors.</verify>
  <done>Preview server exposes cost/margin and sale management endpoints ready for UI consumption</done>
