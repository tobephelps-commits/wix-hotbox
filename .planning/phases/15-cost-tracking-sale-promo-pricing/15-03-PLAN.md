<objective>
Integrate WIX Coupon API to create, manage, and list store-level discount coupon codes.

Purpose: Separate from per-product sale pricing (Plan 02), coupon codes are store-level discounts that customers enter at checkout. The store owner needs to create promo codes for marketing campaigns, loyalty rewards, and event-specific discounts without logging into the WIX dashboard. This plan provides CLI-based coupon management.

Output: wix-coupons.ts module with coupon CRUD via WIX API, CLI for creating and managing coupon codes.
</objective>

<task type="auto">
  <name>Task 1: Add WIX coupon types</name>
  <files>scripts/pipeline/types.ts</files>
  <action>
  Add WIX coupon interfaces to types.ts:

  - `WixCouponScope`: Object with namespace ("stores" for e-commerce), group (object with name "product" and entityId for specific product, or name "collection" and entityId for collection — omit for store-wide).

  - `WixCouponCreate`: Request body for creating a coupon.
    Fields: specification (object with: name (string — coupon display name), code (string — the promo code customers enter), startTime (string — ISO, optional), expirationTime (string — ISO, optional), usageLimit (number — max total uses, optional), limitedToOneItem (boolean — apply to one item only, optional), limitPerCustomer (number — max uses per customer, optional), active (boolean — default true), scope (WixCouponScope — what the coupon applies to)).

    Also: type field in specification — one of "moneyOff" | "percentOff" | "freeShipping".
    For "moneyOff": specification must include `moneyOffAmount` (number).
    For "percentOff": specification must include `percentOff` (number, 1-100).
    For "freeShipping": no additional amount fields needed.

  - `WixCoupon`: Response shape from WIX API.
    Fields: id (string), specification (same as create but with additional dateCreated field), numberOfUsages (number).

  NOTE: WIX Coupons V2 API base URL is `https://www.wixapis.com/stores/v2/coupons`.
  The API requires `WIX_STORES.MANAGE_COUPONS` permission on the API key.
  </action>

  <done>WIX coupon types exported from types.ts</done>

<task type="auto">
  <name>Task 2: Build WIX coupon management module with CLI</name>
  <files>scripts/pipeline/wix-coupons.ts, package.json</files>
  <action>
  Create scripts/pipeline/wix-coupons.ts:

  **API functions (using existing getHeaders pattern from wix-api.ts — import getApiKey approach or duplicate the minimal auth helper):**

  Since wix-api.ts keeps getApiKey and getHeaders as private functions, create local equivalents in this module that read WIX_API_KEY and WIX_SITE_ID. Use the same pattern (import 'dotenv/config', read from process.env, same headers format). This avoids modifying wix-api.ts's internal functions.

  WIX Coupons V2 base: `https://www.wixapis.com/stores/v2/coupons`

  - `createCoupon(params)`: POST /stores/v2/coupons with { couponInfo: { specification } } body. Return created coupon.
  - `getCoupon(couponId)`: GET /stores/v2/coupons/{couponId}. Return coupon.
  - `listCoupons()`: POST /stores/v2/coupons/query with empty query. Handle pagination. Return all coupons.
  - `deleteCoupon(couponId)`: DELETE /stores/v2/coupons/{couponId}.
  - `updateCoupon(couponId, updates)`: PATCH /stores/v2/coupons/{couponId} with partial specification.

  **CLI interface** (when run directly):

  - `npx tsx scripts/pipeline/wix-coupons.ts create --code BIGBARN20 --type percentOff --amount 20 [--limit 100] [--per-customer 1] [--expires 2026-03-01] [--collection "Big Barn Crossfit"] [--product PRODUCT_ID]`
  - `npx tsx scripts/pipeline/wix-coupons.ts create --code FREESHIP --type freeShipping [--limit 50]`
  - `npx tsx scripts/pipeline/wix-coupons.ts create --code SAVE5 --type moneyOff --amount 5`
  - `npx tsx scripts/pipeline/wix-coupons.ts list` — Print table: Code, Type, Amount, Uses, Limit, Expires, Status
  - `npx tsx scripts/pipeline/wix-coupons.ts delete COUPON_ID`

  **Scope handling:**
  - No --collection or --product flag: store-wide coupon (scope has namespace "stores" only)
  - --collection "Name": Resolve collection name to ID using getCollectionByName from wix-api.ts, create scoped coupon
  - --product PRODUCT_ID: Create product-specific coupon

  **Error handling:**
  - If WIX returns 403, suggest user check that API key has WIX_STORES.MANAGE_COUPONS permission
  - Print human-readable errors for invalid codes (WIX requires 4+ chars, alphanumeric + dash)

  Add to package.json scripts: `"coupons": "npx tsx scripts/pipeline/wix-coupons.ts"`
  </action>
