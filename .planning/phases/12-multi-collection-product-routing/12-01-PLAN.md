<objective>
Add multi-collection product routing to the creation pipeline so products are automatically assigned to one or more WIX collections during creation.

Purpose: Currently `addProductToCollection()` exists in wix-api.ts but is never called. Products are created as orphans in "All Products" only. The store owner must manually assign collections in WIX Editor. This plan integrates collection assignment as Step 5 of the creation pipeline, with CLI support for specifying target collections.

Output: Updated pipeline that accepts collection names/IDs during product creation, assigns the product to those collections after variant setup, and reports collection assignments in the CreationResult.
</objective>

  1. Add a `listCollections()` function to wix-api.ts that queries the WIX Stores V1 collections endpoint:
     - POST `https://www.wixapis.com/stores/v1/collections/query` with empty query body `{ query: {} }` to get all collections
     - Return array of `{ id: string, name: string }` objects
     - Use same auth headers pattern as existing functions (getHeaders())
     - Add a `WixCollection` interface: `{ id: string; name: string; [key: string]: unknown }`
     - Handle pagination if needed (same pattern as queryProducts)

  2. Add a `getCollectionByName(name: string)` convenience function:
     - Calls listCollections(), finds collection by case-insensitive name match
     - Returns the collection or throws descriptive error listing available collections
     - This enables CLI usage: `--collection "Big Barn Crossfit"` instead of requiring UUIDs

  3. Create a CLI-runnable script section at the bottom of wix-api.ts (or as a separate small utility) that:
     - Runs `listCollections()` and writes the results to `data/collections.json`
     - Format: `{ "collections": [{ "id": "full-uuid", "name": "Big Barn Crossfit" }, ...], "lastUpdated": "ISO timestamp" }`
     - This serves as a local cache / reference for collection IDs

  4. Run the script to populate `data/collections.json` with the actual collection IDs from the live WIX store.

<task type="auto">
  <name>Task 2: Integrate collection routing into the product creation pipeline</name>
  <files>scripts/pipeline/types.ts, scripts/pipeline/create-product.ts, scripts/pipeline/index.ts</files>
  <action>
  1. Update `CuratedProduct` in types.ts — add an optional `collections` field:
     ```
     /** Target WIX collection names or IDs for this product (optional) */
     collections?: string[];
     ```
     This field accepts either collection names (resolved via getCollectionByName) or raw collection IDs (UUIDs). Keep it optional so existing pipeline usage doesn't break.

  2. Update `CreationResult` in create-product.ts — add a `collectionsAssigned` field:
     ```
     /** Collections this product was added to (empty if none specified) */
     collectionsAssigned: string[];
     ```

  3. Add Step 5 to createWixProduct() in create-product.ts — after Step 4 (verify), before returning:
     - If `curated.collections` is defined and non-empty:
       a. For each collection string in `curated.collections`:
          - If it looks like a UUID (contains hyphens, 36 chars), use it directly as collectionId
          - Otherwise, resolve it via `getCollectionByName(name)` to get the ID
       b. Call `addProductToCollection(productId, collectionId)` for each resolved ID
       c. Use try/catch per collection (same graceful degradation pattern as media/variants)
       d. Track successful assignments in `collectionsAssigned` array
       e. On failure, add warning to `warnings` array (same pattern: "Collection assignment failed for {name}: {error}. Product created but needs manual collection assignment.")
     - If `curated.collections` is undefined or empty, skip Step 5 (no assignment, backward compatible)
     - Log: `✓ Collections: added to {N} collections ({names})` or skip message

  4. Update the CLI runner at the bottom of create-product.ts:
     - Add `--collection` flag (can be specified multiple times): `--collection "Big Barn Crossfit" --collection "Clothing"`
     - Parse collection args and add to the auto-curated CuratedProduct
     - Update usage string to show the new flag

  5. Update pipeline/index.ts barrel exports:
     - Add `listCollections`, `getCollectionByName`, `WixCollection` exports from wix-api.ts

  Import `getCollectionByName` and `addProductToCollection` in create-product.ts (addProductToCollection is already importable from wix-api.ts but not currently imported in create-product.ts).

  IMPORTANT: Keep backward compatibility — if no collections specified, pipeline works exactly as before. The `collections` field is optional on CuratedProduct.
  </action>
