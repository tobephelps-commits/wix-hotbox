<task type="auto">
  <name>Task 1: Create LAN module with mDNS advertisement and network info</name>
  <files>src/lan/types.ts, src/lan/advertise.ts, src/lan/network-info.ts, src/lan/index.ts</files>
  <action>
  Create `src/lan/types.ts`:

  - `NetworkInfo`: hostname (string), addresses (string[] - IPv4 LAN addresses), port (number), mdnsName (string, e.g. 'hotbox'), accessUrls (string[] - full URLs like http://192.168.1.50:3456)

  - `MdnsServiceInfo`: name (string), type (string, '_http._tcp'), port (number), host (string), txt (Record<string, string>)

  Create `src/lan/advertise.ts`:

  - `startAdvertisement(port, serviceName?)`: Use bonjour-service (already in package.json) to publish an HTTP service. Service name defaults to 'HotBox'. Publish `_http._tcp` on the given port. Include txt records: { path: '/', version: '2.0', type: 'hotbox-appliance' }. Return the Bonjour instance for later shutdown.

  - `stopAdvertisement(bonjour)`: Call bonjour.destroy() to stop advertising. Graceful cleanup.

  Create `src/lan/network-info.ts`:

  - `getNetworkInfo(port)`: Use `os.networkInterfaces()` to find all non-internal IPv4 addresses. Build NetworkInfo object with hostname from `os.hostname()`, all LAN IPv4 addresses, port, mdnsName, and constructed accessUrls (http://{ip}:{port} for each address, plus http://{hostname}.local:{port}). Return NetworkInfo.

  Create `src/lan/index.ts` barrel:
  - Re-export all types
  - Re-export advertise functions
  - Re-export getNetworkInfo
  </action>
  <verify>npx tsc --noEmit --pretty 2>&1 | head -20</verify>
  <done>LAN module with mDNS advertisement, network info utility, and barrel exports</done>
</task>
